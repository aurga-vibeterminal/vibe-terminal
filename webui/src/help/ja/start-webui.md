Web UI はサーバー自身の設定ページです:サーバーのすべての機能はセクションに整理され、左サイドバーに一覧表示されます。ターミナルではありません — 日々の作業はデスクトップクライアントか `vtermc` で行います(概要を参照)。このページではレイアウトと共通の動作を説明します;各セクションの設定詳細は機能の章で扱います。

## レイアウト

- **サイドバー** — セクション一覧(下記)、サーバー名横のヘルプアイコン、下部のアプリバージョン。狭い画面では左からスライドインし、ヘッダーのハンバーガーボタンで開閉します;
- **ヘッダー** — 現在のセクションのタイトルに加え、右上には言語セレクターとライト/ダーク切り替えがあります(狭い画面ではヘルプアイコンもここに表示されます);
- **コンテンツ** — 選択中のセクションのフォーム。中央に配置されスクロールできます。

## セクション

サイドバーの順:

- `サーバー` — ポート、TLS 証明書、認証の設定:`Secret Key`、ペアリング用 `QR Code`、リレーアドレス、自動起動トグルはすべてここにあります(クライアントの接続とセットアップガイドを参照)。Linux では、自動起動のヒントがローカルログイン前にデスクトップへ到達するためのディスプレイマネージャーの自動ログインについても説明します(リモートデスクトップとシミュレーターのサーバー設定を参照);
- `Terminal` — ターミナル分析:プロンプト検出、自動確認、LLM 分類(自動確認を参照);
- `UART` — ローカルの UART ポートに基づくシリアル端末プロファイル(UART シリアルを参照);
- `アドオン` — インストール済みアドオン:有効化、編集、アップロード(LLM プロバイダーもアドオンです — LLM を参照);
- `LLM` — 各 AI 機能へ LLM プロバイダーを割り当てます(LLM を参照);
- `音声` — 音声認識プロバイダー、モデル、文字起こしの設定(音声入力のサーバー設定を参照);
- `環境変数` — グループのツリー状に整理された環境変数コレクション(環境変数を参照);
- `MCP` — コードエージェントに公開されるターミナル MCP サーバー(ターミナル MCP を参照);
- `DDNS` — DDNS プロバイダーと同期設定(DDNS を参照);
- `ポートフォワーディング` — 転送ポートのプールと稼働中の TLS 転送(ポートフォワーディングを参照);
- `Static HTTP` — HTTP で公開するフォルダーと稼働中のファイル共有(HTTP サーバーで公開を参照);
- `リモートデスクトップ` — リモートデスクトップのキャプチャ、入力、ストリーム設定(リモートデスクトップとシミュレーターのサーバー設定を参照);
- `LLM 統計` — すべての LLM 機能におけるトークン使用量、リクエスト数、パフォーマンス指標。

## 保存とヒント

- ほとんどのセクションは編集後すぐに自動保存されます — 保存インジケーターとエラーはセクションの下部に表示されます;
- `MCP`、`DDNS`、`リモートデスクトップ` は `変更を保存` が押されるまで編集を保留します:編集中はボタン横に `未保存の変更` のヒントが表示され、`リセット` で破棄できます;
- モバイルクライアントから開いた場合、Web UI はアプリの言語とテーマに従い、独自の言語・テーマ切り替えを非表示にします。
