デスクトップ画面に加えて、リモートデスクトップは Android デバイスもストリーミングできます — adb 経由の実機と AVD エミュレーター。クライアントはそれらをスマホ枠のウィンドウに表示し、タッチ入力、回転、リモートでのエミュレーターライフサイクル制御を提供します。

## 前提条件

サーバーが Android ツールチェーンを見つける必要があります:

- **Android SDK**(`adb` を提供)— デバイスとエミュレーターの両方に必要;
- **Android Studio** — AVD エミュレーターの起動に必要。

どちらもデフォルトで自動検出されます。検出が失敗するか、ツールが標準の場所以外にある場合は、`Remote Desktop` → `Screen streaming tools` の `Android SDK directory` / `Android Studio directory` を設定してください。変更は即座に適用されます(ホット適用、サーバー再起動不要)。

## デバイスソース

パスが整えば、サーバーは利用可能な Android ソースを自動列挙します:

- **接続された実機** — USB デバッグ有効で USB 接続。`adb devices` に見えるものはすべてストリーミング可能;
- **AVD エミュレーター** — 実行中のエミュレーターは自動的に現れます。クライアントから任意の AVD をオンデマンドで起動(事前に手動起動は不要)し、リモートで終了することもできます。

各ソースはクライアントの SCREENS バーに独自のエントリを得ます。

## 画面回転

エミュレーターウィンドウの回転ボタンは `adb` 経由でシステムの `user_rotation` を設定します。デバイス自身の表示方向が変わり、ウィンドウが新しい解像度に再フィットし、縦横どちらにも適応します。

## クライアント側

デスクトップクライアント左パネルの `Debug` タブを開き、SCREENS バーの `Android Simulator` ボタン(サーバーが Android ソースを公開しているときのみ表示)をクリックしてエミュレーターウィンドウを開きます。デバイスピッカーでスマホ枠の外観を切り替え、`Rotate` で方向を反転します。クライアントの使い方を参照してください。

> 実機へのタッチ注入は adb の入力チャネルを使います(Android 4.4+)。一部のベンダーカスタム ROM は制限しており、その場合デバイスは閲覧専用になります。
