マシンをリレーに接続するには 2 つのフィールドだけです。リレーアドレスとそのキー。機能の内容と各要素の関係については前ページの概要を参照してください。

## リレーサーバーのセットアップ

1. リレーとして機能するマシンで `Server` セクションを開きます。
2. `Secret Key` が設定されていることを確認 — ダイスボタンで生成できます。同じキーがクライアントと共有サーバーの両方をペアリングします。
3. `QR Code` ブロックを展開し、クライアントと共有サーバーが接続に使う `Network Interface` / `IP Version` を選択します。

## 共有サーバーの接続

リレーの接続情報はクリップボードで運ばれます — 打ち直しは不要:

1. リレーサーバーの Web UI で `QR code` をクリック。暗号化された共有文字列(アドレス、ポート、シークレットキー)がクリップボードにコピーされます。
2. 共有するマシンの Web UI を開き、`Server` セクションの `Relay Address` フィールドをクリックします。
3. ブラウザがこのサイトのクリップボードアクセス許可を求めるダイアログを出します — `Allow` をクリック:

![ブラウザ — フィールドにフォーカスした際のクリップボードアクセス許可ダイアログ](images/relay-allow-paste.jpg)

4. 許可されるとクリップボードが確認され、共有文字列があればフィールド横に貼り付けボタンが現れます。クリックすると復号して `Relay Address` と `Relay Secret Key` を自動入力します:

![Web UI — 貼り付けた共有文字列から自動入力されたリレーアドレスとシークレットキー](images/relay-paste-share.jpg)

5. 値を確認して `Apply` をクリック — 保存すると上流リレーに再接続します。

![Web UI — 入力済みリレーフィールドと Apply ボタン](images/relay-apply-share.jpg)

> クリップボードの読み取りにはセキュアコンテキスト(HTTPS または localhost)が必要です。平文 HTTP では貼り付けボタンは隠れたままです。リレーアドレスとキーを手入力してください。

既定では、上位接続は暗号化されるだけで検証されません。リレーの証明書も検証したい場合は、「証明書と TLS」の「リレーでの厳格な検証」を参照してください。

## デスクトップクライアント

### 共有サーバーのタブ

共有サーバー上で動くターミナルのタブには 2 つのマーカーが付きます:タブ左端の色付きストライプ — サーバーごとに 1 色 — と、ステータスドット横のリモート OS アイコン(Windows / Apple / Linux)。リレーサーバー自体のローカルタブにはマーカーがありません。

![デスクトップクライアント — 共有サーバーターミナルのタブマーカー](images/relay-tab-indicator.jpg)

### サーバーごとのターミナルプロファイル

プロファイルメニュー(タイトルバー)はサーバーごとにターミナルプロファイルをグループ化します:接続済みリレーサーバー自身のプロファイルが最初に、次に共有サーバーごとに 1 つの折りたたみグループ(マシン名付き)。グループを展開してプロファイルを選ぶとそのサーバーにターミナルが開きます。メニューはタイトルバーで選択されたタブグループに追従します。

![デスクトップクライアント — サーバーごとのグループ付きプロファイルメニュー](images/relay-profile-menu.jpg)

### グループ化と独立ウィンドウ

タイトルバーのグループセレクターはすべてのサーバーのタブグループを一覧表示し、共有サーバーのデフォルトグループは `Ungrouped (Server Name)` と表示されます。各グループのサブメニューにはタブが素早く切り替えられるようリストされ、`Move Group to New Window` が用意されています — グループ全体を独立ウィンドウに切り離し、1 台のマシンにウィンドウやモニタを専用にするのに便利です。

![デスクトップクライアント — 新しいウィンドウへの移動アクション付きグループセレクターメニュー](images/relay-group-selector.jpg)
