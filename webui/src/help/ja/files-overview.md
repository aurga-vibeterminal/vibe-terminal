ファイル管理では、クライアントからサーバー上のファイルを直接扱えます。左のアクティビティバーには 2 つのエントリ — `Recent`(最近のプロジェクト)とファイルエクスプローラー — があり、ターミナルタブと併用します。すべての操作はセッションのサーバー上で行われます。ローカルマシン、またはリレー越しのリモート/共有マシンです。

## Recent:最近のプロジェクト

`Recent` は、コードエージェントが現在のサーバーで最近開いたフォルダを新しい順に一覧表示します:

- エントリを**クリック**すると、ファイルエクスプローラーがそのディレクトリに切り替わります;
- **右クリック**するとクイックアクションのメニューが開きます:
  - `Open in VS Code` — このマシンの VS Code でディレクトリを開く;
  - `Reveal in File Explorer` — OS のファイルマネージャで表示;
  - `Copy Full Path` / `Copy Relative Path` — フルパス、またはリポジトリからの相対パス;
  - `Search in Folder` — そのディレクトリ内のファイルを検索;
  - `Open in Terminal` — そこで新しいターミナルタブを開く。`cd Here` — 現在のターミナルをそこに cd;
  - `Host with HTTP server` — ディレクトリを HTTP ファイルサービスとして公開(HTTP サーバーで公開を参照);
  - `Open in App` — サーバーで検出されたエージェントアプリで開く。

## ファイルエクスプローラー

`Explorer` タブはサーバー側のファイルシステムを閲覧・管理します:ディレクトリナビゲーション、ツリーとフラット表示、検索、作成/リネーム/削除などのファイル操作に加え、サーバーとこのマシンの間のドラッグ&ドロップによるアップロード・ダウンロード。ファイルエクスプローラーとアップロードとダウンロードを参照してください。
