アドオンはコアに手を加えずサーバーに新しい機能を追加します：LLM プロバイダー、音声認識バックエンド、ダイナミック DNS アップデーター、追加の MCP ツール面、Code Agent アプリの検出など、すべてアドオンとして存在します。Web UI の `Addons` セクションで管理します。

## カテゴリー

各アドオンはタイプを宣言し、セクションはそれに従ってカードをグループ化します：

- **Applications** —— ターミナルオブザーバーに Code Agent CLI を認識させます（Claude Code、Codex、Kimi Code、Pi、OpenCode を内蔵）：プロセス検出、ビジー/アイドル状態、自動化フック；
- **LLM Providers** —— AI 機能が選ぶチャット補完バックエンド（OpenAI 互換プロバイダーを内蔵）；
- **Voice / ASR** —— 音声認識バックエンド（内蔵 `vibe-voice` アドオンは管理下のローカル ASR サーバーを指します）；
- **Dynamic DNS** —— ホスト名を現在のアドレスに追従させます（Cloudflare を内蔵）；
- **MCP** —— MCP ホスト上で提供される追加のツール面（EasyEDA Pro を内蔵）；
- その他のタイプは **Other** グループに入ります。

## 内蔵とアップロードのアドオン

- **内蔵** アドオンはプログラムに同梱され、常に利用できます。マニフェストとソースはオリジナルのまま —— 上書きされたソースはいつでも復元できます；
- **アップロード** アドオンはあなた自身のもの：マニフェストと JavaScript ソースを含む zip を `Upload Addon` ボタンでインストールします；
- `Modified` バッジはソースを上書きしたアドオンを示します。

各カードにはタイプ、バッジ、有効化トグルが表示され、展開すると説明、作者、設定フィールド、ソースコードが現れます。

## 設定

アドオンのマニフェストが設定フィールドを宣言し、展開したカードがフォームにします。値はアドオンごとに保存され、有効な間だけ効果があります。パスワード型フィールドはマスクされたままです。オフにしても設定は保持され、再度有効化すれば続きから再開できます。
