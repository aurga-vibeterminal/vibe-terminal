翻訳は、クライアントで出会うテキスト——AI チャットの返信、コミットメッセージ、コードコメント、コードエディターや差分の任意の選択範囲——を選んだ言語に変えます。翻訳モデルはサーバー側で設定されます。クライアントはテキストを送り、結果を描画し、キャッシュして原文と訳文を行き来できるようにするだけです。

## 翻訳できる場所

- **Copilot パネル**——すべてのメッセージヘッダー（自分のメッセージ、モデルの返信、`思考中...` ブロック）に翻訳アイコンがあります。ワンクリックで本文が訳文に置き換わり、もう一度クリックすると原文に戻ります;
- **コミットメッセージの下書き**——Git パネルのコミットボックスは、下書きが複数行になると翻訳ボタンを表示します。下書き全体をその場で翻訳し、もう一度クリックすれば元の文に戻ります;
- **コミット詳細ポップアップ**——Git 履歴でコミットにホバーすると詳細ポップアップが開きます。ハッシュの横の翻訳アイコンでコミットメッセージをあなたの言語に切り替えられます;
- **コードエディターと差分ビュー**——任意の範囲を選択（矩形選択も可）し、右クリックして `翻訳` を選びます。ガターに小さな地球バッジで翻訳済み行が示され、選択範囲の横に訳文カードが開きます。

## 仕組み

1. クライアントはテキストをサーバーに送ります。エディターや差分で選択したテキストの場合はファイル名も添えられ、モデルがそのファイルのコメント構文を知ることができます;
2. サーバーの翻訳 LLM が、Web UI で設定されたターゲット言語へ翻訳します。Markdown 書式（見出し、リスト、表、コードフェンス）は保持され、ファイルの選択範囲では `//` や `#` などのコメントマーカーは装飾と見なされて除去され、コードと識別子はそのまま残ります;
3. クライアントは結果をリクエスト元で Markdown として描画します——チャットメッセージはその場で置き換え、エディターと差分の選択範囲はスクロール可能なカードで表示します。

## 必要なもの

- 翻訳機能を有効にしたサーバー。一度きりの設定は *Server Setup*（Web UI の `LLM` セクション）を参照してください;
- そのサーバーに接続したデスクトップクライアント。クライアント側の設定は一切不要で、すべての画面が同じサーバー設定を自動的に使います。

翻訳が未設定の場合、結果の代わりにサーバーのエラー（訳文カード内など）が表示されます。
