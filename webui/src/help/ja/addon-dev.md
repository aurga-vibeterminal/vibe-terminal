カスタマイズには 2 つのレベルがあります：既存アドオンのソースにパッチを当てるか、内蔵アドオンを参考に新しいものを作ってアップロードするかです。

## ソースのホットパッチ

任意のアドオンカードの鉛筆ボタンで JavaScript ソースを開いて編集します。保存すると元のソースを上書きするスナップショットが保存され —— 内蔵・アップロード問わず —— 変更は再起動なしで即座に反映されます。プロンプトの調整、URL の修正、本番でのアイデアの試行に便利です。

`Reset` はスナップショットを破棄してオリジナルのソースを復元します（内蔵のみ —— アップロード済みアドオンは元々あなたのものです）。

![アドオンのソース編集 —— 保存したスナップショットが元を上書き](images/addon-edit-source.jpg)

## 独自アドオンの作成

アドオンは 2 つのファイルです：

- `<id>.json` —— マニフェスト：`id`、`name`、`description`、`author`、`email`、`date`、`type`、および Web UI がフォームにする `config_fields`（key、label、フィールド型、デフォルト、説明）；
- `<id>.js` —— ソース：プレーンな JavaScript ファイル（組み込み QuickJS エンジンで実行、設定フィールドへの `addon.get_config()` ブリッジを提供）。タイプごとに必要な関数をエクスポートします —— 例：LLM プロバイダーの `chat_completion()`、MCP アドオンのツール一覧とブリッジ呼び出し。

最速の始め方は既存アドオンのエクスポートです：カードの `Export` ボタンでマニフェストとソースを 1 つの zip としてダウンロードできます。目標に最も近い内蔵アドオンを選び（`crates/vterm-server/src/addon/builtins/` にもあります）、id、name、type、エクスポートする関数を書き換え、`Upload Addon` でインストールします。アップロードしたアドオンはゴミ箱ボタンで削除できます。

![アドオンのエクスポート —— マニフェストと JavaScript ソースを 1 つの zip に](images/addon-export.jpg)

## 保存場所

アップロードされたアドオンとソースのスナップショットは、設定ディレクトリの `addons/` フォルダーに `<id>.json` + `<id>.js` として保存され、再起動後も残ります。内蔵 id については `.js` の上書きのみ有効で、内蔵アドオンは独自のマニフェストを保持します。
