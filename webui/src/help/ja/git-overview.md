Git パネルはバージョン管理をクライアントに組み込みます。ステージ、コミット、ブランチ管理、ワークツリー、インタラクティブリベース、競合解決、プッシュを — ターミナルウィンドウを離れずに行えます。すべての操作は現在のターミナルセッションの Git リポジトリに対して行われます。セッションがどのディレクトリで実行されていても、そのリポジトリがパネルに表示されます。

## 開き方

左のアクティビティバーの `Git` タブをクリックします(アクティブなセッションが Git リポジトリ内にある場合のみリポジトリデータが表示されます)。タブのリポジトリはそのアクティブセッションに追従します。リポジトリのパンくずで親子リポジトリ間を移動でき、サブモジュールは別途リストされます。

![Git パネル — 変更、履歴、ブランチ](images/git-overview-panel.jpg)

## できること

- **ステージングとコミット** — ファイル単位または一括のステージ/アンステージ、変更の破棄、メッセージ付きコミット、AI 生成コミットメッセージ(LLM アシストを参照);
- **履歴** — コミット履歴とファイル単位の履歴、リビジョン間の比較と復元;
- **ブランチ** — ローカル/リモートのブランチとタグのチェックアウト、作成、削除;
- **ワークツリー** — ブランチを隔離された作業ツリーにチェックアウト(自動的に新しいターミナルタブが開きます)。完了したらマージして戻します(ワークツリーを参照);
- **インタラクティブリベース** — コミットキューを視覚的に並べ替え/スカッシュ/編集し、競合解決付き(インタラクティブリベースを参照);
- **競合解決** — 4 モードのマージエディタ。ハンクを 1 つずつ解決する AI エージェントを含みます(競合の解決を参照);
- **プッシュ等** — 高機能プッシュダイアログ、スタッシュ、detached HEAD 処理(プッシュ・チェックアウト他を参照)。
