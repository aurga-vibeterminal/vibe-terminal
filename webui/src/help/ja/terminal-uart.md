UART シリアルは、デバイスのシリアルコンソール(デバッグポート、組込みボード、SBC)を、他のターミナルと同じように閲覧・操作できるターミナルタブに変えます。

## ポートの設定

Web UI の `UART` セクション → `Add UART Port`:

- `Name` — ターミナルのタイトルとして表示されます(例:「Debug Console」);
- `Serial Port` — 検出されたポートから選択します(件数はページ上部に表示);
- `Baud Rate` / `Data Bits` / `Parity` / `Stop Bits` / `Flow Control` — デバイスのファームウェアに合わせます;
- `Terminal Type` と `Encoding` — エンコーディングはデフォルトで Auto(UTF-8)。ファームウェアに追従できます;
- `Show Advanced Options` でさらなるシリアルパラメータが現れます。

保存したポートは `Configured UART Ports` リストに表示され、いつでも編集・削除できます。

## クライアントでの使用

設定済みポートは通常のサーバーセッションと同様にターミナルタブとして開きます:

- シリアルデータは到着順に表示され、キーボード入力は直接ポートに送られます;
- 右クリックメニューには `Clear`(画面を空にする)と `Encoding` サブメニュー(エンコーディングをライブ切り替え。現在のものにチェックマーク)があります;
- UART セッションにはシェル機能がありません(クイックコマンド、Apps、Envs メニュー項目なし)。

典型的な用途:ルーター/スイッチのコンソール、組込みボードのログ、フラッシュ治具の監視。
