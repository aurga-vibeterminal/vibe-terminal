リベースやマージで競合に突き当たると、パネルは競合ビューに切り替わります。左に競合ファイルリスト、右にマージエディタ。競合ファイルは `CHANGES` リストにも `!` バッジ付きで現れ、クリックすると通常の diff ではなくこのビューに直接ジャンプします。エディタは 4 つの解決モードを持ち、いつでも切り替えられます。

![競合ビュー — 左にファイルリスト、右にマージエディタ](images/git-conflicts-view.jpg)

## 競合ファイルリスト

ファイルは状態ごとにグループ化されます。自動マージに成功したもの(自動ステージ済み)と、まだ手動対応が必要なものです。ファイルをクリックしてエディタで開きます。解決が進むにつれてリストはライブ更新され、空になるまで続きます。

## 4 つの解決モード

- **Merge**(デフォルト)— 競合がハンクごとに提示されます。ハンクごとに `take ours` / `take theirs` を選ぶか、マージ結果をインライン編集;
- **Split** — diff をより細かい行レベルのセグメントに分解し、1 つのハンク内で両側を少しずつ採用できます;
- **Raw** — `diff3` 競合マーカー(`<<<<<<<` / `=======` / `>>>>>>>`)付きの素の編集。手動調整用;
- **AI** — エージェントがファイルをハンクごとに解決します。LLM が各競合ハンクを分析し、説明と信頼度付きのソリューションカードを生成します。指示を入力して戦略を導いたり(例:「相手側優先、ログ文は保持」)、一時停止して別モードで微調整し、再開できます — 解決済みハンクはスキップされます。

どのモードでも、解決はセッション内のファイルに書き込まれ、ステージされます。手動編集とまったく同じです。

## リベースの続行

すべての競合が解決されると、リベースは次のコミットへ進みます。いつでも中止して、リベース前の状態に戻ることもできます。
