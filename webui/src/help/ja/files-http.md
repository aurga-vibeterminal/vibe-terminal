`Host with HTTP server` は、サーバー上の任意のディレクトリをワンクリックで HTTP ファイルサービスとして公開します。同じネットワーク(またはリレー経由)の他のデバイス — スマホ、別のパソコン、テスト機 — がブラウザからそのディレクトリを閲覧・ダウンロードできます。ビルド成果物やログの束を共有したり、クライアント未導入のデバイスにファイルを渡すのに理想的です。

## 使い方

3 つの入口があり、すべてディレクトリに対してです。ファイルリストの右クリックメニュー、Recent エントリの右クリックメニュー、パンくずの右クリックメニュー → `Host with HTTP server`。

クリックすると:

1. サーバーはそのディレクトリをルートとする静的 HTTP サービスを開始します。ポートは Static HTTP ポート範囲から採番されます;
2. **ローカルサーバー**: `http://127.0.0.1:port/` URL がクリップボードに直接コピーされ、「HTTP server: … (クリップボードにコピー)」というステータスメッセージが表示されます;
3. **リモートサーバー**(リレー経由で接続):クライアントは自動的にリバースプロキシマッピングを要求し、外部から到達可能な共有 URL をコピーします — LAN の制限は障害になりません。

任意のデバイスのブラウザでその URL を開くと、ディレクトリが通常の Web 一覧のように閲覧・ダウンロードできます。

## 実行中サービスの管理

各 HTTP サービスは停止されるまで動作し続けます:

- Web UI の `Static HTTP` セクションを開くと、`Services` リストに実行中のすべてのサービスとそのドキュメントルートが表示されます;
- 各エントリに停止ボタンがあります。ポート範囲は同じページで設定します。

> このサービスは読み取り専用のファイル一覧です — 書き込みエンドポイントはありません。ディレクトリの内容は変更に合わせてライブで見えるため、継続的に生成されるログや成果物に適しています。
