環境変数機能では、プロジェクトごと(`ANDROID_HOME`、API キー、プロキシ設定)にグループ化された変数セットを管理し、任意のターミナルセッションにワンクリックで適用・クリアできます。設定はサーバー設定に保存され、値は保存時に暗号化されます。

## Web UI での管理

`Environment Variables` セクションはツリー形式で整理されます:

- **グループ** — 純粋なコンテナでネスト可能(右クリック → `New Group`)。プロジェクトやシナリオごとの整理に;
- **コレクション** — ツリーの葉であり、実際の変数の保持者です(`New Leaf`)。ターミナルに適用できるのはコレクションのみです;
- 各コレクションのキー/バリューは `Edit Variables` で編集します(`Add Variable`)。値はデフォルトで隠されています;
- コレクションは複製して派生バリアントを作れます(1 つのキーだけ変えた同じセット)。

![環境変数ページ — グループ/コレクションツリー](images/terminal-env-tree.jpg)

## ターミナルへの適用

ターミナル内で右クリック → `Envs`:

- サブメニューは Web UI のツリーを反映します。コレクションを展開して `Apply` を選ぶと変数が現在のセッションに注入され、`Clear` で再び除去されます;
- 新しく起動したプロセスは変数を見られます(既に実行中のフォアグラウンドプログラムは見られません);
- コレクションはグループの下に折りたたまれて表示されます。ツリーにコレクションがない間は `Envs` 項目全体が非表示になります。
