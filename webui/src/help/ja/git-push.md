ブランチリストの右クリックメニューに、プッシュ、チェックアウト、日常のブランチ操作が集約されています。

## プッシュ

ブランチを右クリック → `Push '{branch}'...` でプッシュダイアログを開きます:

![ブランチ右クリック — Push エントリ](images/git-push-contextmenu.jpg)

- `local → remote` の対象マッピングを表示します。どちらの名前も変更できます(既存のリモートブランチに別名でプッシュする場合は確認を求めます);
- オプション: `Push all branches`、`Set upstream`(初回プッシュでアップストリームをバインド)、`Push tags`、`Dry run`;
- 履歴を書き換える `Force` と、より安全な `Force with lease`(他人がプッシュ済みなら拒否 — 推奨)。リベース後のプッシュなど、履歴を書き換える操作にはこれらのいずれかが必要です;
- ダイアログには強制プッシュのリスクヒントが表示されます。

![プッシュダイアログ — local → remote 対象とオプションチェックボックス](images/git-push-dialog.jpg)

## チェックアウト

ブランチを右クリック → `Checkout` でブランチを切り替えます — ローカルブランチは直接チェックアウトされ、リモートブランチやタグはチェックアウトダイアログを開きます:

![ブランチ右クリック — Checkout エントリ](images/git-checkout-contextmenu.jpg)

- `New branch name` — 作成するローカルブランチ。ref から事前入力されます;
- `Create new local branch`(`-B`)、`Track remote as upstream`(`--track`、リモートブランチのみ)、`Force`(`-f`)、`Merge`(`--merge`)。

![チェックアウトダイアログ — ブランチ名とオプション](images/git-checkout-dialog.jpg)

セッションの作業ディレクトリは切り替えに追従し、ターミナルと Git パネルはすぐに新しいブランチを反映します。

## Detached HEAD

素のコミットをチェックアウトすると(履歴閲覧中にコミットをチェックアウトするなど)、HEAD がデタッチされます。次のコミット時に `Detached HEAD` ダイアログが開きます:コミット先の既存ブランチを選ぶか、その場で `+ Create new branch…`、または今は `Skip` します。

## その他の操作

- **スタッシュ** — 変更ヘッダーからすべての変更をスタックにスタッシュ(メッセージはオプション)。`STASHES` リストは `Pop`(適用して削除)と `Drop`(破棄、不可逆)をサポートします;
- **ブランチ/ワークツリーの削除** — エントリの右クリックメニューから。どちらも不可逆操作の確認付き;
- **履歴と復元** — `HISTORY` がコミットを一覧表示。右クリックでファイル履歴、作業ツリーとの diff、リビジョンへの復元;
- **コピー** — ブランチ名とコミットハッシュをワンクリックでコピー。エージェントや同僚への貼り付けに便利です。
