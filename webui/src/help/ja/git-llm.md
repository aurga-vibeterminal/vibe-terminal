Git パネルの知能は LLM 駆動です。ワンクリックのコミットメッセージ、AI アシストによる diff 読解、ハンクごとのエージェント競合解決。すべて Web UI で設定された LLM プロバイダーに依存します。

## プロバイダーの設定

Web UI の `LLM` セクションを開きます:

- `Provider` を選び認証情報を入力します(フィールドはプロバイダーのマニフェストで定義されます)。設定はグローバルで、ターミナル分類、Git コミットメッセージ、チャットアシスタントなど AI 機能が同じプロバイダーを共有します;
- プロバイダーは LLM タイプのアドオンです。主要なものは内蔵されており、カスタムプロバイダーは `Addons` セクションで zip としてアップロードできます(マニフェストが設定フィールドを宣言し、Web UI がフォームに変換します)。

![Web UI の LLM セクション — プロバイダーを選び認証情報を入力](images/git-llm-provider-config.jpg)

## Git の LLM 機能

- **コミットメッセージ生成** — コミットボックス横の AI ボタンをクリックすると、LLM がステージされた diff を読んでメッセージを書き、アニメーション付きでボックスに入力されます。メッセージは編集可能のままです。納得してからコミットしてください;
- **diff 分析** — diff ビューヘッダーのスパークルボタンが現在の diff を分析します;
- **競合 AI エージェント** — リベースのマージエディタの AI モードが、説明と信頼度付きでハンクを 1 つずつ解決します(競合の解決を参照)。

![コミットボックスに入力される AI 生成コミットメッセージ](images/git-llm-commit-message.jpg)

> LLM はテキストを生成するためにのみリポジトリ内容を読みます。コミットやマージは、必ずあなたが確認したときにのみ行われます。
