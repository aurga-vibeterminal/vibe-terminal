Git パネルの `CHANGES` 領域は日常のコミットループをカバーします。変更の確認、ステージ、破棄、スタッシュ、メッセージ付きコミット。

## ステージとアンステージ

- 未ステージの変更は `CHANGES` の下にリストされ、各ファイルにステータスバッジが付きます — `M` 変更、`A` 追加、`D` 削除、`?` 未追跡、`!` 競合(サブモジュール行には追加で `SUB` タグ);
- 行にホバーするとインライン操作ボタンが現れます。`+` は未ステージファイルをステージ、`−` はステージ済みをアンステージ、未ステージ行の `×` は破棄します。セクションヘッダーの `Stage All Changes` / `Unstage All Changes` ボタンで一括処理できます;
- `Ctrl` クリックでファイルを複数選択にトグル、`Shift` クリックで範囲選択 — 操作ボタンが選択したすべてのファイルに適用されます;
- ファイル名をクリックすると diff が開き、決める前に変更を確認できます;
- ファイルの右クリックには `View File History`、`Stash This File`、`Copy Full Path` / `Copy Relative Path`、`Reveal in File Explorer`、ターミナルをファイルのフォルダへジャンプさせる `cd` ショートカットがあります。

![STAGED CHANGES セクション — 行ごとの Unstage ボタン付きステージ済みファイル](images/git-staging-staged.jpg)

## コミット

1. 含めるべきものをステージ;
2. コミットボックスにメッセージを入力(`Ctrl+Enter` でコミット)するか、AI ボタンで生成(LLM アシストを参照);
3. `Commit` をクリック。

![コミットボックス — AI 生成ボタン付きメッセージ入力](images/git-staging-commit.jpg)

コミット後、履歴ヘッダー(コミット履歴の上のブランチ名付きバー)にホバーすると、右側に `Fetch`、`Pull`、`Push` ボタンがフェードインします。`Push` は現在のブランチを即座にアップストリームへ送ります。`Force with lease` などのオプションには、ブランチリストのプッシュダイアログを使ってください(プッシュ・チェックアウト他を参照)。

![履歴ヘッダーのホバーで Fetch、Pull、Push ボタンが現れる](images/git-staging-push.jpg)

## スタッシュ

- `CHANGES` ヘッダーのアーカイブボタンで `Stash All Changes` ダイアログが開き、オプションのメッセージでスタッシュを説明できます;
- 未ステージの選択ファイルの右クリックには `Stash This File`(複数選択時は `Stash <n> Selected Files`)があり、それらのパスだけをスタッシュします — サブモジュール行は除外されます;
- スタッシュは `STASHES` の下に `WIP on <branch>` エントリとして集まります。展開すると捕捉したファイルがリストされ、ファイルをクリックすると diff が表示されます;
- スタッシュ行にホバーすると `Apply`(復元して保持)、`Pop`(適用して削除)、`Drop`(適用せず削除)が現れます — `Pop` と `Drop` は先に確認を求め、右クリックメニューには `View Diff` もあります;
- スタッシュリストが空の間は `STASHES` セクションは非表示のままです。

## 破棄

未ステージファイルの `Discard Changes` は、その中の未コミット変更をすべて捨てます。確認ダイアログがあり、この操作は**元に戻せません**。

> コミットにはステージされた内容のみが含まれます。未ステージの変更は作業ツリーに残ります。
