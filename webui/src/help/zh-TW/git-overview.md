Git 面板把版本控制做進用戶端：不離開終端機視窗就能完成暫存、提交、分支管理、worktree、互動式 rebase、衝突解決和推送。所有操作作用於目前終端機工作階段所在的 Git 儲存庫——在哪個目錄開的終端機，面板就顯示哪個儲存庫。

## 開啟

點擊左側活動欄的 `Git` 分頁（僅當活動工作階段位於 Git 儲存庫中時顯示儲存庫資料）。分頁的儲存庫由其活動工作階段決定；透過儲存庫階層連結可在父/子儲存庫間跳轉，子模組會單獨列出。

![Git 面板全貌 —— 變更、歷史與分支](images/git-overview-panel.jpg)

## 能做什麼

- **暫存與提交**：逐檔案或批次 stage/unstage、放棄變更、寫訊息提交，支援 AI 產生提交訊息（見「LLM 輔助」）；
- **歷史**：提交歷史與單檔案歷史，任意兩個版本的對比、回退；
- **分支**：本地/遠端分支與標籤的切換（Checkout）、新增、刪除；
- **Worktree**：為分支建立獨立工作樹（自動開新終端機分頁），完成後合併回主分支再刪除（見「Worktree 工作樹」）；
- **互動式 Rebase**：視覺化重排/合併/編輯提交佇列，衝突視覺化解決（見「互動式 Rebase」）；
- **衝突解決**：四種模式的合併編輯器，包括逐塊 AI 代理解決（見「解決衝突」）；
- **推送與雜項**：帶完整選項的 Push 對話方塊、Stash、Detached HEAD 處理（見「Push、Checkout 與更多」）。
