在終端機裡執行程式碼 Agent（Claude Code、Codex、Kimi、Pi、OpenCode 等）時，它們的對話被困在那個終端機視窗裡——捲動歷史混在命令輸出中，換屏就看不到了。`Code Agent 會話歷史`把 Agent 的完整對話提取到一個專用面板：結構化展示每一輪問答、可切換歷史會話、支援翻譯，還能從面板直接向終端機發命令。

## 開啟面板

點擊標題列右側的聊天（`AI`）按鈕切換 Copilot 面板；面板頂部的下拉列出目前終端機工作階段中 Agent 的**全部歷史會話**，按時間排序，選中即載入。

## 工作原理

- 伺服器知道目前終端機裡執行著哪個 Agent 應用，並解析其**原生會話檔案**（各 Agent 的 JSONL/歷史格式，位於其專案目錄）；會話檔案變化時即時推送增量，對話流隨之捲動更新；
- 支援的 Agent：`claude` / `codex` / `kimi` / `pi` / `opencode`；其他應用暫無會話面板；
- 訊息區分角色（你 / Agent）與類型（正文 / **Thinking** 推理過程），顯示模型名稱與時間，Markdown 渲染。

## 面板能力

- **切換會話**：頂部 `Conversations` 下拉在多個歷史會話間切換，每項顯示內容摘要與時間；
- **翻譯**：每條 Agent 訊息可請求翻譯，譯文就地替換原文（可切回）；
- **直接發命令**：底部輸入框輸入內容（Shift+Enter 換行）按 Enter，命令直接送入目前終端機——像在 Agent 的輸入框裡打字一樣，但不佔用終端機檢視。

## 與其他功能的關係

- 面板與終端機是同一工作階段的兩個檢視：Agent 在終端機裡的提問仍然透過終端機回答（或配合「自動確認」）；面板負責回看歷史，不截獲互動；
- 結合 `Terminal MCP`（見前一篇），外部 Agent 也能讀取終端機螢幕與執行命令——面板展示的對話與 MCP 操作共同構成完整的 Agent 工作記錄。
