Web 介面是伺服器自身的設定頁面：伺服器的每項功能都歸入一個分區，列於左側側邊欄。它不是終端機——日常工作在桌面用戶端或 `vtermc` 中進行（見「功能總覽」）。本頁說明整體版面與共通操作方式；各功能章節會詳細介紹每個分區的設定。

## 版面配置

- **側邊欄**——分區清單（見下文）、伺服器名稱旁的說明圖示，以及底部的應用程式版本；在窄螢幕上它從左側滑入，由頁首的漢堡按鈕切換；
- **頁首**——目前分區的標題，右上方為語言選擇器與淺色/深色切換（在窄螢幕上，說明圖示也在此處）；
- **內容**——所選分區的表單，置中且可捲動。

## 分區

依側邊欄順序：

- `伺服器`——連接埠、TLS 憑證與驗證設定：`金鑰`、配對 `QR Code`、中繼位址與`登入時自動啟動`開關都在此處（見「用戶端配對」與「設定指南」）。在 Linux 上，自動啟動提示還會說明顯示管理器的自動登入設定，用於在本機登入前進入桌面（見遠端桌面與模擬器章節的「伺服器設定」）；
- `Terminal`——終端機分析：提示偵測、自動確認與 LLM 分類（見「自動確認」）；
- `UART`——以本機 UART 埠為後端的串列終端機 Profile（見「UART 串列埠」）；
- `附加元件`——已安裝的附加元件：可啟用、編輯或上傳（LLM 提供者也是附加元件——見「LLM 大模型」）；
- `LLM`——為每項 AI 功能指派 LLM 提供者（見「LLM 大模型」）；
- `語音`——語音辨識的提供者、模型與轉錄設定（見語音輸入章節的「伺服器設定」）；
- `環境變數`——以群組樹狀結構組織的環境變數集合（見「環境變數」）；
- `MCP`——暴露給 Code Agent 的終端機 MCP 伺服器（見「Terminal MCP」）；
- `DDNS`——DDNS 提供者與同步設定（見「DDNS 動態網域」）；
- `連接埠轉發`——轉發連接埠池與目前生效的 TLS 轉發（見「連接埠轉發」）；
- `靜態 HTTP`——透過 HTTP 託管的目錄與目前生效的檔案分享（見「HTTP 檔案服務」）；
- `遠端桌面`——遠端桌面的擷取、輸入與串流設定（見遠端桌面與模擬器章節的「伺服器設定」）；
- `LLM 統計`——所有 LLM 功能的 Token 用量、請求次數與效能指標。

## 儲存與小提示

- 多數分區會在編輯後不久自動儲存——儲存指示器與任何錯誤都顯示在分區底部；
- `MCP`、`DDNS` 與 `Remote Desktop` 會暫存編輯內容，直到按下 `儲存變更`：編輯未送出時，按鈕旁會出現 `有未儲存的變更` 提示，`重設` 則會捨棄這些變更；
- 從行動用戶端開啟時，Web 介面會跟隨 App 的語言與主題，並隱藏自身的語言與主題控制項。
