中繼（relay）解決一個問題：多數機器藏身在 NAT 或動態 IP 之後，用戶端無法逐一直連。讓一台公網可連線的機器擔任中繼入口，其餘機器主動向它撥號；用戶端只需與中繼保持一條連線，就能使用所有共享伺服器的終端機。

## 架構

![中繼架構 —— 用戶端與中繼保持一條連線，各共享伺服器向上游中繼撥號](diagram/relay)

- **中繼伺服器（relay server）**：公網入口，用戶端與共享伺服器都連向它。它的 `中繼位址` 留空。
- **共享伺服器（shared server）**：`中繼位址` 指向中繼的機器，向上游撥號並把自身終端機共享出去。圖中每個共享節點左側的彩色豎條對應桌面用戶端分頁上的同色標記——每種顏色代表一台伺服器。
- 連線方向永遠由內向外：共享伺服器主動連線中繼，無需任何埠轉發或公網 IP。

## 用戶端看到什麼

連上中繼後，每台共享伺服器如同本機一般可用：

- 終端機分頁帶彩色豎條與遠端系統圖示，一眼區分是哪台機器（見設定指南）；
- Profile 選單按伺服器分組，可直接在任何機器上開啟終端機；
- 分頁分組可以整組撕到獨立視窗，為某台機器單獨分配一個視窗。

## 安全模型

用戶端與共享伺服器使用同一把金鑰配對，連線經中繼隧道轉發；金鑰隨配對 QR Code / 分享字串傳遞，憑證不以明文落地。
