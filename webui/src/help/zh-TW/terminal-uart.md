UART 串列埠把裝置的序列主控台（偵錯埠、嵌入式板卡、單板電腦）變成一個終端機分頁，在用戶端裡像普通終端機一樣檢視與互動。

## 設定連接埠

Web 介面的 `UART` 設定頁 → `新增 UART 連接埠`：

- `名稱`：顯示在終端機裡的名稱（如「偵錯主控台」）；
- `序列埠`：從偵測到的序列埠清單中選擇（頁面頂部顯示偵測數量）；
- `鮑率` / `資料位元` / `同位校驗` / `停止位元` / `流量控制`：與裝置韌體一致；
- `終端機類型` 與 `編碼`：編碼預設自動（UTF-8），可按裝置韌體選擇；
- `顯示進階選項`裡有更多序列埠參數。

儲存後連接埠出現在`已設定 UART 連接埠`清單，可隨時編輯或刪除。

## 在用戶端使用

設定好的連接埠像普通伺服器工作階段一樣開啟為終端機分頁：

- 序列資料即時呈現，鍵盤輸入直接送往序列埠；
- 右鍵選單提供`清除`（清屏）與 `Encoding` 子選單（執行中切換編碼，目前項帶 ✓）；
- 序列埠工作階段沒有 Shell 相關能力（快速命令、應用、環境變數選單不會出現）。

典型用途：路由器/交換器主控台、嵌入式開發板日誌、燒錄治具監視。
