Git 面板的智慧化能力由 LLM 驅動：一鍵產生提交訊息、AI 輔助理解差異、在 rebase 衝突中逐塊代理解決。這些都依賴在 Web 介面設定好的 LLM 提供商。

## 設定提供商

開啟 Web 介面的 `LLM 配置` 頁：

- `提供商` 選擇一個 LLM 後端並填入憑證（金鑰等欄位由提供商的清單定義）；這裡的設定是全域的——終端機分類、Git 提交訊息、聊天助理等共用同一提供商；
- 提供商本身是 LLM 類型的外掛：內建了常用提供商，自訂提供商可以在`外掛`頁面上傳 zip 安裝（清單宣告設定欄位，Web 介面據此自動產生表單）。

![Web 介面 LLM 設定頁 —— 選擇提供商並填寫憑證](images/git-llm-provider-config.jpg)

## Git 中的 LLM 能力

- **產生提交訊息**：在 Git 面板的提交框旁點擊 AI 按鈕，LLM 讀取本次暫存的差異產生提交訊息，以打字動畫填入輸入框；訊息始終可編輯，確認後再提交；
- **差異 AI 分析**：差異檢視頭部的星光按鈕觸發對目前 diff 的分析解讀；
- **衝突 AI 代理**：rebase 衝突的合併編輯器提供 AI 模式，逐塊解釋並解決衝突（含信心度），詳見「解決衝突」。

![AI 產生的提交訊息填入提交框](images/git-llm-commit-message.jpg)

> LLM 只讀取儲存庫內容用於產生文字；提交與合併動作始終由你確認觸發。
