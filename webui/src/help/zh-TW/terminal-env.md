環境變數功能讓你為不同專案維護成組的變數（如 `ANDROID_HOME`、API 金鑰、代理設定），在任意終端機工作階段中一鍵套用或清除。變數儲存在伺服器設定中，值落盤前加密。

## 在 Web 介面維護

`環境變數`設定頁以樹狀組織：

- **分組**：純容器，可嵌套（右鍵 →`新增分組`），用於按專案/場景歸類；
- **集合**：樹中的葉子，真正的變數載體（`新增集合`）——只有集合能套用到終端機；
- 每個集合透過`編輯變數`維護鍵值對（`新增變數`），值預設隱藏顯示；
- 集合支援複製，方便衍生變體（如同一組變數只改一個金鑰）。

## 套用到終端機

在終端機內右鍵 → `環境`：

- 子選單按 Web 介面裡的樹狀結構展示；展開某個集合，選擇`套用`把變數注入目前工作階段，`清除`則把該集合的變數從工作階段中移除；
- 套用後新啟動的處理程序都能讀到這些變數（對已在前台執行的程式無效）；
- 集合在選單中按分組摺疊展示，樹裡沒有集合時整個`環境`選單項目隱藏。
