伺服器端終端機分析器持續觀察終端機輸出：識別命令提示、偵測任務完成，並在配合 LLM 時對輸出進行分類。「自動確認」是其中最常用的能力——當終端機停在普通的確認提示（如 `Proceed? [Y/n]`）時，自動替你按下 Enter，長時間任務不再卡在詢問上。

## 設定

Web 介面的`終端分析`設定頁：

- `終端觀察器`：總開關，啟用伺服器端終端機分析；
- `自動確認`：只對被分類為**普通確認**的提示自動發送 Enter，不會盲目應答其他提問；
- `延遲分析時間（秒）`：Agent 進入閒置後等待多久再分析，避免連續任務之間產生多餘的 LLM 請求；
- `確認寬限期（秒）`：偵測到確認提示後等待使用者接管的寬限時間；
- `完成通知`：輸出被分類為任務完成時發送事件（可接入通知渠道）。

> 頁面提示：Agent 自身的自動模式開啟時，建議在用戶端關閉「自動確認」，避免兩套自動化互相搶答。

## 依賴 LLM

提示的分類由 LLM 完成：在 `LLM 配置`頁選擇`提供商`並填好憑證（配置用於終端機分類、Git 提交訊息、聊天助理等全部 LLM 功能）。未設定 LLM 時，分析器仍可運作，但分類精度下降，自動確認建議保持關閉。
