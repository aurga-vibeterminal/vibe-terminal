## 衝突檔案清單

按狀態分組：自動合併成功的檔案（自動暫存）與仍需手動處理的檔案。點擊檔案進入編輯器；解決一個，清單即時更新，直到清空。

## 四種解決模式

- **Merge**（預設）：衝突按塊（hunk）呈現，逐塊選擇`採用 ours` / `採用 theirs` / 手動編輯合併結果，所見即所得；
- **Split**：把 diff 拆成更細的行級片段，同一塊裡可以分段採納雙方；
- **Raw**：帶 `diff3` 衝突標記（`<<<<<<<` / `=======` / `>>>>>>>`）的原文編輯，適合手工精修；
- **AI**：逐塊代理解決——LLM 分析每塊衝突，給出解決方案、解釋與信心度卡片；可以輸入指令約束解決策略（如「以 theirs 為主，保留日誌語句」），支援暫停後在其他模式微調再繼續，已解決的塊自動跳過。

所有模式下，解決結果都直接寫入工作階段中的檔案並暫存，與手動編輯無異。

## 與 rebase 的銜接

衝突全部解決後，繼續執行 rebase 的下一個提交；若想放棄整個變基，隨時可以中止回到變基前的狀態。
