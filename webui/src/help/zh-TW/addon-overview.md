附加元件（Addon）在不更動核心的前提下為伺服器擴充新能力：LLM 提供者、語音辨識後端、動態 DNS 更新器、額外的 MCP 工具面，以及 Code Agent 應用偵測，都以附加元件形式存在。Web UI 的 `Addons` 區塊負責管理它們。

## 類別

每個附加元件宣告一個類型，區塊按類型分組展示卡片：

- **Applications（應用程式）** —— 教終端機觀察器識別一個 Code Agent CLI（內建 Claude Code、Codex、Kimi Code、Pi、OpenCode）：程序偵測、忙碌/閒置狀態、自動化掛鉤；
- **LLM Providers（LLM 提供者）** —— 供 AI 功能選擇的對話補全後端（內建 OpenAI 相容提供者）；
- **Voice / ASR（語音辨識）** —— 語音辨識後端（內建 `vibe-voice` 附加元件指向被守護的本機 ASR 伺服器）；
- **Dynamic DNS（動態 DNS）** —— 讓網域始終指向目前位址（內建 Cloudflare）；
- **MCP** —— 在 MCP 宿主上額外提供的 MCP 工具面（內建 EasyEDA Pro）；
- 其餘類型歸入 **Other（其他）** 群組。

## 內建與上傳的附加元件

- **內建（Built-in）** 附加元件隨程式發布，始終可用。其清單與原始碼保持原始狀態 —— 被覆寫的原始碼隨時可以還原；
- **上傳（Uploaded）** 附加元件是你自己的：一個包含清單和 JavaScript 原始碼的 zip 包，透過 `Upload Addon`（上傳附加元件）按鈕安裝；
- `Modified`（已修改）徽章表示該附加元件的原始碼被你覆寫過。

每張卡片顯示附加元件類型、徽章和啟用開關；展開後顯示描述、作者、設定欄位和原始碼。

## 設定

附加元件的清單宣告其設定欄位，展開的卡片會把它們渲染成表單。設定按附加元件儲存，僅在啟用時生效；密碼類欄位保持遮罩顯示。關閉附加元件會保留其設定，重新啟用後繼續沿用。
