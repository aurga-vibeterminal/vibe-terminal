`Host with HTTP server` 把伺服器上的任意目錄一鍵發布為 HTTP 檔案服務：同一區網（或經中繼）的其他裝置——手機、另一台電腦、測試機——用瀏覽器就能瀏覽和下載該目錄下的檔案。適合臨時分享建置產物、日誌包，或給沒有安裝用戶端的裝置遞檔案。

## 使用方式

三種入口都在目錄上：`檔案清單`右鍵、`Recent` 項目右鍵、麵包屑右鍵 → `Host with HTTP server`。

點擊後：

1. 伺服器在該目錄上啟動靜態 HTTP 服務，連接埠從 Static HTTP 的連接埠區間中分配；
2. **本地伺服器**：服務的 `http://127.0.0.1:連接埠/` 位址直接複製到剪貼簿，狀態列提示 "HTTP server: …(copied to clipboard)"；
3. **遠端伺服器**（經中繼連線）：用戶端自動請求一條反向代理映射，拿到可從外部存取的分享 URL 再複製——區網限制不再是障礙。

之後在任何裝置的瀏覽器開啟該 URL，即可像普通網頁目錄一樣瀏覽、下載檔案。

## 管理已啟動的服務

每個 HTTP 服務會持續執行，直到手動停止：

- 開啟 Web 介面的`靜態 HTTP`設定頁，`Services` 清單列出所有正在執行的服務及其根目錄；
- 每條記錄有停止按鈕；連接埠區間也可在該頁配置。

> 該服務是唯讀的檔案瀏覽，不會暴露寫入介面；目錄內容變化即時可見，適合持續產出日誌/產物的場景。
