Сервер має вбудований хост Model Context Protocol, а розділ `MCP` веб-інтерфейсу його налаштовує: код-агенти (Claude Code, Codex, Kimi Code, Pi, OpenCode, Qwen Code, DeepSeek Harness, …) можуть під'єднуватися з власного чату й працювати просто на вашій машині — читати та керувати терміналами та навіть керувати EasyEDA Pro.

## Налаштування сервера

Увімкніть MCP-сервер і налаштуйте:

- `Port` (типово `6180`) і `Bind Address` — `127.0.0.1` тримає ендпоінт лише на localhost; `0.0.0.0` відкриває його в мережу;
- `Access Token` — обов'язковий для запитів не з localhost: віддалені викликівці мають пред'являти його як Bearer-токен, а запити з localhost завжди пропускаються. Він ніколи не порожній — нове встановлення постачає випадковий токен; кістка перегенеровує його, кнопка копіювання видає;
- `Stream Throttle` — мінімальний інтервал між виштовхуваннями екранного потоку під'єднаним агентам.

Зміни набирають чинності після `Save`; сервер перезавантажується на льоту без рестарту.

## Ендпоінти

Кожен набір можливостей обслуговується за власною адресою `http://localhost:{port}/{id}/mcp`:

- **Terminal MCP** (`/terminal/mcp`) — вбудована термінальна поверхня. Агенти можуть перелічувати термінали, читати видимий екран і прокрутку, вводити сирий текст і названі клавіші, змінювати розмір і чекати на запрошення. Виклики інструментів адресують термінал за його Terminal ID — правий клік по терміналу → `MCP` → `Copy Terminal ID` і вставте ID у контекст агента (див. Terminal MCP у розділі Terminals);
- **EasyEDA Pro MCP** (`/easyeda/mcp`) — вбудований MCP-аддон, що мостить EasyEDA Pro до агентів: невеликий фіксований набір інструментів плюс каталог викликів `eda.*` із пошуком, що пересилається розширенню-конектору EasyEDA через WebSocket. Спершу увімкніть аддон у розділі `Addons` — його ендпоїнт з'явиться в списку після встановлення, а значок покаже, чи під'єднаний демон аддона. Поле `Timeout` аддона обмежує кожен містковий запит (збільште для повільних операцій EDA);
- **Інші MCP-аддони** — будь-який встановлений аддон типу MCP додає свій ендпоїнт так само, кожен зі значком під'єднано/від'єднано наживо.

Оберіть CLI агента у спадному списку над переліком; кнопка копіювання біля ендпоїнту видасть готову до запуску команду налаштування для цієї програми.

## Під'єднання агента

Токен ніколи не вставляється вручну. Сервер веде згенерований профіль середовища `Vibe Terminal MCP Bearer Token` (див. розділ Environment Variables), що експортує `VTERM_MCP_TOKEN`; застосуйте його до терміналу перед під'єднанням агента, а потім використайте скоповану команду:

- **Програми з shell-командою** (Claude Code, Codex) — виконайте скоповану команду `mcp add` у звичайному терміналі. Codex читає токен зі `VTERM_MCP_TOKEN` через `--bearer-token-env-var`, тож секрет не потрапляє в командний рядок;
- **Діалогові програми** (Kimi Code, Pi, OpenCode, Qwen Code, DeepSeek Harness) — запустіть програму із застосованим профілем і надішліть скопований промпт у її розмову. Агент безпосередньо оновить конфігурацію MCP. Kimi використовує `bearerTokenEnvVar`; Pi, OpenCode і Qwen Code використовують Bearer-токен з `VTERM_MCP_TOKEN`, тому сам токен ніколи не з'являється в чаті.

У Pi і Qwen Code `/mcp` оглядає з'єднання.

Картка `Command Templates` під налаштуваннями зберігає команди налаштування за програмами: редагуйте записи, перевизначайте вбудовані або додавайте шаблони для нових CLI — перегляд показує саме те, що видасть кнопка копіювання.
