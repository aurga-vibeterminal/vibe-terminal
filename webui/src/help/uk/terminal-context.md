Код-агенти (Claude Code, Codex, Kimi, Pi, OpenCode…) знають лише те, що досягає їхнього входу. `Додавання контексту` — спосіб вручити їм шляхи файлів і фрагменти коду без перепечатування: перетягніть файли з `Explorer`, або перетягніть виділений текст з редактора коду і вигляду diff Git просто в термінал агента або ввід чату Copilot.

## Перетягування файлів

Натисніть файл — або множинний вибір — у списку файлів `Explorer` і перетягніть його:

- **На термінал**: повні шляхи друкується в точці відпускання, розділені пробілами, готові стати частиною вашого наступного промпту агентові;
- **На ввід чату Copilot**: шляхи вставляються в чернетку повідомлення, по одному на рядок, щоб зібрати багатофайловий промпт перед надсиланням.

Шляхи, перетягнуті з файлового менеджера ОС і відпущені на термінал, автоматично беруться в лапки, тож імена з пробілами виживають недоторканими.

## Перетягування виділеного коду як контексту

Виділіть текст у редакторі коду або в diff Git, потім натисніть саме виділення і перетягніть його на термінал:

- коли термінал **запускає код-агент**, відпускання вставляє *блок контексту* — шлях файлу, діапазон рядків і фрагмент, обгорнутий у кодову огорожу:

````text
File: crates/vterm/src/ui/terminal_view.rs
Lines: 558-566
```
fn can_accept_native_drop(&self, info: &DndInfo) -> bool { … }
```
````

- коли термінал на **звичайному запиті shell**, відпускання друкує виділений текст натомість, тож той самий жест працює і для звичайних команд;
- коли diff переглядається на конкретному коміті, блок додатково несе рядок `Commit:`, пришпилюючи точну ревізію.

![Перетягування виділення редактора в термінал агента опускає блок контексту File/Lines](images/terminal-context-drag-selection.mp4)

## Копіювання контексту

Той самий блок живе в контекстному меню: `Copy Context` у редакторі коду і вигляді diff копіює його в буфер обміну. Вставте у ввід чату Copilot — або будь-якому іншому агенту — коли перетягування незручне. Анімація вище показує блок, що вийшов, у вводі агента.

## Поради

- Множинний вибір у `Explorer`, щоб опустити кілька шляхів одразу;
- ввід чату Copilot надсилається прямо в термінал як надрукований текст (див. `Історія код-агента`), тож контекст, доданий там, досягає агента точно так, ніби ви його надрукували;
- поєднайте з `Автопідтвердженням`, щоб агент діяв за опущеним контекстом без зайвих запитів.
