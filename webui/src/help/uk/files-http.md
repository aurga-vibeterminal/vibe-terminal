`Host with HTTP server` публікує будь-яку директорію на сервері як HTTP-файлову службу одним кліком: інші пристрої в тій самій мережі (або через реле) — телефон, інший комп'ютер, тестовий стенд — можуть оглядати й завантажувати цю директорію з браузера. Ідеально для обміну артефактами збірок і пакунками логів, або передавання файлів пристроям без установленого клієнта.

## Як користуватися

Три входи, усі на директорії: контекстне меню списку файлів, контекстне меню запису Recent і контекстне меню навігаційних крихт → `Host with HTTP server`.

Клацання:

1. Сервер запускає статичну HTTP-службу, вкорінену в цій директорії, з портом із діапазону портів Static HTTP;
2. **Локальний сервер**: URL `http://127.0.0.1:port/` копіюється просто в буфер обміну, з повідомленням стану «HTTP server: … (скопійовано в буфер обміну)»;
3. **Віддалений сервер** (з'єднаний через реле): клієнт автоматично просить відображення зворотного проксі й копіює зовнішньо досяжну URL спільного доступу — обмеження LAN не перешкода.

Відкрийте цю URL у браузері будь-якого пристрою, і директорія оглядається та завантажується як звичайний веб-список.

## Керування працюючими службами

Кожна HTTP-служба працює, поки не зупинена:

- Відкрийте розділ `Static HTTP` веб-інтерфейсу; список `Services` показує кожну працюючу службу та її корінь документів;
- кожен запис має кнопку зупинки; діапазон портів налаштовується на тій самій сторінці.

> Служба — список файлів лише для читання — без кінцевих точок запису; вміст директорії видно наживо в міру змін, що пасує безперервно створюваним логам і артефактам.
