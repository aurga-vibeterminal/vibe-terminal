Провідник файлів оперує файловою системою боці сервера. Панель інструментів угорі лівої панелі перемикає між Recent / Explorer / Git / Debug / Search; Explorer — файловий браузер.

## Кнопка Home: стрибок до cwd термінала

Клацніть кнопку `Home` (хатинку) на панелі інструментів:

- перемикає у вигляд `Explorer`;
- стрибає до **робочої директорії активного термінала** (його cwd);
- пришпилює цю директорію як дерево і чистить поле пошуку — ви завжди починаєте від «де термінал, те і бачите».

![Провідник файлів у звичайному режимі — Home, навігаційні крихти і плаский список](images/files-explorer.jpg)

## Режим дерева і пошук

- **Пришпилити як дерево**: кнопка-шпилька на правому кінці крихт перемикає між пласким списком і режимом дерева. У режимі дерева теки розгортаються в розгортане дерево директорій (стрибок Home пришпилює автоматично);
- **Пошук**: поле пошуку вгорі фільтрує поточний список за ім'ям, поки ви друкуєте; `Search in Folder` з контекстного меню Recent запускає рекурсивний пошук по цілій директорії.

![Провідник файлів у режимі дерева — пришпилений корінь розгортається в дерево директорій](images/files-explorer-tree.jpg)

## Базові операції

Правою на файлі або теці:

- **Створити**: `New Folder` / `New File`;
- **Редагувати**: `Rename`; `Copy` / `Cut` / `Paste` (працює між директоріями);
- **Видалити**: `Delete`, з діалогом підтвердження;
- **Зв'язок із терміналом**: `Open in Terminal` відкриває нову термінальну вкладку в цій директорії; `cd to Directory` робить cd поточного термінала туди;
- **Зв'язок з ОС**: `Reveal in File Explorer` показує локальну директорію в системному файловому менеджері;
- **Шляхи**: `Copy Full Path` / `Copy Relative Path`;
- **Публікація**: `Host with HTTP server` публікує директорію як HTTP-файлову службу (див. Публікація через HTTP-сервер); `Open in App` відкриває її застосунком агента, виявленим на сервері.

Кожна операція діє на файловій системі боці сервера; віддалені сесії поводяться точно як локальні.
