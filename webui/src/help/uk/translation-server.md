Переклад — це LLM-завдання на рівні функції, що налаштовується на сервері один раз. Будь-який запит на переклад від будь-якого клієнта — повідомлення чату, чернетки комітів, виділення редактора й діфів — проходить через ті самі налаштування.

## Увімкнення функції

Відкрийте розділ `LLM` веб-інтерфейсу та знайдіть картку `Translation`:

1. Увімкніть `Enable LLM translation`;
2. Оберіть `Provider` — у випадаючому списку лише LLM-аддони, **увімкнені** в розділі `Додатки` (вбудований провайдер **OpenAI Compatible LLM** покриває більшість випадків);
3. Заповніть поля провайдера в `Provider Configuration` (для вбудованого: `Base URL`, `API Key`, `Model`, опційно `Extra Body`, ліміти токенів, `Timeout`);
4. Оберіть `Target Language`, якою писатиметься кожен переклад.

Конфігурація зберігається навіть коли функцію вимкнено, але сервер застосовує її лише після вмикання перемикача. Без нього запити клієнта падають із *"translation addon is not configured or disabled"*.

## Цільова мова

На відміну від функцій термінала і Git, у перекладі немає опції `Auto` — він завжди перекладає однією явною мовою зі списку (English, 简体中文, 繁體中文, Deutsch, Español, Français, 日本語, 한국어, Nederlands, Polski, Português, Русский, ไทย, Tiếng Việt, العربية, Bahasa Indonesia, Bahasa Melayu, Українська). Налаштування діє на весь сервер; зміна впливає лише на нові запити. Неналаштована мова відкочується до англійської.

![Випадаючий список цільової мови](images/translation-server-language.jpg)

## Повторне використання облікових даних провайдера

Кнопки копіювати/вставити біля заголовка `Provider Configuration` клонують значення полів між картками функцій, що використовують той самий аддон провайдера, — оберіть і заповніть провайдера раз (скажімо, для повідомлень комітів Git), натисніть **Copy**, потім **Paste** у картці Translation.

## Вибір моделі

Переклади — короткі, чутливі до затримки промпти: швидка модель виграє у велику модель, що міркує. **Qwen3.5 9B** за OpenAI-сумісним ендпоінтом (Ollama, vLLM, llama.cpp) або **DeepSeek V4 Flash** через API працюють однаково добре. Сервер чекає до 60 секунд на запит; повільним локальним моделям може знадобитися збільшений `Timeout` у полях провайдера.

> Режим роздумів додає секунди затримки без виграшу в якості — вимкніть його в `Extra Body`, напр. `{"enable_thinking": false}` для Qwen або `{"thinking": {"type": "disabled"}}` для DeepSeek.
