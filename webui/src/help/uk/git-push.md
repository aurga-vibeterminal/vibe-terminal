Контекстне меню списку гілок зосереджує push, checkout і повсякденні операції з гілками.

## Push

Правою на гілці → `Push '{branch}'...` відкриває діалог push:

![Правою на гілці — запис Push](images/git-push-contextmenu.jpg)

- показує відображення цілей `local → remote`; кожне з імен можна змінити (push на наявну віддалену гілку під іншим ім'ям просить підтвердження);
- опції: `Push all branches`, `Set upstream` (прив'язати upstream при першому push), `Push tags`, `Dry run`;
- переписуючий історію `Force` і безпечніший `Force with lease` (відмовляє, коли хтось інший запушив — бажаний). Операції, що переписують історію, як push після rebase, вимагають одного з них;
- у діалозі показується підказка ризику force push.

![Діалог push — цілі local → remote і прапорці опцій](images/git-push-dialog.jpg)

## Checkout

Правою на гілці → `Checkout`, щоб перемкнути гілку — локальні гілки виводяться просто, а віддалена гілка чи тег відкриває діалог checkout:

![Правою на гілці — запис Checkout](images/git-checkout-contextmenu.jpg)

- `New branch name` — локальна гілка до створення, передзаповнена з посилання;
- `Create new local branch` (`-B`), `Track remote as upstream` (`--track`, лише віддалені гілки), `Force` (`-f`), `Merge` (`--merge`).

![Діалог checkout — ім'я гілки і опції](images/git-checkout-dialog.jpg)

Робоча директорія сесії йде за перемиканням; термінал і панель Git віддзеркалюють нову гілку негайно.

## Від'єднаний HEAD

Checkout голого коміту (напр. checkout коміту під час перегляду історії) від'єднує HEAD. Наступний коміт тоді відкриває діалог `Detached HEAD`: виберіть наявну гілку для коміту, `+ Create new branch…` на місці або поки `Skip`.

## Інші операції

- **Stash** — stash-ніть усі зміни на стек (повідомлення необов'язкове) із заголовка змін; список `STASHES` підтримує `Pop` (застосувати і видалити) та `Drop` (відкинути, незворотно);
- **Видалення гілок/worktree** — через контекстне меню запису, обидва з підтвердженнями незворотних дій;
- **Історія і відновлення** — `HISTORY` перелічує коміти; правою для історії файлу, diff проти робочого дерева або відновлення до ревізії;
- **Копіювання** — імена гілок і хеші комітів копіюються одним кліком, зручно для вставки агентові або колезі.
