يسند قسم `LLM` بواجهة الويب مزود LLM لكل ميزة ذكاء اصطناعي — تصنيف الطرفية، ورسائل تنفيذ Git، وحل التعارضات، وصقل النص الصوتي، والترجمة. المزودون أنفسهم إضافات من نوع LLM تُدار في قسم `Addons`.

## المزودون إضافات

يسكن مزودو LLM مجموعة `LLM` في قسم `Addons`:

- مزود **OpenAI Compatible LLM** مدمج؛ ويمكن رفع مزودين مخصصين كـ zip (زر `Upload`). يعلن بيان الإضافة حقول الضبط (مفتاح API وعنوان الأساس والطراز و…) التي تحوّلها واجهة الويب إلى نموذج;
- لا يظهر المزود في مُنتقيات الميزات إلا ما دامت إضافته **مفعّلة** — فعّلها أولًا في قسم Addons;
- يحرر زر القلم على بطاقة إضافة مصدرها؛ ويمكن التراجع عن إضافة مدمجة عدّلتها بـ `Reset`.

## الضبط لكل ميزة

لكل بطاقة ميزة في قسم `LLM` مفتاح تفعيلها واختيار مزودها الخاص، فتستطيع الأعمال المختلفة استخدام طرز مختلفة:

- **Terminal Classification** — تصنّف حالة الطرفية حين لا تكفي الأنماط المدمجة. يعطّل `Max Consecutive Failures` الـ LLM للجلسة بعد ذلك العدد من الإخفاقات المتتابعة (الأدنى 3);
- **Git Commit Messages** — توليد رسائل التنفيذ من التغييرات المحضرة;
- **Git Conflict Resolve** — حل تعارضات إعادة التأسيس/الدمج مقطعًا مقطعًا;
- **Voice Text Polish** — صقل نسخ الإدخال الصوتي قبل الإرسال;
- **Translation** — ترجمة النص إلى اللغة الهدف المختارة.

وسّع بطاقة لاختيار `Provider` وملء حقول المزود. يُحفظ الضبط حتى مع تعطيل الميزة ولا يسري إلا بعد تفعيلها. حين تستخدم عدة ميزات إضافة المزود نفسها، يستنسخ وزرا النسخ/اللصق بجانب `Provider Configuration` قيم حقوله بين تلك الميزات (انظر أدناه).

تقدم ميزتا Terminal وGit لغة مخرجات مع خيار `Auto` (يقرر الطراز)؛ وتستخدم الترجمة قائمة أهداف صريحة English/简体中文.

## النسخ/اللصق بين الميزات

تحفظ كل ميزة نسخةً خاصة من حقول المزود، لذا استخدام مزود واحد لعدة ميزات يعني عادةً إعادة كتابة عنوان الأساس ومفتاح API والطراز نفسهما في كل بطاقة. تحوي ترويسة `Provider Configuration` زرين صغيرين يُزيلان هذا التكرار:

- **نسخ** — ينسخ قيم الحقول المعروضة حاليًا في هذه البطاقة، مع إضافة المزود التي تنتمي إليها;
- **لصق** — يظهر في بطاقة فقط حين يكون المزود المختار فيها هو الإضافة نفسها التي انطبع منها الضبط المنسوخ؛ والنقر عليه يملأ حقول البطاقة بالقيم المنسوخة.

لمشاركة طرف واحد بين، مثلًا، رسائل تنفيذ Git والترجمة: اختر المزود وملأ حقوله في البطاقة الأولى، واضغط **نسخ**، ثم افتح البطاقة الأخرى (مع اختيار المزود نفسه) واضغط **لصق**. تُخزَّن القيم المُلصقة في ضبط الميزة نفسها كما تُخزَّن أي تعديلة حقول أخرى، وتُحفظ معها. الحافظة داخل الصفحة فقط — تُفرَّغ عند مغادرة قسم LLM.

![زرّا النسخ واللصق في ترويسة Provider Configuration — استنساخ حقول مزود بين الميزات التي تستخدم الإضافة نفسها](images/ai-llm-duplicate-config.jpg)

## المزود المتوافق مع OpenAI

يعمل المزود المدمج مع أي واجهة دردشة متوافقة مع OpenAI. الحقول الرئيسة:

- ‏`Base URL` / `API Key` / `Model` — الطرف والبيانات واسم الطراز;
- ‏`Extra Body` — كائن JSON يُدمج في كل جسم طلب، للمعاملات الخاصة بالطراز;
- ‏`Max Input Tokens` / `Max Output Tokens` — ميزانية المطالبة وسقف الإكمال;
- ‏`Timeout` — مهلة لكل طلب بالثواني؛ ارفعها للنماذج المحلية البطيئة.

## الطرز الموصى بها

أعمال الذكاء هذه مطالبات صغيرة حساسة للزمن — طراز سريع «على قدر» يغلب طراز استدلالًا ضخمًا:

- **محليًا: Qwen3.5 9B** — النقطة المثلى لتوليد رسائل تنفيذ Git وتصنيف الطرفية والترجمة وصقل الصوت. قدّمه بطرف متوافق مع OpenAI‏ (Ollama وvLLM وllama.cpp) ووجّه `Base URL` إليه;
- **عبر API: DeepSeek V4 Flash‏ (`deepseek-v4-flash`)** — سريع بما يكفي للاستخدام التفاعلي وقادر على كل الميزات أعلاه.

> يضيف نمط التفكير ثواني من الزمن ونادرًا ما ينفع هذه المهام القصيرة — أطفئه في `Extra Body` لتجربة أفضل، مثل `{"enable_thinking": false}` لـ Qwen أو `{"thinking": {"type": "disabled"}}` لـ DeepSeek‏ (المفتاح الدقيق يعتمد على مجموعتك؛ ويُدمج JSON حرفيًا في جسم الطلب).
