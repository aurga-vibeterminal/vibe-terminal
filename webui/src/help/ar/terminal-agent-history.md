عند تشغيلك وكيل شيفرة (Claude Code أو Codex أو Kimi أو Pi أو OpenCode…) في طرفية، تظل محادثته محبوسة في نافذة الطرفية — تتدحرج بين مخرجات الأوامر، وتضيع ما إن تتحرك الشاشة. يرفع `سجل محادثات وكيل الشيفرة` المحادثة كاملة إلى لوحة مخصصة: كل تبادل معروض منظمًا، والمحادثات الماضية قابلة للتبديل، والرسائل قابلة للترجمة — ويمكنك إرسال الأوامر إلى الطرفية من اللوحة مباشرة.

## فتح اللوحة

اضغط زر الدردشة (`AI`) في يمين شريط العنوان لتبديل لوحة Copilot. يسرد المنسدل في أعلاها **كل المحادثات الماضية** للوكيل العامل في الجلسة النشطة، الأحدث أولًا؛ واختيار واحدة يحمّلها.

![لوحة Copilot — منسدل المحادثات وتدفق الرسائل](images/terminal-agent-history.jpg)

## كيف يعمل

- يعرف الخادم أي تطبيق وكيل يعمل في الطرفية ويحلل **ملفات جلساته الأصلية** (صيغة JSONL/السجل لكل وكيل تحت مجلد مشروعه)؛ وتتدفق تغييرات الملف حيًّا فتبقى عرض المحادثة محدثًا;
- الوكلاء المدعومون: `claude` / `codex` / `kimi` / `pi` / `opencode`؛ ولا لوحة محادثة بعد للتطبيقات الأخرى;
- تحمل الرسائل دورًا (أنت / وكيل) ونوعًا (نص / استدلال **Thinking**)، مع اسم الطراز والوقت، معروضة كـ Markdown.

## ميزات اللوحة

- **تبديل المحادثات**: منسدل `Conversations` أعلى اللوحة ينتقل بين الجلسات الماضية، ويعرض كل مدخل موجزًا ووقته;
- **الترجمة**: يمكن ترجمة أي رسالة وكيل عند الطلب؛ تستبدل الترجمة النص في موضعه (ويمكن ردها);
- **إرسال الأوامر مباشرة**: اكتب في الصندوق أسفل اللوحة (Shift+Enter لسطر جديد) واضغط Enter — يذهب الأمر مباشرة إلى الطرفية الحالية، كالكتابة في صندوق إدخال الوكيل نفسه دون احتلال عرض الطرفية.

## تكامله مع الميزات الأخرى

- اللوحة والطرفية وجهان لجلسة واحدة: أسئلة الوكيل في الطرفية تُجاب هناك (أو عبر التأكيد التلقائي)؛ واللوحة لمراجعة السجل لا لاعتراض التفاعل;
- مقترنًا بـ `Terminal MCP` (الصفحة السابقة)، يستطيع الوكلاء الخارجيون أيضًا قراءة شاشة الطرفية وتشغيل الأوامر — المحادثة المعروضة هنا مع أفعال MCP تشكل السجل الكامل لعمل الوكيل.
