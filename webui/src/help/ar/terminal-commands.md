تثبّت الأوامر السريعة أوامر build/test/deploy للمشروع في قائمة الزر الأيمن للطرفية — نقرة واحدة للتشغيل، متاحة في كل مكان. تُدار الأوامر لكل مستودع في `.vterm/commands.json` في جذر المستودع.

## إنشاء commands.json

زر أيمن داخل طرفية → `Commands`:

- عندما لا يكون لدى مستودع الجلسة commands.json بعد، تعرض القائمة مدخلًا وحيدًا، `Generate commands.json` — الضغط عليه يجعل الخادم يكشف نوع المشروع (npm / Cargo / .NET / Xcode / Gradle-Android / عام) ويكتب قالبًا مبدئيًا متحفظًا. الملف الموجود غير الفارغ **لا يُستبدل أبدًا**;
- مكان الملف: `.vterm/commands.json` في جذر مستودع Git (مجلد العمل الحالي للمجلدات غير التابعة لـ Git).

## التنقيح

يحتوي القالب المولَّد على الأوامر المعتادة لنوع المشروع المكتشف فقط. دع وكيل الشيفرة (مثل وكيل محرر متصل بـ MCP هذا الخادم) يقرأ المشروع وينقّح الملف:

```json
{
  "commands": [
    { "name": "Build", "command": "cargo build --release" },
    { "name": "Test verbose", "command": "cargo test -- --nocapture",
      "env": { "RUST_LOG": "debug" } },
    { "name": "Package (Windows)", "command": "./packaging/windows/package.bat",
      "os": "win" }
  ]
}
```

يُقبل أيضًا مصفوفة المستوى الأعلى؛ و `env` اختياري ويحدد متغيرات قبل تشغيل الأمر؛ والمفتاح القديم `value` ما يزال يُقرأ. حقل `os` الاختياري يُقيّد المدخل بنظام التشغيل الذي يعمل عليه `vterm-server`: استخدم `"win"` لويندوز، أو `"linux"` لينكس، أو `"osx"` لماك. وإذا أُهمل `os` أو ضُبط على `"all"` أو على قيمة غير معروفة، فالمدخل متاح على كل المنصات. يراقب الخادم المجلد الحالي وتغييرات commands.json ويبثها — أعد فتح القائمة وهناك الأوامر الجديدة.

## التشغيل

زر أيمن → `Commands` → اضغط مدخلًا لتشغيله في تلك الطرفية (يطبَّق env الاختياري أولًا). القائمة غير متاحة أثناء عمل تطبيق وكيل في الجلسة، حتى لا يسقط نص الأمر داخل واجهته.

## مثال: بناء أندرويد وتثبيته عبر Wi-Fi

جولة كاملة على مشروع Gradle-Android: ثبّت إعداد ADB اللاسلكي وتدفق البناء-التثبيت في قائمة الزر الأيمن، ثم أعد بناء التطبيق بنقرة.

**1. تحويل الهاتف إلى ADB لاسلكي.** يُكتب هذان الأمران مرة لكل جهاز — `adb tcpip 5555` والهاتف على USB، ثم `adb connect` بعنوان الهاتف:

![طرفية — تحويل هاتف أندرويد إلى ADB لاسلكي بـ adb tcpip 5555 و adb connect](images/terminal-commands-adb-setup.gif)

**2. دع وكيل الشيفرة يكتب الأوامر.** افتح وكيل شيفرة المشروع (هنا Claude Code) في طرفية واطلب إضافة أوامر بناء وتثبيت — يقرأ تخطيط المشروع ويكتب المدخلات في `.vterm/commands.json`:

![طرفية — Claude Code يحرر commands.json بأوامر بناء وتثبيت APK](images/terminal-commands-agent-edit.mp4)

**3. البناء والتثبيت من القائمة.** قسّم الطرفية ليكون لمخرجات البناء لوحها الخاص، ثم زر أيمن → `Commands` → المدخل — يجمع Gradle حزمة APK ويثبتها على الهاتف عبر Wi-Fi:

![طرفية — تقسيم لوح وتشغيل أمر البناء والتثبيت لأندرويد من قائمة الزر الأيمن](images/terminal-commands-split-run.mp4)
