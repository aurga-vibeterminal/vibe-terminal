كل طرفية مواطن من الدرجة الأولى في MCP (بروتوكول Model Context): يقود الوكلاء الخارجيون الطرفيات عبر أدوات MCP للخادم — سرد الطرفيات، وقراءة الشاشة، وتشغيل الأوامر، وانتظار الاكتمال — فيمكن لوكيل البرمجة الذي تستخدمه أصلًا تشغيل صدفات تفاعلية حقيقية.

## أدوات MCP للطرفية على الخادم

حول جلسات الطرفية يمكن لعميل MCP:

- `list_terminals` — كل الطرفيات المفتوحة؛ `get_terminal` — عنوان طرفية ومجلدها وحالة تطبيقها;
- `get_screen` — نص الشاشة المرئي الحالي؛ `get_scrollback` — أسطر السجل الحديثة;
- `send_command` — تنفيذ سطر أمر (مع إلحاق Enter)؛ `send_input` — نص خام دون Enter (تأكيد `y`، ملء النماذج)؛ `send_key` — مفاتيح مسماة (Enter وCtrl+C والأسهم);
- `clear_terminal` — تفريغ المخزن؛ `resize_terminal` — تغيير حجم PTY؛ `wait_terminal` — الحجب حتى تفرغ الطرفية.

## مخاطبة طرفية: معرّف الطرفية

تستهدف نداءات الأدوات طرفية بمعرّفها. زر أيمن داخل طرفية → `MCP` → `Copy Terminal ID`، ثم الصق المعرّف لوكيلك ليقود تلك الطرفية بعينها.

## تسجيل تطبيقات الوكلاء بنقرة

تسرد القائمة الفرعية `MCP` أيضًا تطبيقات الوكلاء المكتشفة على الخادم (واجهات محررات وما شابه). الضغط على تطبيق يكتب أمر `mcp add` جاهزًا في الطرفية — **دون سطر جديد في النهاية**؛ راجعه واضغط Enter بنفسك لتسجيل خدمة MCP لهذا الخادم لدى ذلك الوكيل. تختفي المدخلات أثناء عمل تطبيق في الجلسة سلفًا، فلا يسقط النص داخل واجهته.

> حلقة نموذجية: انسخ معرّف الطرفية لوكيلك → يبدأ `send_command` بناءً → `wait_terminal` حتى الاكتمال → يقرأ `get_screen` النتيجة. مع التأكيد التلقائي (انظر فصل الطرفيات)، تعمل المهام التفاعلية الطويلة شبه بلا رقابة.
