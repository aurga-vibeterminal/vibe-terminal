تركّز قائمة الزر الأيمن للفروع الدفع والسحب وعمليات الفروع اليومية.

## الدفع

زر أيمن على فرع → `Push '{branch}'...` يفتح حوار الدفع:

![زر أيمن على فرع — بند Push](images/git-push-contextmenu.jpg)

- يعرض تخطيط الأهداف `local → remote`؛ ويمكن تغيير أي من الاسمين (الدفع إلى فرع بعيد قائم باسم مختلف يطلب تأكيدًا);
- الخيارات: `Push all branches` و `Set upstream` (ربط المنبع عند أول دفع) و `Push tags` و `Dry run`;
- ‏`Force` كاتب التاريخ، و `Force with lease` الأكثر أمانًا (يرفض حين دفع شخص آخر — المفضل). تتطلب عمليات إعادة كتابة التاريخ، كالدفع بعد إعادة تأسيس، أحدهما;
- يعرض الحوار تنبيه خطر بشأن الدفع القسري.

![حوار الدفع — الأهداف local → remote وخيارات الاختيار](images/git-push-dialog.jpg)

## السحب (Checkout)

زر أيمن على فرع → `Checkout` لتبديل الفرع — تُسحب الفروع المحلية مباشرة، أما فرع بعيد أو وسم فيفتح حوار السحب:

![زر أيمن على فرع — بند Checkout](images/git-checkout-contextmenu.jpg)

- ‏`New branch name` — الفرع المحلي المراد إنشاؤه، معبأ مسبقًا من المرجع;
- ‏`Create new local branch` (`-B`)، `Track remote as upstream` (`--track`، للفروع البعيدة فقط)، `Force` (`-f`)، `Merge` (`--merge`).

![حوار السحب — اسم الفرع والخيارات](images/git-checkout-dialog.jpg)

يتبع مجلد عمل الجلسة التبديل؛ وتعكس الطرفية ولوح Git الفرع الجديد فورًا.

## HEAD المنفصل

سحب تنفيذ مجرد (مثل سحب تنفيذ أثناء تصفح التاريخ) يفصل HEAD. يفتح التنفيذ التالي حينئذ حوار `Detached HEAD`: اختر فرعًا قائمًا للتنفيذ فيه، أو `+ Create new branch…` في الموضع، أو `Skip` الآن.

## عمليات أخرى

- **الكبس** — كبس كل التغييرات إلى المكدس (برسالة اختيارية) من ترويسة التغييرات؛ تدعم قائمة `STASHES` الأمرين `Pop` (تطبيق وإزالة) و `Drop` (إسقاط، لا رجعة فيه);
- **حذف الفروع/الأشجار** — عبر قائمة الزر الأيمن للمدخل، وكلاهما بتأكيدات أفعال لا رجعة فيها;
- **التاريخ والاستعادة** — يسرد `HISTORY` التنفيذات؛ وزر أيمن لتاريخ ملف أو diff مع شجرة العمل أو استعادة إلى مراجعة;
- **النسخ** — تُنسخ أسماء الفروع وبصمات التنفيذ بنقرة، مفيد للّصق لوكيل أو زميل.
