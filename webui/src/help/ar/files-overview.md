تتيح لك إدارة الملفات العمل بملفات الخادم مباشرة من العميل: لشريط النشاط الأيسر بندان — `Recent` (المشاريع الحديثة) ومستكشف الملفات — يستخدمان مع تبويبات الطرفية. كل شيء يعمل على خادم الجلسة: الجهاز المحلي، أو جهاز بعيد/مشارك عبر مرحّل.

## Recent: المشاريع الحديثة

يسرد `Recent` المجلدات التي فتحها وكلاء الشيفرة مؤخرًا على الخادم الحالي، الأحدث أولًا:

- **اضغط** مدخلًا فينتقل مستكشف الملفات إلى ذلك المجلد;
- **الزر الأيمن** يفتح قائمة إجراءات سريعة:
  - `Open in VS Code` — فتح المجلد في VS Code على هذا الجهاز;
  - `Reveal in File Explorer` — إظهاره في مدير ملفات النظام;
  - `Copy Full Path` / `Copy Relative Path` — المسار الكامل، أو النسبي للمستودع;
  - `Search in Folder` — البحث في الملفات داخل ذلك المجلد;
  - `Open in Terminal` — فتح تبويب طرفية جديدة هناك؛ `cd Here` — نقل الطرفية الحالية إليه بـ cd;
  - `Host with HTTP server` — نشر المجلد كخدمة ملفات HTTP (انظر النشر عبر خادم HTTP);
  - `Open in App` — فتحه بتطبيق وكيل مكتشف على الخادم.

## مستكشف الملفات

تبويب `Explorer` يتصفح نظام ملفات جانب الخادم ويديره: التنقل في المجلدات، وعروض الشجرة والمسطحة، والبحث، والإنشاء/إعادة التسمية/الحذف وعمليات أخرى، إضافة إلى الرفع والتنزيل بالسحب والإفلات بين الخادم وهذا الجهاز. انظر مستكشف الملفات والرفع والتنزيل.
