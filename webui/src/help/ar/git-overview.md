يبني لوح Git إدارة الإصدارات داخل العميل: التحضير والتنفيذ وإدارة الفروع وأشجار العمل وإعادة التأسيس التفاعلية وحل التعارضات والدفع — دون مغادرة نافذة طرفيتك. يعمل كل شيء على مستودع Git لجلسة الطرفية الحالية: في أي مجلد تعمل الجلسة، ذاك هو المستودع الذي يعرضه اللوح.

## فتحه

اضغط تبويب `Git` في شريط النشاط الأيسر (تظهر بيانات المستودع فقط حين تكون الجلسة النشطة داخل مستودع Git). يتبع مستودع التبويب جلسته النشطة؛ ويتيح فتات خبز المستودع القفز بين المستودعات الأصل والفرعية، وتُسرَد الوحدات الفرعية على حدة.

![لوح Git — التغييرات والتاريخ والفروع](images/git-overview-panel.jpg)

## ما يستطيع فعله

- **التحضير والتنفيذ** — تحضير/إلغاء تحضير لكل ملف أو دفعة، وترك التغييرات، والتنفيذ برسالة، ورسائل تنفيذ مولَّدة بالذكاء الاصطناعي (انظر مساعدة LLM);
- **التاريخ** — تاريخ التنفيذات ولكل ملف، والمقارنة والاستعادة بين المراجعات;
- **الفروع** — سحب وإنشاء وحذف الفروع المحلية/البعيدة والوسوم;
- **أشجار العمل** — سحب فرع إلى شجرة عمل معزولة (يفتح تبويب طرفية جديد تلقائيًا)، ودمجه عند الانتهاء (انظر أشجار العمل);
- **إعادة التأسيس التفاعلية** — إعادة ترتيب/سحق/تحرير طابور التنفيذات بصريًا مع حل التعارضات (انظر إعادة التأسيس التفاعلية);
- **حل التعارضات** — محرر دمج بأربعة أنماط، بينها وكيل ذكاء اصطناعي يحل المقاطع واحدًا واحدًا (انظر حل التعارضات);
- **الدفع وممتفرقات** — حوار دفع كامل الميزات، والكبائن (stashes)، ومعالجة HEAD المنفصل (انظر الدفع والسحب والمزيد).

تغطي الصفحات التالية كل نطاق بهذا الترتيب.
