الإضافات توسّع الخادم بقدرات جديدة دون المساس بالنواة: مزوّدو LLM، وواجهات التعرف على الصوت، ومحدّثات DNS الديناميكي، وأسطح أدوات MCP إضافية، وكشف تطبيقات وكلاء الشيفرة — كلها تعيش كإضافات. قسم `Addons` في واجهة الويب يديرها.

## الفئات

كل إضافة تصرّح بنوع، والقسم يجمع البطاقات وفقه:

- **Applications** — تعلّم مراقب الطرفيات التعرف على CLI لوكيل شيفرة (Claude Code وCodex وKimi Code وPi وOpenCode مدمجة): كشف العمليات، حالة مشغول/خامل، خطافات الأتمتة؛
- **LLM Providers** — واجهات إكمال المحادثة التي تختار منها ميزات الذكاء الاصطناعي (مزوّد متوافق مع OpenAI مدمج)؛
- **Voice / ASR** — واجهات التعرف على الصوت (الإضافة المدمجة `vibe-voice` تشير إلى خادم ASR المحلي المُشرَف عليه)؛
- **Dynamic DNS** — تُبقي اسم المضيف مواكبًا للعنوان الحالي (Cloudflare مدمج)؛
- **MCP** — أسطح أدوات MCP إضافية تُخدَم على مضيف MCP (EasyEDA Pro مدمج)؛
- أي شيء آخر يقع في مجموعة **Other**.

## الإضافات المدمجة والمرفوعة

- الإضافات **المدمجة** تأتي داخل البرنامج ومتاحة دائمًا. بيانها ومصدرها يبقيان أصليين — المصدر المُستبدَل يمكن استعادته في أي وقت؛
- الإضافات **المرفوعة** ملكك: ملف zip يضم بيانًا ومصدر JavaScript، يُثبَّت عبر زر `Upload Addon`؛
- شارة `Modified` تميّز إضافة استبدلت مصدرها.

كل بطاقة تعرض النوع والشارات ومفتاح تفعيل؛ وعند توسيعها تظهر الأوصاف والمؤلف وحقول الإعداد والشيفرة المصدرية.

## الإعداد

بيان الإضافة يصرّح بحقول إعدادها، والبطاقة الموسعة تحوّلها إلى نموذج. القيم تُخزَّن لكل إضافة ولا تسري إلا أثناء تفعيلها؛ حقول كلمة المرور تبقى مموهة. تعطيل الإضافة يحتفظ بإعدادها — وعند إعادة التفعيل تكمل من حيث توقفت.
