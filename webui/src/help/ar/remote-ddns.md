‏يأتي إنترنت المنازل والمكاتب عادة بعنوان IP عام ديناميكي يتغير دون إنذار. يُبقي DDNS نطاقًا ثابتًا موجّهًا إلى عنوان IP الحالي للجهاز — فلا يحتاج العملاء والخوادم الأخرى إلا تذكر الاسم، لا العنوان أبدًا.

## كيف يعمل

![بنية DDNS — يكشف المدير العنوان المحلي دوريًا، وتحدّث الإضافة سجل DNS عبر واجهة المزود، ويتصل العملاء بالنطاق](diagram/ddns)

تعمل السلسلة كلها تلقائيًا في خلفية الخادم:

1. يجدد **مدير DDNS** في دورة ثابتة (كل 5 دقائق افتراضيًا، قابلة للضبط بمتغير البيئة `TERMINAL_SERVER_DDNS_POLL_INTERVAL_SECS`)؛ وحفظ الإعداد يستدعي تجديدًا فوريًا، ولا يعمل شيء ما دامت الخدمة معطلة;
2. يقرأ **كشف العنوان المحلي** واجهة الشبكة المختارة أولًا، لائذًا بالكشف القائم على المسارات، ويرشّح النتيجة بإعداد `IP Family` (‏IPv4 / IPv6 / مزدوج);
3. تستلم **إضافة DDNS** — سكربت JS معزول — الإعداد مفكوك التشفير والعنوان الحالي وتستدعي واجهة مزود DNS عبر HTTP. فإضافة Cloudflare المدمجة مثلًا تبحث عن المنطقة بالنطاق وتعيد كتابة سجلات A / AAAA إلى العنوان الحالي، حاذفة السجلات البائدة عند اختفاء عائلة عناوين;
4. **يحل العملاء** النطاق إلى أحدث عنوان ويتصلون بالاسم.

## الإعداد

افتح قسم `DDNS` بواجهة الويب:

1. شغّل `Enable`. ويمكنك أيضًا إبقاء الخدمة مطفأة أثناء الملء — الخدمة المعطلة تحفظ إعدادها لكنها لا تعمل أبدًا;
2. اختر مزودًا تحت `Provider`؛ و `Cloudflare DDNS` مدمج;
3. املأ حقول المزود (مثال Cloudflare):
   - ‏`Email` — بريد حساب Cloudflare;
   - ‏`API Token` — رمز بصلاحية Zone → DNS → Edit;
   - ‏`Domain` — النطاق الجذر للمنطقة، مثل `example.com`;
   - ‏`Subdomain` — اسم السجل داخل المنطقة، مثل `sub` لـ `sub.example.com`؛ اتركه فارغًا لجذر المنطقة;
4. في `Network Interface & IP` اختر `Interface` و `IP Family`. يتطلب `Dual Stack` أن تحمل الواجهة عنواني IPv4 وIPv6 معًا;
5. اضغط `Save` ثم `Sync Now` للتحقق. يعرض `Sync Status` آخر عنوان IP مدفوعًا ووقت المزامنة، مع رسالة خطأ الإضافة عند الفشل.

## الأمان

تُشفَّر بيانات المزود (رموز API) قبل تخزينها (`enc-v2:`) ولا تُفك إلا في الذاكرة أثناء عمل الإضافة؛ وتعمل الإضافات في بيئة JS معزولة قدرتها الوحيدة HTTP الصادر.

## توسيع المزودين

المزودون إضافات: بيان JSON الوصفي (يعلن حقول الإعداد التي تحوّلها واجهة الويب إلى نموذج) زائد سكربت JS يعرض `run()`. و `cloudflare-ddns` المدمج هو التنفيذ المرجعي — ويمكن رفع مزودين مخصصين كـ zip في قسم `Addons`.

## مع الميزات الأخرى

- متى حلّ النطاق، يستطيع رمز QR في قسم `Server` تحويل `Connection Type` إلى `DDNS Domain`، فيمسح العملاء اتصالًا بالنطاق;
- تستطيع خوادم أخرى وضع `wss://your-domain:port` في `Relay Address` لتشغيل سلسلة المرحّل عبر النطاق (انظر فصل المرحّل).
