ذكاء لوح Git يقوده LLM: رسائل تنفيذ بنقرة، وقراءة diff بمساعدة الذكاء الاصطناعي، وحل تعارضات بوكيل مقطعًا مقطعًا. كل ذلك يعتمد على مزود LLM مضبوطًا في واجهة الويب.

## ضبط المزود

افتح قسم `LLM` بواجهة الويب:

- اختر `Provider` واملأ بياناته (تحدد الحقولَ بيانُ المزود الوصفية)؛ والضبط شامل — تصنيف الطرفية ورسائل تنفيذ Git والتطبيق المساعد وغيرها من ميزات الذكاء الاصطناعي تتشارك المزود نفسه;
- المزودون إضافات من نوع LLM: الشائعون مدمجون، ويمكن رفع مزودين مخصصين كملف zip في قسم `Addons` (يعلن البيان حقول الضبط التي تحوّلها واجهة الويب إلى نموذج).

![قسم LLM بواجهة الويب — اختر مزودًا واملأ بياناته](images/git-llm-provider-config.jpg)

## ميزات LLM في Git

- **توليد رسالة التنفيذ** — اضغط زر الذكاء الاصطناعي بجانب صندوق التنفيذ؛ يقرأ LLM الـ diff المحضَّر ويكتب رسالة تُدبَّل في الصندوق مع تحريك. وتبقى الرسالة قابلة للتحرير — نفّذ فقط حين ترضى عنها;
- **تحليل diff** — زر الشرارة في ترويسة عرض diff يحلل diff الحالي;
- **وكيل الذكاء للاشتباكات** — نمط AI لمحرر الدمج في إعادة التأسيس يحل المقاطع واحدًا واحدًا بتفسيرات ودرجة ثقة (انظر حل التعارضات).

![رسالة التنفيذ المولَّدة بالذكاء الاصطناعي مدبولة في صندوق التنفيذ](images/git-llm-commit-message.jpg)

> يقرأ LLM محتوى المستودع لإنتاج النص فقط؛ ويحدث التنفيذ والدمج دائمًا حين تؤكدهما أنت.
