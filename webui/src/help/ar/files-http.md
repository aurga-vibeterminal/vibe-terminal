ينشر `Host with HTTP server` أي مجلد على الخادم كخدمة ملفات HTTP بنقرة واحدة: تستطيع بقية أجهزة الشبكة نفسها (أو عبر المرحّل) — هاتف أو حاسوب آخر أو منصة اختبار — تصفح ذلك المجلد وتنزيله من متصفح. مثالي لمشاركة نواتج البناء وحزم السجلات، أو تسليم ملفات لأجهزة دون العميل المثبت.

## كيفية الاستخدام

ثلاثة مداخل، كلها على مجلد: قائمة الزر الأيمن لقائمة الملفات، وقائمة الزر الأيمن لمدخل Recent، وقائمة الزر الأيمن لفتات الخبز → `Host with HTTP server`.

بالضغط عليه:

1. يبدأ الخادم خدمة HTTP ثابتة متجذرة في ذلك المجلد، والمنفذ مأخوذ من نطاق منافذ Static HTTP;
2. **الخادم المحلي**: يُنسخ عنوان `http://127.0.0.1:port/` مباشرة إلى الحافظة، مع رسالة حالة «HTTP server: … (نُسخ إلى الحافظة)»;
3. **الخادم البعيد** (المتصل عبر مرحّل): يطلب العميل تلقائيًا تخطيط وكيل عكسي وينسخ عنوان المشاركة القابل للوصول خارجيًا — فقيود الشبكة المحلية ليست عائقًا.

افتح ذلك العنوان في متصفح أي جهاز فيتصفح المجلد وينزل كقائمة ويب عادية.

## إدارة الخدمات العاملة

تستمر كل خدمة HTTP بالعمل حتى تُوقف:

- افتح قسم `Static HTTP` بواجهة الويب؛ تعرض قائمة `Services` كل خدمة عاملة وجذر مستنداتها;
- لكل مدخل زر إيقاف؛ ويُضبط نطاق المنافذ في الصفحة نفسها.

> الخدمة قائمة ملفات للقراءة فقط — بلا نقاط كتابة؛ ومحتويات المجلد مرئية حيًّا مع تغيرها، ما يناسب السجلات والنواتج المنتجة باستمرار.
