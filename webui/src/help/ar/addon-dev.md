هناك مستويان للتخصيص: ترقيع مصدر إضافة قائمة، أو كتابة واحدة جديدة على نمط مدمجة ورفعها.

## ترقيع المصدر الساخن

زر القلم على أي بطاقة إضافة يفتح مصدر JavaScript للتحرير. الحفظ يخزّن لقطة تستبدل الأصل — للإضافات المدمجة والمرفوعة على السواء — ويسري التغيير فورًا دون إعادة تشغيل. مفيد لتعديل prompt أو إصلاح URL أو تجربة فكرة على النظام الحي.

`Reset` يلغي اللقطة ويستعيد المصدر الأصلي (المدمجة فقط — المرفوعة ملكك أصلًا).

![تحرير مصدر إضافة — اللقطة المحفوظة تستبدل الأصل](images/addon-edit-source.jpg)

## كتابة إضافتك

الإضافة ملفان:

- `<id>.json` — البيان: `id` و`name` و`description` و`author` و`email` و`date` و`type` و`config_fields` (المفتاح، التسمية، نوع الحقل، القيمة الافتراضية، الوصف) التي تحوّلها واجهة الويب إلى نموذج؛
- `<id>.js` — المصدر: ملف JavaScript عادي (تشغّله محرّك QuickJS المدمج، مع جسر `addon.get_config()` إلى الحقول المُعدّة) يصدّر الدوال التي يستدعيها نوعه — مثل `chat_completion()` لمزوّد LLM، وقوائم الأدوات ونداءات الجسر لإضافة MCP.

أسرع بداية هي تصدير إضافة قائمة: زر `Export` على بطاقتها ينزّل zip يضم البيان والمصدر معًا. اختر المدمجة الأقرب لهدفك (توجد أيضًا في `crates/vterm-server/src/addon/builtins/`)، عدّل id وname وtype والدوال المصدَّرة، ثم ثبّت النتيجة بـ`Upload Addon`. المرفوعة يمكن حذفها مجددًا بزر سلة المهملات.

![تصدير إضافة — البيان ومصدر JavaScript في zip واحد](images/addon-export.jpg)

## التخزين

الإضافات المرفوعة ولقطات المصدر تعيش في مجلد `addons/` من مجلد الإعداد بصيغة `<id>.json` + `<id>.js` فتنجو من إعادة التشغيل. بالنسبة لمعرّف مدمج يُحترم استبدال `.js` فقط — المدمجة تحتفظ ببيانها الخاص.
