Panel Git membina kawalan versi ke dalam klien: staging, commit, mengurus cabang, worktree, rebase interaktif, penyelesaian konflik dan push — tanpa meninggalkan tetingkap terminal anda. Semuanya beroperasi pada repositori Git sesi terminal semasa: di direktori mana pun sesi berjalan, itulah repositori yang dipaparkan panel.

## Membukanya

Klik tab `Git` dalam bar aktiviti kiri (data repositori hanya muncul apabila sesi aktif berada dalam repositori Git). Repositori tab mengikut sesi aktifnya; serampang roti repositori membolehkan anda melompat antara repositori induk dan anak, dan submodule disenaraikan berasingan.

![Panel Git — perubahan, sejarah dan cabang](images/git-overview-panel.jpg)

## Apa yang boleh dilakukan

- **Staging & commit** — stage/unstage setiap fail atau pukal, buang perubahan, commit dengan mesej, mesej commit dijana AI (lihat Bantuan LLM);
- **Sejarah** — sejarah commit dan setiap fail, bandingkan dan pulihkan antara semakan;
- **Cabang** — checkout, cipta dan padam cabang tempatan/jauh serta tag;
- **Worktree** — checkout cabang ke pokok kerja terpencil (tab terminal baharu terbuka secara automatik), gabungkan semula apabila selesai (lihat Worktree);
- **Rebase interaktif** — susun semula/squash/sunting barisan commit secara visual dengan penyelesaian konflik (lihat Rebase Interaktif);
- **Penyelesaian konflik** — penyunting gabung dengan empat mod, termasuk ejen AI yang menyelesaikan hunk satu demi satu (lihat Menyelesaikan Konflik);
- **Push & pelbagai** — dialog push berfungsi penuh, stash, pengendalian detached-HEAD (lihat Push, Checkout & Lagi).

Halaman-halaman berikut meliputi setiap kawasan dalam tertib itu.
