Интеллект панели Git движется LLM: сообщения коммитов одним кликом, чтение diff с помощью ИИ и разрешение конфликтов агентом фрагмент за фрагментом. Всё это опирается на LLM-провайдера, настроенного в веб-интерфейсе.

## Настройка провайдера

Откройте раздел `LLM` веб-интерфейса:

- Выберите `Provider` и заполните его учётные данные (поля определены манифестом провайдера); конфигурация глобальна — классификация терминала, сообщения коммитов Git, чат-ассистент и другие ИИ-функции разделяют одного провайдера;
- Провайдеры — аддоны типа LLM: обычные встроены, а пользовательские можно загрузить zip-архивом в разделе `Addons` (манифест объявляет поля конфигурации, которые веб-интерфейс превращает в форму).

![Раздел LLM веб-интерфейса — выберите провайдера и заполните учётные данные](images/git-llm-provider-config.jpg)

## Функции LLM в Git

- **Генерация сообщения коммита** — нажмите кнопку ИИ рядом с полем коммита; LLM читает индексированный diff и пишет сообщение, вводимое в поле с анимацией. Сообщение остаётся редактируемым — коммитьте, только когда довольны;
- **Анализ diff** — кнопка-искра в заголовке вида diff анализирует текущий diff;
- **ИИ-агент конфликтов** — режим ИИ редактора слияния rebase разрешает фрагменты по одному с объяснениями и уверенностью (см. Разрешение конфликтов).

![ИИ-сгенерированное сообщение коммита, вводимое в поле коммита](images/git-llm-commit-message.jpg)

> LLM читает содержимое репозитория только для создания текста; коммиты и слияния происходят всегда, когда вы их подтверждаете.
