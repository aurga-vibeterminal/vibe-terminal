Когда вы запускаете код-агент (Claude Code, Codex, Kimi, Pi, OpenCode…) в терминале, его диалог заперт в этом окне терминала — прокручивается между выводом команд и исчезает при движении экрана. `История диалогов код-агента` поднимает весь диалог в отдельную панель: каждый обмен показан структурированно, прошлые диалоги переключаются, сообщения переводятся — и можно отправлять команды в терминал прямо из панели.

## Открытие панели

Нажмите кнопку чата (`AI`) в правой части строки заголовка, чтобы переключить панель Copilot. Выпадающий список вверху перечисляет **все прошлые диалоги** агента, работающего в активной терминальной сессии, новые первыми; выбор загружает его.

![Панель Copilot — выпадающий список диалогов и поток сообщений](images/terminal-agent-history.jpg)

## Как это работает

- Сервер знает, какое приложение агента работает в терминале, и разбирает его **родные файлы сессий** (формат JSONL/истории каждого агента в его каталоге проекта); изменения файла поступают вживую, поддерживая вид диалога актуальным;
- Поддерживаемые агенты: `claude` / `codex` / `kimi` / `pi` / `opencode`; у других приложений панели диалогов пока нет;
- Сообщения несут роль (вы / агент) и тип (текст / **Thinking**-рассуждение), а также имя модели и время, отрисованные как Markdown.

## Возможности панели

- **Переключение диалогов**: выпадающий список `Conversations` вверху перемещается между прошлыми сессиями, каждая запись показывает краткое описание и время;
- **Перевод**: любое сообщение агента можно перевести по запросу; перевод заменяет текст на месте (и может быть переключён обратно);
- **Прямая отправка команд**: введите в поле внизу (Shift+Enter для новой строки) и нажмите Enter — команда идёт прямо в текущий терминал, как ввод в собственное поле агента, не занимая вид терминала.

## Взаимодействие с другими функциями

- Панель и терминал — два вида одной сессии: вопросы агента в терминале по-прежнему отвечаются там (или через автоподтверждение); панель предназначена для просмотра истории, а не для перехвата взаимодействия;
- Вместе с `Terminal MCP` (предыдущая страница) внешние агенты могут также читать экран терминала и выполнять команды — показанный здесь диалог плюс MCP-действия образуют полную запись работы агента.
