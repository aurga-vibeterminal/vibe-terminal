Когда rebase или слияние наталкивается на конфликты, панель переключается на вид конфликтов: слева список конфликтных файлов, справа редактор слияния. Конфликтные файлы также появляются в списке `CHANGES` со значком `!` — клик по ним прыгает прямо в этот вид вместо простого diff. Редактор предлагает четыре режима разрешения, и переключаться между ними можно в любой момент.

## Список конфликтных файлов

Файлы сгруппированы по состоянию: автоматически слитые успешно (автоматически индексированные) и требующие ручного внимания. Кликните файл, чтобы открыть его в редакторе; список обновляется вживую по мере разрешения, пока не опустеет.

## Четыре режима разрешения

- **Merge** (по умолчанию) — конфликты представляются фрагмент за фрагментом; на каждый выбирайте `take ours` / `take theirs` или правьте слитый результат прямо в строке;
- **Split** — diff разбивается на более мелкие сегменты уровня строк, так что обе стороны можно принимать по кусочкам внутри одного фрагмента;
- **Raw** — простое редактирование с маркерами конфликтов `diff3` (`<<<<<<<` / `=======` / `>>>>>>>`) для ручной доводки;
- **AI** — агент разрешает файл фрагмент за фрагментом: LLM анализирует каждый конфликтный фрагмент и выдаёт карточки решений с объяснением и уверенностью. Можно вводить инструкции, направляя стратегию (напр. «предпочитай theirs, сохрани логи»), ставить на паузу, донастраивать в другом режиме и продолжать — уже разрешённые фрагменты пропускаются.

В любом режиме решение записывается в файл вашей сессии и индексируется — ровно как ручная правка.

## Продолжение rebase

Когда каждый конфликт разрешён, rebase переходит к следующему коммиту; можно также прервать в любой точке, вернувшись к состоянию до rebase.
