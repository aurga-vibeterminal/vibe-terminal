Десктоп-клиент открывает удалённые экраны из панели SCREENS вверху панели Debug. Каждый экран живёт в собственном плавающем окне, которое можно использовать вместе с терминалами.

## Открытие панели SCREENS

1. Подключитесь к целевому серверу (напрямую или через релей);
2. кликните вкладку `Debug` в левой панели активности (значок инструментов);
3. панель `SCREENS` появляется вверху: по кнопке дисплея на каждый физический экранный стол сервера, затем переключатели `iOS Simulator` и `Android Simulator`.

![Панель Debug — панель SCREENS с кнопками дисплеев и переключателями симуляторов](images/remote-desktop-client-screens.jpg)

## Окна экранных столов

Кликните кнопку дисплея, чтобы открыть окно этого экрана:

- окно свободно масштабируется (вплоть до 800×600), и картинка перестраивается с ним;
- мультимониторные серверы получают по окну на дисплей; несколько могут быть открыты одновременно;
- при подключении окно показывает заглушку «подготовка рабочего стола»; если серверу не хватает разрешения на захват, окно сразу показывает инструкции платформы о разрешениях;
- повторный клик по кнопке панели или закрытие окна останавливает просмотр (активное состояние кнопки остаётся синхронным с окном).

## Окно симулятора iOS

Кликните `iOS Simulator`, чтобы открыть окно фиксированного размера с рамкой телефона (264×640 портрет):

- селектор устройств вверху меняет облик телефона; окно подстраивается под выбранное разрешение;
- `Rotate` переворачивает портрет/пейзаж (окно 524×380 в пейзаже);
- требует сервер macOS с работающим симулятором iOS из Xcode.

## Окно эмулятора Android

`Android Simulator` работает так же: фиксированная рамка телефона, селектор устройств, кнопка поворота. Передаваемые источники включают работающие эмуляторы AVD и подключённые реальные устройства; AVD также можно запустить или выключить по запросу из клиента (см. Устройства Android).

> Окна, передающие localhost-сервер, автоматически исключаются из захвата экрана, чтобы избежать зеркала обратной связи; окна, передающие удалённую машину, остаются захватываемыми, чтобы внешняя запись по-прежнему их показывала.
