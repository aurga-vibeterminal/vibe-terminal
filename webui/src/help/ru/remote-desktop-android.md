Помимо экранных столов, удалённый рабочий стол может передавать устройства Android — настоящие телефоны через adb и эмуляторы AVD. Клиент показывает их в окне с рамкой телефона с сенсорным вводом, поворотом и удалённым управлением жизненным циклом эмулятора.

## Предпосылки

Серверу нужно найти инструментарий Android:

- **Android SDK** (предоставляет `adb`) — требуется и устройствам, и эмуляторам;
- **Android Studio** — требуется для запуска эмуляторов AVD.

Оба автоопределяются по умолчанию. Если определение не удаётся или инструменты живут вне стандартных мест, задайте `Android SDK directory` / `Android Studio directory` в `Remote Desktop` → `Screen streaming tools`; изменения применяются немедленно (горячо, без перезапуска сервера).

## Источники устройств

С путями на месте сервер автоматически перечисляет доступные источники Android:

- **Подключённые реальные устройства** — подключите по USB с включённой отладкой USB; всё, что видит `adb devices`, может передаваться;
- **Эмуляторы AVD** — работающие эмуляторы появляются сами; также можно запустить выбранный AVD по запросу из клиента (не нужно запускать вручную заранее) и удалённо выключить.

Каждый источник получает собственную запись в панели SCREENS клиента.

## Ориентация

Кнопка поворота окна эмулятора задаёт системный `user_rotation` через `adb` — собственное направление экрана устройства меняется, и окно подстраивается под новое разрешение, адаптируясь и к портрету, и к пейзажу.

## Сторона клиента

Откройте вкладку `Debug` в левой панели десктоп-клиента и нажмите кнопку `Android Simulator` в панели SCREENS (она появляется только когда сервер открывает источники Android), чтобы открыть окно эмулятора; селектор устройств меняет облик рамки телефона, а `Rotate` переворачивает ориентацию. См. Работа с клиентом.

> Сенсорная инъекция на реальных устройствах использует входной канал adb (Android 4.4+); некоторые вендорские ROM её ограничивают — тогда устройство только для просмотра.
