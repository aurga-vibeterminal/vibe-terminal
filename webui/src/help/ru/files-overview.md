Управление файлами позволяет работать с файлами на сервере прямо из клиента: левая панель активности имеет две записи — `Recent` (недавние проекты) и проводник файлов — используемые вместе с вкладками терминалов. Всё работает на сервере сессии: локальная машина или удалённая/разделяемая машина через релей.

## Recent: недавние проекты

`Recent` перечисляет папки, которые ваши код-агенты открывали на текущем сервере позже всех, новые первыми:

- **Кликните** запись, и проводник файлов переключится на этот каталог;
- **Правый клик** открывает меню быстрых действий:
  - `Open in VS Code` — открыть каталог в VS Code на этой машине;
  - `Reveal in File Explorer` — показать в файловом менеджере ОС;
  - `Copy Full Path` / `Copy Relative Path` — полный путь или путь относительно репозитория;
  - `Search in Folder` — поиск файлов внутри каталога;
  - `Open in Terminal` — открыть новую вкладку терминала там; `cd Here` — сделать cd текущего терминала к нему;
  - `Host with HTTP server` — опубликовать каталог как HTTP-файловую службу (см. Публикация через HTTP-сервер);
  - `Open in App` — открыть приложением агента, обнаруженным на сервере.

## Проводник файлов

Вкладка `Explorer` просматривает и управляет файловой системой на стороне сервера: навигация по каталогам, древовидный и плоский виды, поиск, создание/переименование/удаление и другие операции, плюс загрузка и скачивание перетаскиванием между сервером и этой машиной. См. Проводник файлов и Загрузка и скачивание.
