Интерактивный rebase превращает `git rebase -i` в визуальный поток: перетаскиванием переупорядочивайте очередь коммитов, применяйте коммиты по одному, разрешайте конфликты визуально — командная строка не нужна.

## Начало

Откройте панель веток и введите в поле `Filter branches...`, чтобы найти целевую ветку, затем правый клик по ней → `Rebase Current Branch onto '{branch}'`, чтобы перебазировать текущую ветку на цель. Панель переключается на вид rebase, проходящий четыре фазы:

![Поиск ветки в панели, затем запуск rebase на цель](images/git-rebase-search.jpg)

## 1. Редактирование очереди коммитов

Коммиты вашей ветки, которых нет у цели, образуют очередь:

- **Перетаскивайте** для переупорядочивания;
- у каждого коммита выпадающий список действий: `pick` (сохранить) / `squash` (подвернуть в предыдущий, объединить сообщения) / `fixup` (подвернуть, отбросить сообщение) / `edit` (остановиться для правки) / `drop` (отбросить);
- сквошнутые и отброшенные коммиты визуально сворачиваются.

![Очередь коммитов rebase — переупорядочивание перетаскиванием, действия по коммитам](images/git-rebase-queue.jpg)

## 2. Применение

`Start Rebase` воспроизводит очередь на цель коммит за коммитом с живым индикатором прогресса; без конфликтов идёт прямо до конца. `Abort` откатывает в любой момент.

## 3. Конфликты (если есть)

Конфликт при применении переключает на вид конфликтов — список файлов плюс редактор слияния с четырьмя режимами (`Merge` / `Split` / `Raw` / `AI`), где каждый конфликтный фрагмент получает собственное решение (`Ours` / `Theirs` / `Both`…; см. Разрешение конфликтов). Когда каждый файл разрешён, `Continue` возобновляет rebase.

![Вид конфликтов — решения слияния по фрагментам](images/git-rebase-resolve-conflict.jpg)

## 4. Готово

По завершении панель подтверждает `Branch '{branch}' was rebased onto '{target}'` и показывает карточку отправки — rebase переписал историю, поэтому удалённая ветка требует принудительного обновления:

- `Force Push with Lease` — рекомендовано: перезаписывает только когда никто больше не отправлял и никогда не использует простой `--force`;
- `Not now` — пропустить отправку; локальный rebase уже завершён.

![Страница завершения — Force Push with Lease или пропуск отправки](images/git-rebase-done.jpg)

> Сессия остаётся usable во время rebase; закрытие панели не прерывает выполняющийся.
