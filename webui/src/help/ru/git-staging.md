Область `CHANGES` панели Git покрывает повседневный цикл коммитов: просмотр изменений, индексацию, отмену, стэширование и коммит с сообщением.

## Индексация и снятие

- Неиндексированные изменения перечислены под `CHANGES`, каждый файл помечен значком состояния — `M` изменён, `A` добавлен, `D` удалён, `?` не отслеживается, `!` конфликт (строки сабмодулей несут дополнительный тег `SUB`);
- Наведение на строку раскрывает встроенные кнопки действий: `+` индексирует неиндексированный файл, `−` снимает индексированный, а `×` на неиндексированной строке отменяет его; кнопки `Stage All Changes` / `Unstage All Changes` в заголовках разделов обрабатывают всё сразу;
- `Ctrl`-клик переключает файлы в мультивыделение, а `Shift`-клик выбирает диапазон — кнопка действия затем применяется к каждому выбранному файлу;
- Клик по имени файла открывает его diff, чтобы рассмотреть изменение перед решением;
- Правый клик по файлу предлагает `View File History`, `Stash This File`, `Copy Full Path` / `Copy Relative Path`, `Reveal in File Explorer` и ярлык `cd`, переносящий терминал в папку файла.

## Коммит

1. Индексируйте то, что должно войти;
2. введите сообщение в поле коммита (`Ctrl+Enter` коммитит) или нажмите кнопку ИИ для генерации (см. Помощь LLM);
3. нажмите `Commit`.

![Поле коммита — ввод сообщения с кнопкой генерации ИИ](images/git-staging-commit.jpg)

После коммита наведите на заголовок истории — полосу с именем ветки над историей коммитов — и справа проявятся кнопки `Fetch`, `Pull` и `Push`. `Push` немедленно отправляет текущую ветку в её upstream; для опций вроде `Force with lease` используйте диалог отправки списка веток (см. Push, checkout и другое).

![Наведение на заголовок истории раскрывает кнопки Fetch, Pull и Push](images/git-staging-push.jpg)

## Стэширование

- Кнопка архива в заголовке `CHANGES` открывает диалог `Stash All Changes`, где необязательное сообщение описывает стэш;
- правый клик по выбранным неиндексированным файлам предлагает `Stash This File` (или `Stash <n> Selected Files` при мультивыделении), чтобы застэшировать только эти пути — строки сабмодулей исключаются;
- стэши собираются под `STASHES` как записи `WIP on <ветка>`; разворачивание одной перечисляет захваченные файлы, а клик по файлу показывает его diff;
- наведение на строку стэша показывает `Apply` (восстановить и сохранить), `Pop` (применить и удалить) и `Drop` (удалить без применения) — `Pop` и `Drop` сначала спрашивают подтверждение, а контекстное меню добавляет `View Diff`;
- раздел `STASHES` остаётся скрытым, пока список стэшей пуст.

## Отмена изменений

`Discard Changes` на неиндексированном файле отбрасывает все его незакоммиченные изменения — есть диалог подтверждения, и действие **не может быть отменено**.

> Коммит включает только индексированное содержимое; неиндексированные изменения остаются в рабочем дереве.
