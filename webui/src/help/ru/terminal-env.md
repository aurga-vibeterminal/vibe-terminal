Переменные окружения позволяют вести сгруппированные наборы переменных по проектам (`ANDROID_HOME`, API-ключи, настройки прокси) и применять или снимать их в любой терминальной сессии одним кликом. Они живут в конфигурации сервера; значения шифруются в покое.

## Ведение в веб-интерфейсе

Раздел `Environment Variables` организует их деревом:

- **Группы** — чистые контейнеры, вложенные (правый клик → `New Group`), для организации по проекту или сценарию;
- **Коллекции** — листья дерева и фактические держатели переменных (`New Leaf`); к терминалу можно применять только коллекции;
- Пары ключ/значение каждой коллекции редактируются через `Edit Variables` (`Add Variable`); значения по умолчанию скрыты;
- Коллекции можно дублировать, создавая варианты (тот же набор с изменённым ключом).

![Страница Environment Variables — дерево групп/коллекций](images/terminal-env-tree.jpg)

## Применение к терминалу

Правый клик внутри терминала → `Envs`:

- подменю отражает дерево из веб-интерфейса; разверните коллекцию и выберите `Apply`, чтобы внедрить её переменные в текущую сессию, или `Clear`, чтобы снять их;
- новые процессы видят переменные (уже работающие программы переднего плана — нет);
- коллекции появляются свёрнутыми под своими группами; весь пункт `Envs` скрывается, пока в дереве нет коллекций.
