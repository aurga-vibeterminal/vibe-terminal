Код-агенты (Claude Code, Codex, Kimi, Pi, OpenCode…) знают только то, что достигает их входа. `Добавление контекста` — способ передать им пути файлов и фрагменты кода без перепечатки: перетащите файлы из `Explorer`, или перетащите выделенный текст из редактора кода и вида diff Git прямо в терминал агента или поле чата Copilot.

## Перетаскивание файлов

Нажмите файл — или мультивыделение — в списке файлов `Explorer` и перетащите:

- **На терминал**: полные пути вводятся в точке отпускания, разделённые пробелами, готовые стать частью вашего следующего запроса агенту;
- **На поле чата Copilot**: пути вставляются в черновик сообщения, по одному на строку, чтобы собрать мультифайловый запрос перед отправкой.

Пути, перетащенные из файлового менеджера ОС и брошенные на терминал, автоматически берутся в кавычки, так что имена с пробелами выживают нетронутыми.

![Перетаскивание файла из списка Explorer в терминал вводит его полный путь](images/terminal-context-drag-file.gif)

## Перетаскивание выделенного кода как контекста

Выделите текст в редакторе кода или в diff Git, затем нажмите само выделение и перетащите на терминал:

- когда терминал **запускает код-агент**, отпускание вставляет *блок контекста* — путь файла, диапазон строк и фрагмент, обёрнутый в кодовую ограду:

````text
File: crates/vterm/src/ui/terminal_view.rs
Lines: 558-566
```
fn can_accept_native_drop(&self, info: &DndInfo) -> bool { … }
```
````

- когда терминал на **обычном приглашении shell**, отпускание вводит сырой выделенный текст, так что тот же жест работает и для обычных команд;
- когда diff просматривается у конкретного коммита, блок дополнительно несёт строку `Commit:`, фиксирующую точную ревизию.

![Перетаскивание выделения редактора в терминал агента опускает блок контекста File/Lines](images/terminal-context-drag-selection.mp4)

## Копирование контекста

Тот же блок живёт в контекстном меню: `Copy Context` в редакторе кода и виде diff копирует его в буфер обмена. Вставьте в поле чата Copilot — или любому другому агенту — когда перетаскивание неудобно. Анимация выше показывает получившийся блок во вводе агента.

## Советы

- Мультивыделение в `Explorer`, чтобы опустить несколько путей за раз;
- поле чата Copilot отправляется прямо в терминал как введённый текст (см. `История код-агента`), поэтому добавленный там контекст достигает агента ровно как если бы вы его напечатали;
- совместите с `Автоподтверждением`, чтобы агент действовал по опущенному контексту без лишних запросов.
