Перевод — это LLM-задача на уровне функции, настраиваемая на сервере один раз. Любой переводческий запрос от любого клиента — сообщения чата, черновики коммитов, выделения в редакторе и диффах — проходит через одни и те же настройки.

## Включение функции

Откройте раздел `LLM` веб-интерфейса и найдите карточку `Перевод`:

1. Включите `Включить перевод с помощью LLM`;
2. Выберите `Провайдер` — в выпадающем списке только LLM-аддоны, **включённые** в разделе `Дополнения` (встроенный провайдер **OpenAI Compatible LLM** покрывает большинство случаев);
3. Заполните поля провайдера в `Конфигурация провайдера` (для встроенного: `Base URL`, `API Key`, `Model`, опционально `Extra Body`, лимиты токенов, `Timeout`);
4. Выберите `Целевой язык`, на котором будет писаться каждый перевод.

Конфигурация сохраняется даже при выключенной функции, но сервер применяет её только после включения переключателя. Без него запросы клиента падают с *"translation addon is not configured or disabled"*.

## Целевой язык

В отличие от функций терминала и Git, у перевода нет опции `Авто` — он всегда переводит на один явный язык из списка (English, 简体中文, 繁體中文, Deutsch, Español, Français, 日本語, 한국어, Nederlands, Polski, Português, Русский, ไทย, Tiếng Việt, العربية, Bahasa Indonesia, Bahasa Melayu, Українська). Настройка действует на весь сервер; смена влияет только на новые запросы. Ненастроенный язык откатывается к английскому.

![Выпадающий список целевого языка](images/translation-server-language.jpg)

## Повторное использование учётных данных провайдера

Кнопки копировать/вставить рядом с заголовком `Конфигурация провайдера` клонируют значения полей между карточками функций, использующими один аддон провайдера, — выберите и заполните провайдера один раз (скажем, для сообщений коммитов Git), нажмите **Копировать**, затем **Вставить** в карточке Перевод.

## Выбор модели

Переводы — короткие, чувствительные к задержке промпты: быстрая модель выигрывает у большой рассуждающей. **Qwen3.5 9B** за OpenAI-совместимым эндпоинтом (Ollama, vLLM, llama.cpp) или **DeepSeek V4 Flash** по API работают одинаково хорошо. Сервер ждёт до 60 секунд на запрос; медленным локальным моделям может понадобиться увеличенный `Timeout` в полях провайдера.

> Режим размышлений добавляет секунды задержки без выигрыша в качестве — отключите его в `Extra Body`, напр. `{"enable_thinking": false}` для Qwen или `{"thinking": {"type": "disabled"}}` для DeepSeek.
