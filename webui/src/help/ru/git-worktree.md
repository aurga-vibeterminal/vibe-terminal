Worktree извлекают несколько веток одного репозитория в отдельные каталоги: разрабатывайте параллельно, не трогая основное рабочее дерево, затем слейте ветку обратно и почистите. Vibe Terminal превращает весь цикл в тычки мышью.

## Создание worktree

1. В списке веток панели Git правый клик по целевой ветке (локальной или удалённой) → `New Worktree`;
2. диалог именует новый worktree по ветке — отредактируйте при желании; подтвердите, и сервер создаст каталог worktree и извлечёт туда ветку;
3. **новая вкладка терминала открывается автоматически** с рабочим каталогом нового worktree — начинайте изолированную разработку немедленно, пока основное дерево остаётся на своей ветке.

![Диалог New Worktree — имя по умолчанию — ветка](images/git-worktree-create.jpg)

![Новая вкладка, открытая для свежесозданного worktree](images/git-worktree-terminal.jpg)

## Параллельная работа

Каждый worktree — полностью независимый рабочий каталог: сборки и тесты основной ветки и ветки функции идут бок о бок в разных вкладках без помех. Извлечённые в worktree ветки несут маркер worktree с их путём в списке веток, а коммиты и отправка работают прямо из вкладки worktree, как в любой ветке.

Правый клик по ветке worktree добавляет две записи только для worktree: `Reveal in File Explorer` (локальные сессии) открывает его каталог в системном файловом менеджере, а `Open in Terminal` открывает там ещё одну вкладку.

## Слияние обратно и уборка

1. Коммитьте и отправляйте внутри вкладки worktree как обычно;
2. переключите главную вкладку на целевую ветку (напр. `main`), правый клик по ветке функции → `Merge into Current Branch`, чтобы забрать работу;

   ![Слияние ветки worktree обратно в основную ветку](images/git-worktree-merge.jpg)

3. после слияния правый клик по ветке → `Delete Worktree`: это удаляет каталог worktree и его ветку вместе. Сначала убедитесь, что всё слито или отправлено — диалог предупредит снова, и действие необратимо.

   ![Подтверждение Delete Worktree — каталог и ветка удаляются вместе](images/git-worktree-delete.jpg)
