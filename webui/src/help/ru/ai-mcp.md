Сервер имеет встроенный хост Model Context Protocol, а раздел `MCP` веб-интерфейса его настраивает: код-агенты (Claude Code, Codex, Kimi Code, Pi, OpenCode, Qwen Code, DeepSeek Harness, …) могут подключаться из собственного чата и работать прямо на вашей машине — читать и управлять терминалами и даже управлять EasyEDA Pro.

## Настройки сервера

Включите MCP-сервер и настройте:

- `Port` (по умолчанию `6180`) и `Bind Address` — `127.0.0.1` оставляет эндпоинт только на localhost; `0.0.0.0` открывает его в сеть;
- `Access Token` — обязателен для запросов не с localhost: удалённые вызывающие должны предъявлять его как Bearer-токен, а запросы с localhost всегда допускаются. Он никогда не пуст — новая установка поставляет случайный токен; кубик перегенерирует его, кнопка копирования выдаёт;
- `Stream Throttle` — минимальный интервал между выталкиваниями экранного потока подключённым агентам.

Изменения применяются по `Save`; сервер перезагружается на лету без рестарта.

## Эндпоинты

Каждый набор возможностей обслуживается по своему URL `http://localhost:{port}/{id}/mcp`:

- **Terminal MCP** (`/terminal/mcp`) — встроенная терминальная поверхность. Агенты могут перечислять терминалы, читать видимый экран и прокрутку, вводить сырой текст и именованные клавиши, менять размер и ждать приглашение. Вызовы инструментов адресуют терминал по его Terminal ID — правый клик по терминалу → `MCP` → `Copy Terminal ID` и вставьте ID в контекст агента (см. Terminal MCP в разделе Terminals);
- **EasyEDA Pro MCP** (`/easyeda/mcp`) — встроенный MCP-аддон, мостящий EasyEDA Pro к агентам: небольшой фиксированный набор инструментов плюс каталог вызовов `eda.*` с поиском, пересылаемый расширению-коннектору EasyEDA по WebSocket. Сначала включите аддон в разделе `Addons` — его эндпоинт появится в списке после установки, а значок покажет, подключён ли демон аддона. Поле `Timeout` аддона ограничивает каждый мостовой запрос (увеличьте для медленных операций EDA);
- **Другие MCP-аддоны** — любой установленный аддон типа MCP добавляет свой эндпоинт так же, каждый со значком подключено/отключено в реальном времени.

Выберите CLI агента в выпадающем списке над таблицей; кнопка копирования рядом с эндпоинтом выдаст готовую к запуску команду настройки для этого приложения.

## Подключение агента

Токен никогда не вставляется вручную. Сервер ведёт сгенерированный профиль окружения `Vibe Terminal MCP Bearer Token` (см. раздел Environment Variables), экспортирующий `VTERM_MCP_TOKEN`; примените его к терминалу перед подключением агента и используйте скопированную команду:

- **Приложения с shell-командой** (Claude Code, Codex) — выполните скопированную команду `mcp add` в обычном терминале. Codex читает токен из `VTERM_MCP_TOKEN` через `--bearer-token-env-var`, так что секрет не попадает в командную строку;
- **Диалоговые приложения** (Kimi Code, Pi, OpenCode, Qwen Code, DeepSeek Harness) — запустите приложение с применённым профилем и отправьте скопированный промпт в его беседу. Агент сам обновит конфигурацию MCP. Kimi использует `bearerTokenEnvVar`; Pi, OpenCode и Qwen Code используют Bearer-токен из `VTERM_MCP_TOKEN`, поэтому сам токен никогда не появляется в чате.

В Pi и Qwen Code команда `/mcp` показывает соединения.

Карточка `Command Templates` под настройками хранит команды настройки по приложениям: правьте записи, переопределяйте встроенные или добавляйте шаблоны для новых CLI — предпросмотр показывает ровно то, что выдаст кнопка копирования.
