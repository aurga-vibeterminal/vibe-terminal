Контекстное меню списка веток сосредотачивает отправку, checkout и повседневные операции с ветками.

## Push

Правый клик по ветке → `Push '{branch}'...` открывает диалог отправки:

![Правый клик по ветке — пункт Push](images/git-push-contextmenu.jpg)

- он показывает сопоставление целей `local → remote`; любое из имён можно изменить (отправка в существующую удалённую ветку под другим именем запрашивает подтверждение);
- опции: `Push all branches`, `Set upstream` (привязать upstream при первой отправке), `Push tags`, `Dry run`;
- переписывающий историю `Force` и более безопасный `Force with lease` (отказывается, когда кто-то другой отправлял — предпочтительно). Операции, переписывающие историю, как отправка после rebase, требуют одного из них;
- в диалоге показывается предупреждение о риске принудительных отправок.

![Диалог отправки — цели local → remote и флажки опций](images/git-push-dialog.jpg)

## Checkout

Правый клик по ветке → `Checkout` для переключения ветки — локальные ветки извлекаются напрямую, а удалённая ветка или тег открывает диалог checkout:

![Правый клик по ветке — пункт Checkout](images/git-checkout-contextmenu.jpg)

- `New branch name` — создаваемая локальная ветка, предзаполненная из ссылки;
- `Create new local branch` (`-B`), `Track remote as upstream` (`--track`, только удалённые ветки), `Force` (`-f`), `Merge` (`--merge`).

![Диалог checkout — имя ветки и опции](images/git-checkout-dialog.jpg)

Рабочий каталог сессии следует переключению; терминал и панель Git отражают новую ветку немедленно.

## Отсоединённый HEAD

Извлечение чистого коммита (напр. checkout коммита при просмотре истории) отсоединяет HEAD. Следующий коммит тогда открывает диалог `Detached HEAD`: выберите существующую ветку для коммита, `+ Create new branch…` на месте или пока `Skip`.

## Прочие операции

- **Стэш** — застэшировать все изменения в стек (сообщение необязательно) из заголовка изменений; список `STASHES` поддерживает `Pop` (применить и удалить) и `Drop` (отбросить, необратимо);
- **Удаление веток/worktree** — через контекстное меню записи, оба с подтверждениями необратимых действий;
- **История и восстановление** — `HISTORY` перечисляет коммиты; правый клик для истории файла, diff с рабочим деревом или восстановления к ревизии;
- **Копирование** — имена веток и хэши коммитов копируются одним кликом, удобно для вставки агенту или коллеге.
