`Host with HTTP server` публикует любой каталог на сервере как HTTP-файловую службу одним кликом: другие устройства в той же сети (или через релей) — телефон, другой компьютер, испытательный стенд — могут просматривать и скачивать этот каталог из браузера. Идеально для обмена артефактами сборки и пакетами логов или передачи файлов устройствам без установленного клиента.

## Как использовать

Три входа, все на каталоге: контекстное меню списка файлов, контекстное меню записи Recent и контекстное меню хлебных крошек → `Host with HTTP server`.

Клик:

1. Сервер запускает статическую HTTP-службу с корнем в этом каталоге, порт берётся из диапазона Static HTTP;
2. **Локальный сервер**: URL `http://127.0.0.1:port/` копируется прямо в буфер обмена с сообщением «HTTP server: … (скопировано в буфер обмена)»;
3. **Удалённый сервер** (подключён через релей): клиент автоматически запрашивает сопоставление обратного прокси и копирует внешне достижимый URL общего доступа — ограничения LAN не помеха.

Откройте этот URL в браузере любого устройства — каталог просматривается и скачивается как обычный веб-листинг.

## Управление работающими службами

Каждая HTTP-служба работает, пока не остановлена:

- Откройте раздел `Static HTTP` веб-интерфейса; список `Services` показывает каждую работающую службу и её корень документов;
- у каждой записи кнопка остановки; диапазон портов настраивается на той же странице.

> Служба — список файлов только для чтения — без конечных точек записи; содержимое каталога видно вживую по мере изменения, что подходит для непрерывно создаваемых логов и артефактов.
