Проводник файлов оперирует файловой системой на стороне сервера. Панель инструментов вверху левой панели переключает Recent / Explorer / Git / Debug / Search; Explorer — файловый браузер.

## Кнопка Home: прыжок к cwd терминала

Нажмите кнопку `Home` (домик) на панели инструментов:

- Переключает на вид `Explorer`;
- Прыгает к **рабочему каталогу активного терминала** (его cwd);
- Закрепляет этот каталог деревом и очищает поле поиска — вы всегда начинаете от «где терминал, там и смотрите».

![Проводник файлов в обычном режиме — Home, хлебные крошки и плоский список](images/files-explorer.jpg)

## Режим дерева и поиск

- **Закрепить деревом**: кнопка булавки на правом конце хлебных крошек переключает плоский список и режим дерева. В режиме дерева папки раскрываются в сворачиваемое дерево каталогов (прыжок Home закрепляет автоматически);
- **Поиск**: поле поиска вверху фильтрует текущий список по имени по мере ввода; `Search in Folder` из контекстного меню Recent выполняет рекурсивный поиск по всему каталогу.

![Проводник файлов в режиме дерева — закреплённый корень раскрывается в сворачиваемое дерево каталогов](images/files-explorer-tree.jpg)

## Базовые операции

Правый клик по файлу или папке:

- **Создать**: `New Folder` / `New File`;
- **Изменить**: `Rename`; `Copy` / `Cut` / `Paste` (работает между каталогами);
- **Удалить**: `Delete`, с диалогом подтверждения;
- **Связь с терминалом**: `Open in Terminal` открывает новую вкладку терминала в этом каталоге; `cd to Directory` делает cd текущего терминала туда;
- **Связь с ОС**: `Reveal in File Explorer` показывает локальный каталог в системном файловом менеджере;
- **Пути**: `Copy Full Path` / `Copy Relative Path`;
- **Публикация**: `Host with HTTP server` публикует каталог как HTTP-файловую службу (см. Публикация через HTTP-сервер); `Open in App` открывает его приложением агента, обнаруженным на сервере.

Каждая операция действует на файловую систему на стороне сервера; удалённые сессии ведут себя точно как локальные.
