เมื่อคุณรันเอเจนต์โค้ด (Claude Code, Codex, Kimi, Pi, OpenCode…) ในเทอร์มินัล บทสนทนาของมันถูกขังอยู่ในหน้าต่างเทอร์มินัลนั้น — เลื่อนปนกับเอาต์พุตคำสั่ง หายไปเมื่อจอเลื่อนต่อ `ประวัติบทสนทนาเอเจนต์โค้ด` ยกบทสนทนาทั้งหมดขึ้นแผงเฉพาะ: ทุกการแลกเปลี่ยนแสดงแบบมีโครงสร้าง สลับบทสนทนาเก่าได้ แปลข้อความได้ — และส่งคำสั่งเข้าเทอร์มินัลจากแผงตรง ๆ ได้

## การเปิดแผง

กดปุ่มแชท (`AI`) ด้านขวาของแถบหัวเรื่องเพื่อสลับแผง Copilot ดรอปดาวน์ด้านบนรายชื่อ **บทสนทนาเก่าทั้งหมด** ของเอเจนต์ที่ทำงานในเซสชันเทอร์มินัลปัจจุบัน ใหม่สุดก่อน; เลือกหนึ่งเพื่อโหลด

## หลักการ

- เซิร์ฟเวอร์รู้ว่าแอปเอเจนต์ใดทำงานในเทอร์มินัลและแยกวิเคราะห์ **ไฟล์เซสชันเนทีฟ** ของมัน (รูปแบบ JSONL/ประวัติของแต่ละเอเจนต์ใต้ไดเรกทอรีโปรเจกต์); การเปลี่ยนไฟล์ไหลเข้าสด ๆ ทำให้มุมมองบทสนทนาล้สมัย;
- เอเจนต์ที่รองรับ: `claude` / `codex` / `kimi` / `pi` / `opencode`; แอปอื่นยังไม่มีแผงบทสนทนา;
- ข้อความมีบทบาท (คุณ / เอเจนต์) และชนิด (ข้อความ / การให้เหตุผล **Thinking**) พร้อมชื่อโมเดลและเวลา เรนเดอร์เป็น Markdown

## ความสามารถของแผง

- **สลับบทสนทนา**: ดรอปดาวน์ `Conversations` ด้านบนย้ายระหว่างเซสชันเก่า แต่ละรายการแสดงสรุปและเวลา;
- **แปล**: ข้อความเอเจนต์ใดก็ได้แปลเมื่อขอ; คำแปลแทนที่ข้อความในที่ (และสลับกลับได้);
- **ส่งคำสั่งโดยตรง**: พิมพ์ในกล่องล่าง (Shift+Enter ขึ้นบรรทัดใหม่) แล้วกด Enter — คำสั่งเข้าเทอร์มินัลปัจจุบันทันที เหมือนพิมพ์ในกล่องอินพุตของเอเจนต์เองโดยไม่ยึดมุมมองเทอร์มินัล

## ความสัมพันธ์กับฟีเจอร์อื่น

- แผงและเทอร์มินัลเป็นสองมุมมองของเซสชันเดียวกัน: คำถามของเอเจนต์ในเทอร์มินัลยังถูกตอบที่นั่น (หรือผ่านการยืนยันอัตโนมัติ); แผงไว้ทบทวนประวัติ ไม่ใช่ดักบทสนทนา;
- คู่กับ `Terminal MCP` (หน้าก่อน) เอเจนต์ภายนอกยังอ่านจอเทอร์มินัลและรันคำสั่งได้ — บทสนทนาที่แสดงที่นี่บวกการกระทำ MCP เป็นบันทึกงานของเอเจนต์ฉบับสมบูรณ์
