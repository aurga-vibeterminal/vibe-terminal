นอกเหนือจอเดสก์ท็อป เดสก์ท็อประยะไกลสตรีมอุปกรณ์ Android ได้ — โทรศัพท์จริงผ่าน adb และ AVD ไคลเอนต์แสดงมันในหน้าต่างกรอบโทรศัพท์พร้อมอินพุตสัมผัส การหมุน และการควบคุมวงจรชีวิตโปรแกรมจำลองจากระยะไกล

## ข้อกำหนดเบื้องต้น

เซิร์ฟเวอร์ต้องหาชุดเครื่องมือ Android:

- **Android SDK** (มี `adb`) — จำเป็นทั้งอุปกรณ์และโปรแกรมจำลอง;
- **Android Studio** — จำเป็นเพื่อบูต AVD

ทั้งคู่ตรวจอัตโนมัติโดยค่าเริ่มต้น ถ้าการตรวจล้มเหลวหรือเครื่องมืออยู่นอกที่มาตรฐาน ตั้ง `Android SDK directory` / `Android Studio directory` ใต้ `Remote Desktop` → `Screen streaming tools`; การเปลี่ยนแปลงมีผลทันที (ใช้แบบร้อน ไม่ต้องรีสตาร์ทเซิร์ฟเวอร์)

## แหล่งอุปกรณ์

เมื่อเส้นทางพร้อม เซิร์ฟเวอร์ระบุแหล่ง Android ที่มีอัตโนมัติ:

- **อุปกรณ์จริงที่เสียบ** — เสียบ USB โดยเปิด USB debugging; สิ่งที่ `adb devices` เห็นสตรีมได้;
- **AVD** — โปรแกรมจำลองที่รันอยู่โผล่เอง; ยังบูต AVD ที่เลือกตามคำขอจากไคลเอนต์ได้ (ไม่ต้องเปิดเองก่อน) และปิดจากระยะไกลได้

แต่ละแหล่งได้รายการของตัวเองในแถบ SCREENS ของไคลเอนต์

## การวางแนว

ปุ่มหมุนของหน้าต่างโปรแกรมจำลองตั้ง `user_rotation` ของระบบผ่าน `adb` — ทิศทางจอของอุปกรณ์เองเปลี่ยน และหน้าต่างจัดใหม่ตามความละเอียดใหม่ รองรับทั้งแนวตั้งและแนวนอน

## ฝั่งไคลเอนต์

เปิดแท็บ `Debug` ในแผงซ้ายของไคลเอนต์เดสก์ท็อปและคลิกปุ่ม `Android Simulator` ในแถบ SCREENS (ปรากฏเฉพาะเมื่อเซิร์ฟเวอร์เปิดแหล่ง Android) เพื่อเปิดหน้าต่างโปรแกรมจำลอง; ตัวเลือกอุปกรณ์เปลี่ยนหน้าตากรอบโทรศัพท์และ `Rotate` พลิกการวางแนว ดู การใช้งานไคลเอนต์

> การฉีดสัมผัสบนอุปกรณ์จริงใช้ช่องอินพุตของ adb (Android 4.4+); ROM บางค่าของผู้ผลิตจำกัด อุปกรณ์จึงดูอย่างเดียวในกรณีนั้น
