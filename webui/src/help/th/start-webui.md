Web UI คือหน้ากำหนดค่าของตัวเซิร์ฟเวอร์เอง: ฟีเจอร์ของเซิร์ฟเวอร์ทุกตัวถูกจัดเป็นส่วน ๆ แสดงในแถบด้านข้างซ้าย มันไม่ใช่เทอร์มินัล — งานประจำวันทำในไคลเอนต์เดสก์ท็อปหรือ `vtermc` (ดู ภาพรวม) หน้านี้อธิบายโครงสร้างและพฤติกรรมทั่วไป; บทฟีเจอร์อธิบายการตั้งค่าของแต่ละส่วนโดยละเอียด

## การจัดวาง

- **แถบด้านข้าง** — รายการส่วนต่าง ๆ (ด้านล่าง) ไอคอนช่วยเหลือข้างชื่อเซิร์ฟเวอร์ และเวอร์ชันของแอปที่ด้านล่าง; บนจอแคบเลื่อนเข้ามาจากซ้ายและปุ่ม hamburger ในส่วนหัวสลับการแสดงผล;
- **ส่วนหัว** — ชื่อส่วนปัจจุบัน บวกตัวเลือกภาษาและตัวสลับธีมสว่าง/มืดที่มุมขวาบน (บนจอแคบไอคอนช่วยเหลืออยู่ตรงนั้นด้วย);
- **เนื้อหา** — แบบฟอร์มของส่วนที่เลือก จัดกึ่งกลางและเลื่อนดูได้

## ส่วนต่าง ๆ

เรียงตามลำดับในแถบด้านข้าง:

- `เซิร์ฟเวอร์` — การตั้งค่าพอร์ต ใบรับรอง TLS และการยืนยันตัวตน: `Secret Key`, `QR Code` สำหรับการจับคู่ ที่อยู่รีเลย์ และสวิตช์ `Auto-start on Login` อยู่ในส่วนนี้ทั้งหมด (ดู การเชื่อมต่อไคลเอนต์ และ คู่มือการตั้งค่า) บน Linux คำใบ้ของ `Auto-start on Login` ยังอธิบายการล็อกอินอัตโนมัติของ display manager สำหรับการเข้าถึงเดสก์ท็อปก่อนที่จะมีการล็อกอินในเครื่อง (ดู การตั้งค่าเซิร์ฟเวอร์ ในเดสก์ท็อประยะไกลและโปรแกรมจำลอง);
- `Terminal` — การวิเคราะห์เทอร์มินัล: การตรวจจับพรอมต์ การยืนยันอัตโนมัติ และการจำแนกด้วย LLM (ดู ยืนยันอัตโนมัติ);
- `UART` — โปรไฟล์เทอร์มินัลอนุกรมที่ใช้พอร์ต UART ท้องถิ่น (ดู พอร์ตอนุกรม UART);
- `ส่วนเสริม` — ส่วนเสริมที่ติดตั้งแล้ว: เปิดใช้ แก้ไข หรืออัปโหลดได้ (ผู้ให้บริการ LLM คือส่วนเสริม — ดู LLM);
- `LLM` — กำหนดผู้ให้บริการ LLM ให้แต่ละฟีเจอร์ AI (ดู LLM);
- `เสียง` — การตั้งค่าผู้ให้บริการการรู้จำเสียง โมเดล และการถอดความ (ดู การตั้งค่าเซิร์ฟเวอร์ ในการป้อนข้อมูลด้วยเสียง);
- `สภาพแวดล้อม` — ชุดตัวแปรสภาพแวดล้อมในต้นไม้ของกลุ่มย่อย (ดู ตัวแปรสภาพแวดล้อม);
- `MCP` — เซิร์ฟเวอร์ MCP เทอร์มินัลที่เปิดให้เอเจนต์โค้ด (ดู เทอร์มินัล MCP);
- `DDNS` — การตั้งค่าผู้ให้บริการ DDNS และการซิงก์ (ดู DDNS);
- `การส่งต่อพอร์ต` — ชุดพอร์ตที่ส่งต่อและการส่งต่อ TLS ที่ทำงานอยู่ (ดู การส่งต่อพอร์ต);
- `Static HTTP` — โฟลเดอร์ที่โฮสต์ผ่าน HTTP และการแชร์ไฟล์ที่เปิดใช้งานอยู่ (ดู เผยแพร่ด้วยเซิร์ฟเวอร์ HTTP);
- `เดสก์ท็อประยะไกล` — การตั้งค่าการจับภาพ อินพุต และสตรีมสำหรับเดสก์ท็อประยะไกล (ดู การตั้งค่าเซิร์ฟเวอร์ ในเดสก์ท็อประยะไกลและโปรแกรมจำลอง);
- `สถิติ LLM` — การใช้ token จำนวนคำขอ และเมทริกประสิทธิภาพทุกฟีเจอร์ LLM

## การบันทึกและเคล็ดลับ

- ส่วนใหญ่บันทึกอัตโนมัติไม่นานหลังแก้ไข — ตัวบ่งชี้การบันทึกและข้อผิดพลาด (ถ้ามี) ปรากฏที่ด้านล่างของส่วน;
- `MCP`, `DDNS` และ `เดสก์ท็อประยะไกล` ค้างการแก้ไขจนกว่าจะกด `บันทึกการเปลี่ยนแปลง`: ระหว่างที่ยังมีการแก้ไขค้างอยู่ คำใบ้ `การเปลี่ยนแปลงที่ยังไม่ได้บันทึก` จะปรากฏข้างปุ่ม และ `รีเซ็ต` ทิ้งการแก้ไขเหล่านั้น;
- เมื่อเปิดจากไคลเอนต์มือถือ Web UI จะตามภาษาและธีมของแอปและซ่อนตัวเลือกภาษาและธีมของตัวเอง
