## เบราว์เซอร์เตือนว่า “การเชื่อมต่อของคุณไม่เป็นส่วนตัว” — เป็นเรื่องปกติหรือไม่

เป็นเรื่องปกติ พอร์ตที่ส่งต่อ Web UI และการเชื่อมต่อไคลเอนต์ใช้ใบรับรองแบบลงนามเองของเซิร์ฟเวอร์ใบเดียวกัน ตัวการเข้ารหัสเองไม่ได้ถูกทำลาย หากต้องการปิดคำเตือนนี้ถาวร ให้นำเข้าใบรับรองของเซิร์ฟเวอร์เข้าสู่ที่เก็บใบรับรองที่เชื่อถือของอุปกรณ์

## Vibe Terminal ฟรีหรือไม่

ฟรี — ไคลเอนต์/เซิร์ฟเวอร์เดสก์ท็อปและเซิร์ฟเวอร์ headless ฟรีทั้งหมด ดาวน์โหลดและติดตั้งได้กี่เครื่องก็ตามใจ

## ข้อมูลของฉันไปไหน

ไม่ไปไหนนอกจากที่คุณเป็นคนวางไว้เอง เซสชัน ข้อมูลรับรอง (enc-v2:) และการรู้จำเสียงพูดล้วนอยู่บนเครื่องของคุณ คีย์จับคู่ไม่เดินทางเป็นข้อความธรรมดาเด็ดขาด

## เปิดเผยบริการที่ส่งต่อได้อย่างปลอดภัยหรือไม่

ได้ การแชร์ในตัวต้องมีโทเคน: ลิงก์ที่ไคลเอนต์สร้างให้การแชร์ `Host with HTTP server` และหน้า Settings ล้วนแนบโทเคนการเข้าถึงมาด้วย การเชื่อมต่อที่ไม่มีโทเคนหรือเซสชันที่ถูกต้องจะถูกตัดทิ้งก่อนส่งอะไรออกไป เมื่อเข้าชมครั้งแรกโทเคนจะถูกแลกเป็นคุกกี้เซสชันที่ปลอดภัยซึ่งใช้ได้เฉพาะบริการนั้นและหายไปจาก URL — ticket ของ Settings ใช้ได้เพียงครั้งเดียวและหมดอายุภายในหนึ่งนาที ส่วนการหยุดหรือรีสตาร์ทบริการจะทำให้ลิงก์และเซสชันเดิมใช้ไม่ได้ จงถือว่าลิงก์ฉบับเต็มคือข้อมูลรับรองและมอบให้เฉพาะผู้ที่คุณไว้วางใจ การส่งต่อไปยังบริการของคุณเองเพิ่มแค่ TLS ด้วยใบรับรองของเซิร์ฟเวอร์โดยไม่เพิ่มการยืนยันตัวตน — จงวางการยืนยันตัวตนไว้หน้าบริการที่อ่อนไหว และรื้อการส่งต่อทิ้งทันทีจากแผงส่งต่อพอร์ตเมื่อใช้เสร็จ
