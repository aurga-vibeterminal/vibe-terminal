ทุกเทอร์มินัลเป็นพลเมืองชั้นหนึ่งของ MCP (Model Context Protocol): เอเจนต์ภายนอกขับเทอร์มินัลผ่านเครื่องมือ MCP ของเซิร์ฟเวอร์ — รายชื่อเทอร์มินัล อ่านจอ รันคำสั่ง รอจนเสร็จ — ทำให้เอเจนต์เขียนโค้ดที่คุณใช้อยู่แล้วขับเชลล์โต้ตอบจริง

## เครื่องมือ MCP เทอร์มินัลของเซิร์ฟเวอร์

รอบเซสชันเทอร์มินัล ไคลเอนต์ MCP สามารถ:

- `list_terminals` — เทอร์มินัลที่เปิดทั้งหมด; `get_terminal` — ชื่อ cwd และสถานะแอปของหนึ่งเทอร์มินัล;
- `get_screen` — ข้อความจอที่มองเห็นปัจจุบัน; `get_scrollback` — บรรทัดประวัติล่าสุด;
- `send_command` — รันบรรทัดคำสั่ง (ต่อท้าย Enter); `send_input` — ข้อความดิบไม่มี Enter (ยืนยัน `y`, กรอกฟอร์ม); `send_key` — ปุ่มที่ระบุชื่อ (Enter, Ctrl+C, ลูกศร);
- `clear_terminal` — ล้างบัฟเฟอร์; `resize_terminal` — ปรับขนาด PTY; `wait_terminal` — บล็อกจนเทอร์มินัลไม่ยุ่ง

## การชี้เป้าเทอร์มินัล: Terminal ID

การเรียกเครื่องมือเล็งเทอร์มินัลด้วย Terminal ID ของมัน คลิกขวาในเทอร์มินัล → `MCP` → `Copy Terminal ID` แล้ววาง ID ให้เอเจนต์ของคุณเพื่อขับเทอร์มินัลนั้นเป๊ะ ๆ

## ลงทะเบียนแอปเอเจนต์คลิกเดียว

เมนูย่อย `MCP` ยังรายชื่อแอปเอเจนต์ที่ตรวจพบบนเซิร์ฟเวอร์ (CLI เอดิเตอร์และอื่น ๆ) การคลิกแอปจะพิมพ์คำสั่ง `mcp add` สำเร็จรูปลงเทอร์มินัล — **โดยไม่มีบรรทัดใหม่ท้ายสุด**; ตรวจสอบแล้วกด Enter เองเพื่อลงทะเบียนบริการ MCP ของเซิร์ฟเวอร์นี้กับเอเจนต์นั้น รายการซ่อนระหว่างที่แอปทำงานอยู่ในเซสชัน เพื่อข้อความไม่ตกลงใน UI ของแอป

> วงจรทั่วไป: คัดลอก Terminal ID ให้เอเจนต์ → `send_command` เริ่ม build → `wait_terminal` จนเสร็จ → `get_screen` อ่านผลลัพธ์ ควบคู่การยืนยันอัตโนมัติ (ดูบทเทอร์มินัล) งานโต้ตอบยาว ๆ รันแทบไม่ต้องเฝ้า
