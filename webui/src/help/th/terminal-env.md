ตัวแปรสภาพแวดล้อมช่วยให้คุณดูแลชุดตัวแปรแบบกลุ่มรายโปรเจกต์ (`ANDROID_HOME`, คีย์ API, การตั้งค่าพรอกซี) และใช้หรือล้างบนเซสชันเทอร์มินัลใดก็ได้ด้วยคลิกเดียว อยู่ในการตั้งค่าเซิร์ฟเวอร์; ค่าถูกเข้ารหัสขณะพัก

## การดูแลใน Web UI

ส่วน `Environment Variables` จัดเป็นต้นไม้:

- **กลุ่ม** — คอนเทนเนอร์ล้วน ซ้อนกันได้ (คลิกขวา → `New Group`) สำหรับจัดตามโปรเจกต์หรือสถานการณ์;
- **คอลเลกชัน** — ใบของต้นไม้และที่เก็บตัวแปรจริง (`New Leaf`); เฉพาะคอลเลกชันเท่านั้นที่ใช้กับเทอร์มินัลได้;
- คู่คีย์/ค่าของแต่ละคอลเลกชันแก้ผ่าน `Edit Variables` (`Add Variable`); ค่าซ่อนโดยค่าเริ่มต้น;
- คอลเลกชันทำสำเนาเพื่อสร้างตัวแปรได้ (ชุดเดิมเปลี่ยนหนึ่งคีย์)

## การใช้กับเทอร์มินัล

คลิกขวาในเทอร์มินัล → `Envs`:

- เมนูย่อยสะท้อนต้นไม้จาก Web UI; ขยายคอลเลกชันและเลือก `Apply` เพื่อฉีดตัวแปรเข้าเซสชันปัจจุบัน หรือ `Clear` เพื่อลบออก;
- โพรเซสที่เพิ่งเริ่มเห็นตัวแปร (โปรแกรมเบื้องหน้าที่กำลังรันอยู่ไม่เห็น);
- คอลเลกชันแสดงพับอยู่ใต้กลุ่มของมัน; รายการ `Envs` ทั้งหมดซ่อนเมื่อต้นไม้ไม่มีคอลเลกชัน
