แอดออนขยายความสามารถของเซิร์ฟเวอร์โดยไม่แตะแกนกลาง: ผู้ให้บริการ LLM แบ็กเอนด์จำแนกเสียง ตัวอัปเดต DNS แบบไดนามิก พื้นผิวเครื่องมือ MCP เพิ่มเติม และการตรวจจับแอปเอเจนต์โค้ด ล้วนอยู่ในรูปแอดออน ส่วน `Addons` ของ Web UI จัดการสิ่งเหล่านี้

## หมวดหมู่

แอดออนแต่ละตัวประกาศ type และส่วนนี้จัดกลุ่มการ์ดตามนั้น:

- **Applications** — สอนตัวสังเกตเทอร์มินัลให้รู้จัก CLI ของเอเจนต์โค้ด (Claude Code, Codex, Kimi Code, Pi และ OpenCode ในตัว): ตรวจจับโปรเซส สถานะยุ่ง/ว่าง ฮุกอัตโนมัติ；
- **LLM Providers** — แบ็กเอนด์เติมเต็มแชตให้ฟีเจอร์ AI เลือก (มีผู้ให้บริการที่เข้ากันได้กับ OpenAI ในตัว)；
- **Voice / ASR** — แบ็กเอนด์จำแนกเสียง (แอดออน `vibe-voice` ในตัวชี้ไปที่เซิร์ฟเวอร์ ASR ท้องถิ่นที่ถูกคุม)；
- **Dynamic DNS** — ทำให้ชื่อโฮสต์ตามที่อยู่ปัจจุบัน (Cloudflare ในตัว)；
- **MCP** — พื้นผิวเครื่องมือ MCP เพิ่มเติมบนโฮสต์ MCP (EasyEDA Pro ในตัว)；
- ที่เหลือหล่นไปกลุ่ม **Other**

## แอดออนในตัวและที่อัปโหลด

- แอดออน**ในตัว**มาพร้อมโปรแกรมและใช้ได้เสมอ manifest กับซอร์สคงต้นฉบับ — ซอร์สที่ถูกเขียนทับกู้คืนได้ทุกเมื่อ；
- แอดออน**ที่อัปโหลด**คือของคุณ: zip ที่บรรจุ manifest และซอร์ส JavaScript ติดตั้งผ่านปุ่ม `Upload Addon`；
- ป้าย `Modified` บอกว่าคุณเคยเขียนทับซอร์สของแอดออนนั้น

แต่ละการ์ดแสดง type ป้าย และสวิตช์เปิดใช้; ขยายออกจะเห็นคำอธิบาย ผู้เขียน ช่องการตั้งค่า และซอร์สโค้ด

## การตั้งค่า

manifest ของแอดออนประกาศช่องการตั้งค่า และการ์ดที่ขยายเปลี่ยนเป็นฟอร์ม ค่าเก็บต่อแอดออนและมีผลเฉพาะขณะเปิดใช้; ช่องรหัสผ่านยังถูกปิดบัง การปิดแอดออนเก็บการตั้งค่าไว้ — เปิดใหม่ก็ทำต่อจากเดิม
