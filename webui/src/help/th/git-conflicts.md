เมื่อ rebase หรือ merge เจอความขัดแย้ง แผงสลับไปมุมมองความขัดแย้ง: รายการไฟล์ขัดแย้งซ้าย ตัวแก้ merge ขวา ไฟล์ขัดแย้งยังปรากฏในรายการ `CHANGES` พร้อมป้าย `!` — คลิกหนึ่งจะกระโดดตรงเข้ามุมมองนี้แทน diff เปล่า ตัวแก้มีสี่โหมดแก้และสลับได้ตลอดเวลา

## รายการไฟล์ขัดแย้ง

ไฟล์จัดกลุ่มตามสถานะ: ที่ merge อัตโนมัติสำเร็จ (stage อัตโนมัติ) กับที่ยังต้องดูแลมือ คลิกไฟล์เปิดในตัวแก้; รายการอัปเดตสดระหว่างแก้จนว่าง

## สี่โหมดการแก้

- **Merge** (ค่าเริ่มต้น) — ความขัดแย้งแสดง hunk ต่อ hunk; ต่อ hunk เลือก `take ours` / `take theirs` หรือแก้ผล merge ในบรรทัด;
- **Split** — diff แตกเป็นชิ้นระดับบรรทัดละเอียดกว่า สองฝั่งรับทีละชิ้นใน hunk เดียวได้;
- **Raw** — แก้ธรรมดาด้วยเครื่องหมายความขัดแย้ง `diff3` (`<<<<<<<` / `=======` / `>>>>>>>`) สำหรับปรับมือ;
- **AI** — เอเจนต์แก้ไฟล์ hunk ต่อ hunk: LLM วิเคราะห์ hunk ขัดแย้งแต่ละอันและผลิตการ์ดคำตอบพร้อมคำอธิบายและความมั่นใจ คุณพิมพ์คำสั่งคัดเลือกกลยุทธ์ได้ (เช่น "เอา theirs ล้วน เก็บบรรทัด log") พัก ปรับในโหมดอื่น และทำต่อ — hunk ที่แก้แล้วถูกข้าม

ทุกโหมดผลถูกเขียนลงไฟล์ในเซสชันของคุณและ stage เหมือนการแก้มือเป๊ะ

## ต่อ rebase

เมื่อทุกความขัดแย้งถูกแก้ rebase ไปคอมมิตถัดไป; หรือยกเลิกตลอดเวลาเพื่อกลับสู่สถานะก่อน rebase
