เชาวน์ปัญญาของแผง Git ขับเคลื่อนด้วย LLM: ข้อความคอมมิตคลิกเดียว การอ่าน diff โดย AI ช่วย และการแก้ความขัดแย้งโดยเอเจนต์ hunk ต่อ hunk ทั้งหมดพึ่งผู้ให้บริการ LLM ที่ตั้งไว้ใน Web UI

## การตั้งค่าผู้ให้บริการ

เปิดส่วน `LLM` ของ Web UI:

- เลือก `Provider` และกรอกข้อมูลรับรอง (ฟิลด์กำหนดโดยแมนิเฟสต์ของผู้ให้บริการ); การตั้งค่าเป็นแบบรวม — การจำแนกเทอร์มินัล ข้อความคอมมิต Git ผู้ช่วยแชท และฟีเจอร์ AI อื่นใช้ผู้ให้บริการเดียวกัน;
- ผู้ให้บริการเป็น addon ชนิด LLM: ทั่วไปมีในตัว และแบบกำหนดเองอัปโหลดเป็น zip ได้ในส่วน `Addons` (แมนิเฟสต์ประกาศฟิลด์ตั้งค่าที่ Web UI เปลี่ยนเป็นแบบฟอร์ม)

## ฟีเจอร์ LLM ใน Git

- **สร้างข้อความคอมมิต** — กดปุ่ม AI ข้างกล่องคอมมิต; LLM อ่าน diff ที่ stage และเขียนข้อความ พิมพ์ลงกล่องพร้อมแอนิเมชัน ข้อความยังแก้ไขได้ — commit เมื่อพอใจเท่านั้น;
- **วิเคราะห์ diff** — ปุ่มประกายในหัวมุมมอง diff วิเคราะห์ diff ปัจจุบัน;
- **เอเจนต์ AI ความขัดแย้ง** — โหมด AI ของตัวแก้ merge ใน rebase แก้ hunk ทีละอันพร้อมคำอธิบายและความมั่นใจ (ดู แก้ความขัดแย้ง)

![ข้อความคอมมิตที่ AI สร้าง พิมพ์ลงกล่องคอมมิต](images/git-llm-commit-message.jpg)

> LLM อ่านเนื้อหา repo เพื่อผลิตข้อความเท่านั้น; คอมมิตและ merge เกิดขึ้นเมื่อคุณยืนยันเสมอ
