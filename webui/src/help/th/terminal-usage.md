เทอร์มินัลคือหัวใจของ Vibe Terminal: แต่ละแท็บรองรับหนึ่งหรือหลายเซสชันเทอร์มินัล สามารถแบ่งเป็นแผ่นหน้าต่าง หรือลากออกไปเป็นหน้าต่างของตัวเอง เทอร์มินัลเข้าถึงเซิร์ฟเวอร์ท้องถิ่น ตลอดจนเซิร์ฟเวอร์ระยะไกลและแชร์ผ่านรีเลย์

## การสร้างเทอร์มินัล

- กดปุ่ม `+` บนแถบหัวเรื่องเพื่อเปิดแท็บด้วยโปรไฟล์เริ่มต้น;
- กดลูกศรชี้ลงข้าง `+` เพื่อเปิดเมนูโปรไฟล์: โปรไฟล์เทอร์มินัลจัดกลุ่มตามเซิร์ฟเวอร์ (ท้องถิ่น, เชื่อมต่อ, แชร์) — ขยายกลุ่มและเลือกโปรไฟล์เพื่อเปิดเทอร์มินัลบนเซิร์ฟเวอร์นั้น;
- ลากโฟลเดอร์ท้องถิ่นไปบนแถบหัวเรื่องแล้วปล่อยเพื่อเปิดแท็บใหม่ด้วยไดเรกทอรีทำงานนั้น (เฉพาะเซิร์ฟเวอร์ท้องถิ่น; สิ่งที่ปล่อยต้องเป็นโฟลเดอร์)

![แถบหัวเรื่อง — ปุ่มแท็บใหม่และเมนูโปรไฟล์](images/terminal-usage-creation.jpg)

## การจับเมาส์กับเมนูคลิกขวา

- คลิกขวาในเทอร์มินัลเปิดเมนูคลิกขวาของมัน: วาง, แบ่งแผ่นหน้าต่าง, คำสั่งด่วน, คอลเลกชันสภาพแวดล้อม, คัดลอกข้อความทั้งหมด, คำสั่งตั้งค่า MCP และอื่น ๆ ขึ้นกับเซสชัน;
- แอปที่จับเมาส์ (opencode, pi, vim, tmux, htop, …) จะรับอีเวนต์เมาส์แทน — กด `Shift` ค้างไว้เพื่อทำงานปกติได้เหมือนเดิมแม้แอปดังกล่าวกำลังทำงาน:
  - **คัดลอกข้อความ**: กด `Shift` ค้างแล้วเลือกข้อความ จากนั้นคลิกที่อื่นโดยยังกด `Shift` อยู่เพื่อยกเลิกการเลือก ข้อความที่เลือกจะถูกคัดลอกไปยังคลิปบอร์ด;
  - **เมนูคลิกขวา**: `Shift` + คลิกขวา หรือ `Ctrl` + คลิกขวาเปิดเมนูคลิกขวา; การคลิกขวาขณะกดปุ่มซ้ายค้างไว้ก็เปิดได้เช่นกัน (จะยกเลิกการเลือกก่อน);
  - **ลิงก์**: `Shift` + คลิกเปิดลิงก์ได้ตามปกติ

## การแบ่งและการจัดระเบียบด้วยการลาก

- **แบ่ง**: คลิกขวาในเทอร์มินัล → `Split` → `Left` / `Right` / `Top` / `Bottom` แบ่งแท็บเป็นแผ่นหน้าต่าง แต่ละแผ่นเป็นเทอร์มินัลอิสระ;

  ![การแบ่งแท็บ — เมนู Split จากคลิกขวาและแผ่นหน้าต่างที่ได้](images/terminal-usage-split.gif)

- **รวมด้วยการลาก**: ลากแท็บไปบนเทอร์มินัลอื่นแล้วโซนวางจะปรากฏ (ซ้าย/ขวา/บน/ล่าง); ปล่อยเพื่อรวมแท็บเข้ากับแท็บเป้าหมายเป็นแผ่นใหม่;

  ![การรวมด้วยการลาก — แท็บที่ปล่อยบนเทอร์มินัลอื่นกลายเป็นแผ่นใหม่](images/terminal-usage-merge.mp4)

- **แยกออกเป็นหน้าต่าง**: ลากแท็บออกจากแถบแท็บ (หรือไปบนหน้าต่างอื่น) แล้วแท็บทั้งหมดจะออกจากหน้าต่างเดิมเป็นหน้าต่างใหม่ เซสชันทำงานบนเซิร์ฟเวอร์เสมอ — การแบ่ง รวม และลากไม่ขัดจังหวะคำสั่งที่กำลังทำงาน

## แท็บและกลุ่มแท็บ

- **แท็บ** — หนึ่งแท็บเทอร์มินัล อาจมีหลายแผ่นที่แบ่งไว้;
- **กลุ่มแท็บ** — ตัวจัดระเบียบแท็บ โดยค่าเริ่มต้นกลุ่มตามเซิร์ฟเวอร์: แท็บของเซิร์ฟเวอร์ท้องถิ่นอยู่ใน `Ungrouped` และเซิร์ฟเวอร์แชร์แต่ละตัวได้กลุ่ม `Name (Server)`; รองรับกลุ่มแบบกำหนดเอง;
- **กลุ่มและหน้าต่าง** — แต่ละหน้าต่างแสดงหนึ่งกลุ่มที่ใช้งานผ่านตัวเลือกกลุ่มบนแถบหัวเรื่อง (หรือ `All`); `Move Group to New Window` ฉีกทั้งกลุ่มออกเป็นหน้าต่างของตัวเอง อุทิศหน้าต่างหรือจอให้เครื่องหนึ่ง;
- **กลุ่มและเซิร์ฟเวอร์** — กลุ่มจำเซิร์ฟเวอร์ของตัวเอง การสลับกลุ่มจึงโฟกัสกลับไปยังพื้นที่ทำงานของเซิร์ฟเวอร์; เมนูโปรไฟล์ตามกลุ่มที่ใช้งานและแสดงเฉพาะโปรไฟล์ของเซิร์ฟเวอร์ที่เกี่ยวข้อง
