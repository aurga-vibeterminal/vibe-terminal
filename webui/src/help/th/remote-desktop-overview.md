เดสก์ท็อประยะไกลให้คุณดูและควบคุมหน้าจอของเซิร์ฟเวอร์จากไคลเอนต์เดสก์ท็อปแบบเรียลไทม์: เดสก์ท็อปของเครื่องถูกสตรีมมาเป็นหน้าต่างฝั่งคุณ พร้อมฉีดเมาส์และคีย์บอร์ดของคุณ — เหมือนนั่งอยู่ตรงหน้ามัน นอกเหนือจอเดสก์ท็อป โปรแกรมจำลอง Android และ iOS สามารถดูและขับเคลื่อนในหน้าต่างกรอบโทรศัพท์

## ความสามารถ

- **จอเดสก์ท็อป** — จอฟิสิคัลแต่ละจอบนเซิร์ฟเวอร์ถูกสตรีมไปหน้าต่างไคลเอนต์ของตัวเองที่ย่อ-ขยายได้;
- **อุปกรณ์ / โปรแกรมจำลอง Android** — อุปกรณ์ที่เสียบและ AVD ปรากฏเป็นแหล่งสตรีม ดูและแตะได้ในหน้าต่างกรอบโทรศัพท์ พร้อมหมุนและสั่งเปิด/ปิดโปรแกรมจำลองจากระยะไกล;
- **โปรแกรมจำลอง iOS** (เซิร์ฟเวอร์ macOS) — ดูโปรแกรมจำลอง iOS ของ Xcode ในหน้าต่างกรอบโทรศัพท์พร้อมตัวเลือกอุปกรณ์และการหมุน

## หลักการ

เซิร์ฟเวอร์จับภาพจอและเข้ารหัสด้วยตัวเข้ารหัส อัตราเฟรม เพดานความละเอียดและบิตเรตที่ตั้งได้; ไคลเอนต์ถอดรหัสเป็นหน้าต่างลอยและส่งเหตุการณ์อินพุตกลับผ่านการเชื่อมต่อไคลเอนต์-เซิร์ฟเวอร์ที่เข้ารหัสอยู่เดิม — ไม่มีพอร์ตเพิ่ม

การเตรียมต่างกันตามแพลตฟอร์ม: Windows รันเซิร์ฟเวอร์จอเป็นบริการระบบได้และต้องใช้ไดรเวอร์จอเสมือนบนเครื่อง headless; Linux ใช้ความยินยอม Portal บวกปลดล็อกเซสชัน; macOS ต้องการสิทธิ์บันทึกจอ ดู การตั้งค่าเซิร์ฟเวอร์; อุปกรณ์ Android อยู่ใน อุปกรณ์ Android และหน้าต่างไคลเอนต์ใน การใช้งานไคลเอนต์
