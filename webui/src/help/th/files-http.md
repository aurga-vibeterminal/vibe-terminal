`Host with HTTP server` เผยแพร่ไดเรกทอรีใดก็ได้บนเซิร์ฟเวอร์เป็นบริการไฟล์ HTTP ด้วยคลิกเดียว: อุปกรณ์อื่นบนเครือข่ายเดียวกัน (หรือผ่านรีเลย์) — โทรศัพท์ คอมพิวเตอร์อีกเครื่อง ชุดทดสอบ — สามารถท่องและดาวน์โหลดไดเรกทอรีนั้นจากเบราว์เซอร์ เหมาะแก่แชร์ผลลัพธ์ build และชุดล็อก หรือส่งไฟล์ให้อุปกรณ์ที่ไม่ได้ติดตั้งไคลเอนต์

## วิธีใช้

สามทางเข้า ล้วนอยู่บนไดเรกทอรี: เมนูคลิกขวาของรายการไฟล์ เมนูคลิกขวาของรายการ Recent และเมนูคลิกขวาของเส้นทางย่อย → `Host with HTTP server`

เมื่อคลิก:

1. เซิร์ฟเวอร์เริ่มบริการ HTTP คงที่มีรากที่ไดเรกทอรีนั้น โดยพอร์ตมาจากช่วงพอร์ต Static HTTP;
2. **เซิร์ฟเวอร์ท้องถิ่น**: URL `http://127.0.0.1:port/` ถูกคัดลอกตรง ๆ ไปคลิปบอร์ด พร้อมข้อความสถานะ "HTTP server: … (คัดลอกไปคลิปบอร์ดแล้ว)";
3. **เซิร์ฟเวอร์ระยะไกล** (เชื่อมผ่านรีเลย์): ไคลเอนต์ขอ mapping reverse proxy อัตโนมัติและคัดลอก URL แชร์ที่เข้าถึงจากภายนอกได้ — ข้อจำกัด LAN ไม่ใช่อุปสรรค

เปิด URL นั้นในเบราว์เซอร์ของอุปกรณ์ใดก็ได้ ไดเรกทอรีจะท่องและดาวน์โหลดได้เหมือนรายการเว็บปกติ

## การจัดการบริการที่รันอยู่

บริการ HTTP แต่ละตัวรันต่อไปจนถูกหยุด:

- เปิดส่วน `Static HTTP` ของ Web UI; รายการ `Services` แสดงทุกบริการที่รันและรากเอกสารของมัน;
- แต่ละรายการมีปุ่มหยุด; ช่วงพอร์ตตั้งค่าในหน้าเดียวกัน

> บริการเป็นรายการไฟล์อ่านอย่างเดียว — ไม่มี endpoint เขียน; เนื้อหาไดเรกทอรีเห็นสด ๆ ตามการเปลี่ยนแปลง เหมาะกับล็อกและผลลัพธ์ที่ผลิตต่อเนื่อง
