การแปลภาษาเปลี่ยนข้อความที่คุณพบในไคลเอนต์ให้เป็นภาษาที่คุณเลือก: การตอบกลับในแชท AI, ข้อความคอมมิต, คอมเมนต์ในโค้ด หรือการเลือกข้อความใด ๆ ในตัวแก้ไขโค้ดหรือใน diff งานนี้ทำโดยโมเดลแปลภาษาที่กำหนดค่าไว้บนเซิร์ฟเวอร์ — ไคลเอนต์แค่ส่งข้อความ เรนเดอร์ผลลัพธ์ และแคชไว้เพื่อให้คุณสลับไปมาระหว่างต้นฉบับกับคำแปลได้

## ที่ใดใช้การแปลได้

- **แผง Copilot** — ส่วนหัวของข้อความทุกข้อ (ข้อความของคุณ, การตอบกลับของโมเดล และบล็อก `กำลังคิด...`) มีไอคอนแปลภาษา คลิกครั้งแรกแทนเนื้อหาข้อความด้วยคำแปล คลิกอีกครั้งคืนต้นฉบับ;
- **ร่างข้อความคอมมิต** — กล่องคอมมิตในแผง Git จะแสดงปุ่มแปลทันทีที่ร่างของคุณยาวหลายบรรทัด ปุ่มนี้แปลร่างทั้งหมดในที่เดิม และคลิกอีกครั้งก็เรียกถ้อยคำต้นฉบับของคุณกลับมา;
- **ป๊อปอัปรายละเอียดคอมมิต** — ชี้คอมมิตในประวัติ Git จะเปิดป๊อปอัปรายละเอียด; ไอคอนแปลข้างแฮชสลับข้อความคอมมิตเป็นภาษาของคุณ;
- **ตัวแก้ไขโค้ดและมุมมอง diff** — เลือกอะไรก็ได้ (การเลือกแบบบล็อกก็นับ) คลิกขวาแล้วเลือก `แปลภาษา` ตรารูปลูกโลกเล็ก ๆ จะทำเครื่องหมายบรรทัดที่แปลแล้วในรางเลขบรรทัด และการ์ดคำแปลจะเปิดขึ้นข้างการเลือก

## วิธีการทำงาน

1. ไคลเอนต์ส่งข้อความไปยังเซิร์ฟเวอร์ — พร้อมชื่อไฟล์เมื่อข้อความถูกเลือกจากตัวแก้ไขหรือ diff เพื่อให้โมเดลรู้ว่าไฟล์ใช้ไวยากรณ์คอมเมนต์แบบใด;
2. LLM แปลภาษาของเซิร์ฟเวอร์แปลเป็นภาษาเป้าหมายที่กำหนดในเว็บ UI การจัดรูปแบบ Markdown (หัวข้อ รายการ ตาราง บล็อกโค้ด) ถูกรักษาไว้ ในการเลือกจากไฟล์ เครื่องหมายคอมเมนต์อย่าง `//` หรือ `#` จะถูกจัดเป็นของตกแต่งและถูกตัดออก ส่วนโค้ดและตัวระบุคงเดิม;
3. ไคลเอนต์เรนเดอร์ผลลัพธ์เป็น Markdown ณ ที่ที่คำขอมาจาก — แทนที่แบบอินไลน์สำหรับข้อความแชท หรือในการ์ดที่เลื่อนได้สำหรับการเลือกในตัวแก้ไขและ diff

## สิ่งที่คุณต้องมี

- เซิร์ฟเวอร์ที่เปิดใช้คุณสมบัติแปลภาษา — การตั้งค่าครั้งเดียวอธิบายไว้ใน *การตั้งค่าเซิร์ฟเวอร์* (ส่วน `LLM` ของเว็บ UI);
- ไคลเอนต์เดสก์ท็อปที่เชื่อมต่อกับเซิร์ฟเวอร์นั้น ไม่ต้องตั้งค่าอะไรฝั่งไคลเอนต์: ทุกส่วนใช้การตั้งค่าเซิร์ฟเวอร์ชุดเดียวกันโดยอัตโนมัติ

หากไม่ได้กำหนดค่าการแปล ไคลเอนต์จะแสดงข้อผิดพลาดจากเซิร์ฟเวอร์ (เช่นในการ์ดคำแปล) แทนผลลัพธ์
