เมื่อเซิร์ฟเวอร์ตั้งค่าเสร็จ ทุกส่วนของไคลเอนต์จะเสนอการแปลผ่านไอคอนลูกโลกเดียวกัน ผลลัพธ์ถูกแคชต่อรายการ การสลับไปมาจึงไม่ทำซ้ำคำขอ

## ข้อความในแผงแชท

ส่วนหัวข้อความทุกข้อมีไอคอนแปล — ข้างเวลาในข้อความของคุณ ขวาของชื่อผู้ส่งและเวลาในการตอบกลับของโมเดล และขวาของป้าย `กำลังคิด...` ในบล็อกการใช้เหตุผล:

- **คลิกแรก** ส่ง Markdown ดิบของข้อความไปยังเซิร์ฟเวอร์และสลับเนื้อหาข้อความเป็นคำแปล ไอคอนสว่างขึ้นขณะแสดงคำแปล;
- **คลิกอีกครั้ง** คืนข้อความต้นฉบับ;
- คำแปลติดอยู่กับข้อความตราบที่บทสนทนายังเปิด รวมถึงบล็อก `กำลังคิด...` เมื่อขยายออก

ข้อความที่แปลแล้วเรนเดอร์เป็น Markdown ปกติ รายการ ตาราง และบล็อกโค้ดจึงคงรูปร่างเดิม

## ร่างข้อความคอมมิต

ในกล่องคอมมิตของแผง Git ปุ่มแปลจะปรากฏข้างปุ่ม AI เมื่อร่างของคุณเกินหนึ่งบรรทัด:

- **คลิก** เพื่อแปลร่างทั้งหมด — ข้อความที่แปลแล้วแทนร่างในกล่องเป็นพรีวิวแบบอ่านอย่างเดียว;
- **คลิกอีกครั้ง** เพื่อกลับสู่ถ้อยคำต้นฉบับ (ตัวร่างเองไม่เคยถูกแก้ไข);
- พิมพ์ไม่ได้ขณะแสดงพรีวิว สลับกลับก่อนแล้วจึงแก้ไขต่อ

![กล่องคอมมิตพร้อมปุ่มแปลและพรีวิวที่แปลแล้ว](images/translation-commit-draft.jpg)

## ป๊อปอัปรายละเอียดคอมมิต

ชี้คอมมิตในประวัติ Git เพื่อเปิดป๊อปอัปรายละเอียด ข้างปุ่มคัดลอกแฮชมีไอคอนแปล: คลิกเพื่อแปลข้อความคอมมิตในป๊อปอัป คลิกอีกครั้งเพื่อดูต้นฉบับ ข้อความที่แปลเรนเดอร์เหมือนต้นฉบับ — บรรทัดหัวข้อ เนื้อหา Markdown และบล็อกโค้ดรวมอยู่ด้วย

![ป๊อปอัปรายละเอียดคอมมิต — ปุ่มคัดลอกและแปลบนบรรทัดแฮช](images/translation-git-tip.jpg)

## การเลือกในตัวแก้ไขโค้ด

เลือกข้อความในตัวแก้ไขโค้ด — การเลือกปกติและแบบบล็อก (สี่เหลี่ยม) ใช้ได้ทั้งคู่ — คลิกขวาและเลือก `แปลภาษา` (รายการแรกของเมนู):

1. ตราลูกโลกทึบปรากฏเหนือเลขบรรทัดของบรรทัดแรกที่เลือก;
2. การ์ดคำแปลเปิดขึ้นทันทีพร้อมตัวแทน *Translating…* และเติมเต็มเมื่อเซิร์ฟเวอร์ตอบกลับ;
3. การ์ดเกาะแน่น: อยู่กับที่ขณะคุณเลื่อน มีเพียงปุ่มปิด `Esc` หรือคลิกข้างนอกเท่านั้นที่ปิดมันได้ ชี้ที่ตราจะเปิดกลับมา

การเลือกที่แปลแล้วแต่ละอันมีตราของตัวเอง การแปลบรรทัดเดิมซ้ำแค่แสดงการ์ดที่แคชไว้ ตราจะหายไปเมื่อคุณเปิดไฟล์อื่น

![การเลือกในตัวแก้ไขโค้ดพร้อมแปลภาษาในเมนูบริบท](images/translation-editor-menu.jpg)

## การเลือกในมุมมอง diff

มุมมอง diff ใช้วิธีเดียวกัน: เลือกบรรทัดในเนื้อหา diff คลิกขวา `แปลภาษา` ตราแทนเลขบรรทัดใหม่ของแถวแรกที่เลือก และการ์ดผลลัพธ์ยึดอยู่ใต้มัน การเลือกในโหมดแก้ไขก็แปลได้ การสลับไปไฟล์หรือคอมมิตอื่นจะล้างตราทิ้ง

![diff ที่มีการเลือกถูกแปล — ตรารางเลขบรรทัดและการ์ดคำแปล](images/translation-diff-card.jpg)

## สิ่งที่ถูกแปล

เซิร์ฟเวอร์บอกโมเดลว่าข้อความมาจากไหน:

- **ร้อยแก้ว** (ข้อความแชท, ข้อความคอมมิต) — การจัดรูปแบบ Markdown ถูกรักษาไว้ แปลเฉพาะภาษาธรรมชาติ;
- **การเลือกจากไฟล์** (ตัวแก้ไข, diff) — ชื่อไฟล์เดินทางไปกับคำขอ โมเดลจึงรู้เครื่องหมายคอมเมนต์ของไฟล์ (`//`, `#`, `--`, …) เครื่องหมายคอมเมนต์ถูกตัดออกและข้อความคอมเมนต์ถูกแปลเป็นร้อยแก้ว Markdown ในคอมเมนต์ (หัวข้อ รายการ บล็อกโค้ด) อยู่รอด หากการเลือกเป็นโค้ดธรรมดา เฉพาะคอมเมนต์และสตริงลิเทอรัลที่ถูกแปล — ตัวระบุและโครงสร้างคงเดิม
