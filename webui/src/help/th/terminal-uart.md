UART อนุกรมเปลี่ยนคอนโซลอนุกรมของอุปกรณ์ (พอร์ตดีบัก บอร์ดฝังตัว SBC) ให้เป็นแท็บเทอร์มินัลที่คุณดูและโต้ตอบได้เหมือนเทอร์มินัลอื่น

## การตั้งค่าพอร์ต

ในส่วน `UART` ของ Web UI → `Add UART Port`:

- `Name` — แสดงเป็นชื่อเทอร์มินัล (เช่น "Debug Console");
- `Serial Port` — เลือกจากพอร์ตที่ตรวจพบ (จำนวนแสดงบนสุดของหน้า);
- `Baud Rate` / `Data Bits` / `Parity` / `Stop Bits` / `Flow Control` — ให้ตรงกับเฟิร์มแวร์ของอุปกรณ์;
- `Terminal Type` และ `Encoding` — การเข้ารหัสเริ่มต้น Auto (UTF-8) และตามเฟิร์มแวร์ได้;
- `Show Advanced Options` เผยพารามิเตอร์อนุกรมเพิ่มเติม

พอร์ตที่บันทึกปรากฏในรายการ `Configured UART Ports` และแก้ไขหรือลบได้ตลอดเวลา

## การใช้ในไคลเอนต์

พอร์ตที่ตั้งไว้เปิดเป็นแท็บเทอร์มินัลเหมือนเซสชันเซิร์ฟเวอร์ปกติ:

- ข้อมูลอนุกรมแสดงเมื่อมาถึง; อินพุตคีย์บอร์ดไปที่พอร์ตโดยตรง;
- เมนูคลิกขวามี `Clear` (ล้างจอ) และเมนูย่อย `Encoding` (สลับการเข้ารหัสสด ๆ; ตัวปัจจุบันมีเครื่องหมายถูก);
- เซสชัน UART ไม่มีฟีเจอร์เชลล์ (ไม่มีคำสั่งด่วน Apps หรือรายการเมนู Envs)

การใช้ทั่วไป: คอนโซลเราเตอร์/สวิตช์ ล็อกบอร์ดฝังตัว เฝ้าดูเครื่องแฟลช
