การจัดการไฟล์ให้คุณทำงานกับไฟล์บนเซิร์ฟเวอร์ตรงจากไคลเอนต์: แถบกิจกรรมซ้ายมีสองรายการ — `Recent` (โปรเจกต์ล่าสุด) และตัวสำรวจไฟล์ — ใช้คู่กับแท็บเทอร์มินัล ทุกอย่างทำงานบนเซิร์ฟเวอร์ของเซสชัน: เครื่องท้องถิ่น หรือเครื่องระยะไกล/แชร์ผ่านรีเลย์

## Recent: โปรเจกต์ล่าสุด

`Recent` รายชื่อโฟลเดอร์ที่เอเจนต์โค้ดของคุณเปิดล่าสุดบนเซิร์ฟเวอร์ปัจจุบัน ใหม่สุดก่อน:

- **คลิก**รายการหนึ่งแล้วตัวสำรวจไฟล์สลับไปไดเรกทอรีนั้น;
- **คลิกขวา**เปิดเมนูการกระทำด่วน:
  - `Open in VS Code` — เปิดไดเรกทอรีใน VS Code บนเครื่องนี้;
  - `Reveal in File Explorer` — แสดงในตัวจัดการไฟล์ของ OS;
  - `Copy Full Path` / `Copy Relative Path` — เส้นทางเต็ม หรือสัมพัทธ์ต่อ repo;
  - `Search in Folder` — ค้นไฟล์ในไดเรกทอรีนั้น;
  - `Open in Terminal` — เปิดแท็บเทอร์มินัลใหม่ที่นั่น; `cd Here` — cd เทอร์มินัลปัจจุบันไปหา;
  - `Host with HTTP server` — เผยแพร่ไดเรกทอรีเป็นบริการไฟล์ HTTP (ดู เผยแพร่ด้วยเซิร์ฟเวอร์ HTTP);
  - `Open in App` — เปิดด้วยแอปเอเจนต์ที่ตรวจพบบนเซิร์ฟเวอร์

## ตัวสำรวจไฟล์

แท็บ `Explorer` ท่องและจัดการระบบไฟล์ฝั่งเซิร์ฟเวอร์: นำทางไดเรกทอรี มุมมองต้นไม้และแบน ค้นหา สร้าง/เปลี่ยนชื่อ/ลบ และการดำเนินการไฟล์อื่น บวกการอัปโหลดและดาวน์โหลดแบบลากปล่อยระหว่างเซิร์ฟเวอร์กับเครื่องนี้ ดู ตัวสำรวจไฟล์ และ อัปโหลดและดาวน์โหลด
