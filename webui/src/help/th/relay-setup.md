การเชื่อมเครื่องเข้ารีเลย์ใช้สองฟิลด์: ที่อยู่รีเลย์และคีย์ของมัน ดูหน้าก่อน ภาพรวม สำหรับฟีเจอร์นี้คืออะไรและชิ้นส่วนประกอบกันอย่างไร

## ตั้งค่าเซิร์ฟเวอร์รีเลย์

1. เปิดส่วน `Server` บนเครื่องที่จะทำรีเลย์
2. ตรวจว่าตั้ง `Secret Key` ไว้ — ปุ่มลูกเต๋าสร้างได้ คีย์เดียวกันจับคู่ทั้งไคลเอนต์และเซิร์ฟเวอร์แชร์
3. ขยายบล็อก `QR Code` และเลือก `Network Interface` / `IP Version` ที่ไคลเอนต์และเซิร์ฟเวอร์แชร์จะใช้เข้าถึง

## เชื่อมเซิร์ฟเวอร์แชร์

ข้อมูลการเชื่อมต่อรีเลย์เดินทางบนคลิปบอร์ด — ไม่ต้องพิมพ์ใหม่:

1. ใน Web UI ของเซิร์ฟเวอร์รีเลย์ คลิก `QR code` มันคัดลอกสตริงแชร์ที่เข้ารหัส (ที่อยู่ พอร์ต คีย์ลับ) ไปคลิปบอร์ด
2. เปิด Web UI บนเครื่องที่จะแชร์ ส่วน `Server` และคลิกในฟิลด์ `Relay Address`
3. เบราว์เซอร์เด้งกล่องถามว่าอนุญาตให้ไซต์นี้เข้าถึงคลิปบอร์ดหรือไม่ — คลิก `Allow`:

![เบราว์เซอร์ — กล่องอนุญาตเข้าถึงคลิปบอร์ดเมื่อฟิลด์ถูกโฟกัส](images/relay-allow-paste.jpg)

4. เมื่ออนุญาตแล้วคลิปบอร์ดถูกตรวจ: ถ้ามีสตริงแชร์ ปุ่มวางจะปรากฏข้างฟิลด์ — คลิกเพื่อถอดรหัสและกรอก `Relay Address` และ `Relay Secret Key` อัตโนมัติ:

![Web UI — ที่อยู่รีเลย์และคีย์ลับกรอกอัตโนมัติจากสตริงแชร์ที่วาง](images/relay-paste-share.jpg)

5. ตรวจค่าแล้วคลิก `Apply` — การบันทึกต่อรีเลย์ต้นน้ำใหม่

![Web UI — ฟิลด์รีเลย์ที่กรอกแล้วพร้อมปุ่ม Apply](images/relay-apply-share.jpg)

> การอ่านคลิปบอร์ดต้องการบริบทปลอดภัย (HTTPS หรือ localhost) บน HTTP ธรรมดาปุ่มวางคงซ่อน; พิมพ์ที่อยู่และคีย์รีเลย์ด้วยมือ

โดยค่าเริ่มต้นการเชื่อมต่อต้นทางจะเข้ารหัสแต่ไม่ตรวจสอบ หากต้องการตรึงใบรับรองของรีเลย์ด้วย ดูหน้าการตรวจสอบแบบเข้มงวดบนรีเลย์ในส่วนใบรับรองและ TLS

## ไคลเอนต์เดสก์ท็อป

### แท็บเซิร์ฟเวอร์แชร์

แท็บเทอร์มินัลที่รันบนเซิร์ฟเวอร์แชร์มีสองเครื่องหมาย: แถบสีขอบซ้ายของแท็บ — สีหนึ่งต่อเซิร์ฟเวอร์ — และไอคอน OS ระยะไกล (Windows / Apple / Linux) ข้างจุดสถานะ แท็บท้องถิ่นบนเซิร์ฟเวอร์รีเลย์เองไม่มีเครื่องหมาย

![ไคลเอนต์เดสก์ท็อป — เครื่องหมายแท็บเทอร์มินัลเซิร์ฟเวอร์แชร์](images/relay-tab-indicator.jpg)

### โปรไฟล์เทอร์มินัลรายเซิร์ฟเวอร์

เมนูโปรไฟล์ (แถบหัวเรื่อง) จัดกลุ่มโปรไฟล์เทอร์มินัลตามเซิร์ฟเวอร์: ของเซิร์ฟเวอร์รีเลย์ที่เชื่อมอยู่ก่อน แล้วกลุ่มพับได้หนึ่งกลุ่มต่อเซิร์ฟเวอร์แชร์ ตั้งชื่อตามเครื่อง ขยายกลุ่มและเลือกโปรไฟล์เพื่อเปิดเทอร์มินัลบนเซิร์ฟเวอร์นั้น เมนูตามกลุ่มแท็บที่เลือกในแถบหัวเรื่อง

![ไคลเอนต์เดสก์ท็อป — เมนูโปรไฟล์พร้อมกลุ่มรายเซิร์ฟเวอร์](images/relay-profile-menu.jpg)

### การจัดกลุ่มและหน้าต่างแยก

ตัวเลือกกลุ่มบนแถบหัวเรื่องรายกลุ่มแท็บของทุกเซิร์ฟเวอร์; กลุ่มเริ่มต้นของเซิร์ฟเวอร์แชร์แสดงเป็น `Ungrouped (ชื่อเซิร์ฟเวอร์)` เมนูย่อยของแต่ละกลุ่มรายแท็บเพื่อสลับเร็วและมี `Move Group to New Window` ฉีกทั้งกลุ่มออกเป็นหน้าต่างของตัวเอง — มีประโยชน์อุทิศหน้าต่างหรือจอให้เครื่องหนึ่ง

![ไคลเอนต์เดสก์ท็อป — เมนูตัวเลือกกลุ่มพร้อมการกระทำย้ายไปหน้าต่างใหม่](images/relay-group-selector.jpg)
