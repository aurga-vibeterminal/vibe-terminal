เชื่อมต่อไคลเอนต์กับเซิร์ฟเวอร์นี้ด้วย QR code การจับคู่จาก Web UI — หรือพิมพ์ข้อมูลด้วยตนเอง ทุกอย่างที่ไคลเอนต์ต้องการ (ที่อยู่ พอร์ต คีย์ลับ) แสดงอยู่ในส่วน Server

## เตรียมเซิร์ฟเวอร์

- เปิดส่วน `Server` และตรวจว่าตั้ง `Secret Key` ไว้แล้ว; กดปุ่มลูกเต๋าเพื่อสร้าง การสร้างคีย์ใหม่จะยกเลิกไคลเอนต์ที่จับคู่ทุกตัว ซึ่งต้องจับคู่ใหม่
- ขยายบล็อก `QR Code` และเลือก `Network Interface` และ `IP Version` (IPv4 / IPv6) ที่เครื่องอื่นควรใช้เข้าถึงเซิร์ฟเวอร์นี้
- ถ้าตั้งค่าโดเมน DDNS ไว้ คุณสามารถสลับ `Connection Type` เป็น `DDNS Domain` เพื่อให้ QR code ฝังโดเมนแทนที่อยู่ IP
- `Pairing Preview` แสดง URL การเชื่อมต่อที่แน่นอน (`wss://host:port`) ที่ไคลเอนต์จะเรียก
- การคลิก `QR code` จะคัดลอกสตริงแชร์ที่เข้ารหัสไปยังคลิปบอร์ด — ไคลเอนต์ใช้มันกรอกอัตโนมัติแบบแตะครั้งเดียว

## ไคลเอนต์เดสก์ท็อป

- กดปุ่มชื่อเซิร์ฟเวอร์บนแถบหัวเรื่องและเลือก `Servers` ในเมนูเพื่อเปิดกล่องโต้ตอบ Server Manager

![ไคลเอนต์เดสก์ท็อป — เมนูเซิร์ฟเวอร์ที่เปิดโดยกดปุ่มชื่อเซิร์ฟเวอร์](images/start-connect-server-menu.jpg)

- กดปุ่ม `+` ข้างรายการเซิร์ฟเวอร์เพื่อเริ่มแบบฟอร์ม Add Server
- ถ้าสตริงแชร์อยู่ในคลิปบอร์ดของคุณ ไอคอนคลิปบอร์ดจะปรากฏขวาบนของแบบฟอร์ม — กดเพื่อถอดรหัสและกรอก `Title`, `Address` และ `Secret Key` อัตโนมัติ
- มิฉะนั้นกรอกฟิลด์ด้วยตนเอง: ชื่อที่แสดง URL การเชื่อมต่อ (`wss://host:port`, ที่อยู่ IPv6 ในวงเล็บเหลี่ยม) และคีย์ลับ
- กด `Save` แล้วเลือกเซิร์ฟเวอร์ใหม่เพื่อเปิดเซสชัน

![ไคลเอนต์เดสก์ท็อป — Server Manager พร้อมแบบฟอร์ม Add Server](images/start-connect-add-server.jpg)
