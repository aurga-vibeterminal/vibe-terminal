ตัวสำรวจไฟล์ทำงานบนระบบไฟล์ฝั่งเซิร์ฟเวอร์ แถบเครื่องมือบนสุดของแผงซ้ายสลับระหว่าง Recent / Explorer / Git / Debug / Search; Explorer คือเบราว์เซอร์ไฟล์

## ปุ่ม Home: กระโดดไป cwd ของเทอร์มินัล

กดปุ่ม `Home` (บ้าน) บนแถบเครื่องมือ:

- สลับไปมุมมอง `Explorer`;
- กระโดดไป **ไดเรกทอรีทำงานของเทอร์มินัลที่ใช้งาน** (cwd ของมัน);
- ปักหมุดไดเรกทอรีนั้นเป็นต้นไม้และล้างช่องค้นหา — คุณเริ่มเสมอจาก "เทอร์มินัลอยู่ไหน ก็เห็นตรงนั้น"

![ตัวสำรวจไฟล์โหมดปกติ — Home, เส้นทางย่อย และรายการแบน](images/files-explorer.jpg)

## โหมดต้นไม้และการค้นหา

- **ปักหมุดเป็นต้นไม้**: ปุ่มหมุดปลายขวาของเส้นทางย่อยสลับระหว่างรายการแบนกับโหมดต้นไม้ ในโหมดต้นไม้โฟลเดอร์ขยายเป็นต้นไม้ไดเรกทอรีแบบพับได้ (การกระโดดจาก Home ปักหมุดอัตโนมัติ);
- **ค้นหา**: ช่องค้นบนสุดกรองรายการปัจจุบันตามชื่อระหว่างพิมพ์; `Search in Folder` จากเมนูบริบทของ Recent รันการค้นหาแบบวนซ้ำทั้งไดเรกทอรี

![ตัวสำรวจไฟล์โหมดต้นไม้ — รากที่ปักหมุดขยายเป็นต้นไม้ไดเรกทอรีพับได้](images/files-explorer-tree.jpg)

## การดำเนินการพื้นฐาน

คลิกขวาไฟล์หรือโฟลเดอร์:

- **สร้าง**: `New Folder` / `New File`;
- **แก้ไข**: `Rename`; `Copy` / `Cut` / `Paste` (ใช้ข้ามไดเรกทอรี);
- **ลบ**: `Delete` พร้อมกล่องยืนยัน;
- **เชื่อมเทอร์มินัล**: `Open in Terminal` เปิดแท็บเทอร์มินัลใหม่ที่ไดเรกทอรีนั้น; `cd to Directory` ให้เทอร์มินัลปัจจุบัน cd ไป;
- **เชื่อม OS**: `Reveal in File Explorer` แสดงไดเรกทอรีท้องถิ่นในตัวจัดการไฟล์ของระบบ;
- **เส้นทาง**: `Copy Full Path` / `Copy Relative Path`;
- **เผยแพร่**: `Host with HTTP server` เผยแพร่ไดเรกทอรีเป็นบริการไฟล์ HTTP (ดู เผยแพร่ด้วยเซิร์ฟเวอร์ HTTP); `Open in App` เปิดด้วยแอปเอเจนต์ที่ตรวจพบบนเซิร์ฟเวอร์

ทุกการดำเนินการทำงานบนระบบไฟล์ฝั่งเซิร์ฟเวอร์; เซสชันระยะไกลทำตัวเหมือนท้องถิ่นเป๊ะ ๆ
