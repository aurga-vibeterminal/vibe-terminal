แผง Git ฝังการควบคุมเวอร์ชันเข้าไคลเอนต์: stage, commit, จัดการ branch, worktree, rebase โต้ตอบ, แก้ความขัดแย้ง และ push — โดยไม่ออกจากหน้าต่างเทอร์มินัล ทุกอย่างทำงานบน repo Git ของเซสชันเทอร์มินัลปัจจุบัน: เซสชันรันอยู่ไดเรกทอรีไหน repo นั้นคือสิ่งที่แผงแสดง

## การเปิด

คลิกแท็บ `Git` ในแถบกิจกรรมซ้าย (ข้อมูล repo ปรากฏเฉพาะเมื่อเซสชันที่ใช้งานอยู่ใน repo Git) repo ของแท็บตามเซสชันที่ใช้งานของมัน; เส้นทางย่อย repo ให้กระโดดระหว่าง repo แม่-ลูก และ submodule แสดงแยก

![แผง Git — การเปลี่ยนแปลง ประวัติ และ branch](images/git-overview-panel.jpg)

## ความสามารถ

- **Stage และ commit** — stage/unstage รายไฟล์หรือพร้อมกัน ทิ้งการเปลี่ยนแปลง commit พร้อมข้อความ ข้อความคอมมิตจาก AI (ดู ผู้ช่วย LLM);
- **ประวัติ** — ประวัติคอมมิตและรายไฟล์ เปรียบเทียบและคืนค่าระหว่างรีวิชัน;
- **Branch** — checkout, สร้างและลบ branch ท้องถิ่น/ระยะไกลและแท็ก;
- **Worktree** — checkout branch ไปต้นไม้ทำงานแยก (แท็บเทอร์มินัลใหม่เปิดอัตโนมัติ) แล้ว merge กลับเมื่อเสร็จ (ดู Worktree);
- **Rebase โต้ตอบ** — เรียงใหม่/squash/แก้คิวคอมมิตแบบเห็นภาพพร้อมแก้ความขัดแย้ง (ดู Rebase โต้ตอบ);
- **แก้ความขัดแย้ง** — ตัวแก้ merge สี่โหมด รวมเอเจนต์ AI ที่แก้ hunk ทีละอัน (ดู แก้ความขัดแย้ง);
- **Push และอื่น ๆ** — กล่อง push เต็มรูปแบบ, stash, การจัดการ detached-HEAD (ดู Push, Checkout และอื่น ๆ)

หน้าต่อ ๆ ไปครอบคลุมแต่ละด้านตามลำดับนี้
