เอเจนต์โค้ด (Claude Code, Codex, Kimi, Pi, OpenCode…) รู้เฉพาะสิ่งที่ถึงอินพุตของมัน `การเพิ่มบริบท` คือวิธีส่งเส้นทางไฟล์และชิ้นโค้ดโดยไม่ต้องพิมพ์ซ้ำ: ลากไฟล์จาก `Explorer` หรือลากข้อความที่เลือกจากเอดิเตอร์โค้ดและมุมมอง diff ของ Git ตรงเข้าเทอร์มินัลของเอเจนต์หรือช่องแชท Copilot

## ลากไฟล์เข้า

กดไฟล์ — หรือเลือกหลายไฟล์ — ในรายการไฟล์ `Explorer` แล้วลาก:

- **ลงบนเทอร์มินัล**: เส้นทางเต็มถูกพิมพ์ที่จุดปล่อย คั่นด้วยช่องว่าง พร้อมเป็นส่วนของพรอมต์ถัดไปของคุณต่อเอเจนต์;
- **ลงบนช่องแชท Copilot**: เส้นทางถูกแทรกในร่างข้อความ บรรทัดละหนึ่ง เพื่อประกอบพรอมต์หลายไฟล์ก่อนส่ง

เส้นทางที่ลากจากตัวจัดการไฟล์ของ OS และปล่อยบนเทอร์มินัลถูกใส่เครื่องหมายคำพูดอัตโนมัติ ชื่อที่มีช่องว่างจึงรอดครบ

## ลากโค้ดที่เลือกเป็นบริบท

เลือกข้อความในเอดิเตอร์โค้ดหรือ diff ของ Git แล้วกันตัวเลือกเองและลากลงเทอร์มินัล:

- เมื่อเทอร์มินัล **กำลังรันเอเจนต์โค้ด** การปล่อยจะแทรก *บล็อกบริบท* — เส้นทางไฟล์ ช่วงบรรทัด และชิ้นโค้ดห่อในรั้วโค้ด:

````text
File: crates/vterm/src/ui/terminal_view.rs
Lines: 558-566
```
fn can_accept_native_drop(&self, info: &DndInfo) -> bool { … }
```
````

- เมื่อเทอร์มินัลอยู่ที่ **พรอมต์เชลล์ธรรมดา** การปล่อยจะพิมพ์ข้อความดิบที่เลือกแทน ท่าเดียวกันจึงใช้กับคำสั่งปกติได้;
- เมื่อดู diff ที่คอมมิตเฉพาะ บล็อกจะมีบรรทัด `Commit:` ติดรีวิชันที่แน่นอนเพิ่มด้วย

## คัดลอกบริบท

บล็อกเดียวกันอยู่ในเมนูคลิกขวา: `Copy Context` ในเอดิเตอร์โค้ดและมุมมอง diff คัดลอกมันไปคลิปบอร์ด วางในช่องแชท Copilot — หรือเอเจนต์อื่น — เมื่อการลากไม่สะดวก ภาพเคลื่อนไหวข้างบนแสดงบล็อกที่ได้ในอินพุตของเอเจนต์

## เคล็ดลับ

- เลือกหลายไฟล์ใน `Explorer` เพื่อปล่อยหลายเส้นทางพร้อมกัน;
- ช่องแชท Copilot ส่งตรงเข้าเทอร์มินัลเหมือนข้อความพิมพ์ (ดู `ประวัติเอเจนต์โค้ด`) บริบทที่เพิ่มที่นั่นจึงถึงเอเจนต์เหมือนคุณพิมพ์เอง;
- จับคู่กับ `การยืนยันอัตโนมัติ` ให้เอเจนต์ทำงานกับบริบทที่ปล่อยโดยไม่ถามซ้ำ
