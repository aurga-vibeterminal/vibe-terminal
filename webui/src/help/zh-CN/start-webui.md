Web 界面是服务器自身的配置页面：每项服务器功能都组织为一个分区，列在左侧边栏中。它不是终端——日常操作在桌面客户端或 `vtermc` 中完成（见「功能概览」）。本页介绍布局与通用行为；各功能章节会详细介绍每个分区的设置。

## 布局

- **侧边栏** —— 分区列表（见下文）、服务器名称旁的帮助图标，以及底部的应用版本号；在窄屏幕上它从左侧滑入，由页头的汉堡按钮切换开合；
- **页头** —— 当前分区的标题，右上方是语言选择器和浅色/深色切换（窄屏幕上帮助图标也在那里）；
- **内容区** —— 选中分区的表单，居中显示、可滚动。

## 分区

按侧边栏顺序：

- `服务器` —— 端口、TLS 证书与身份验证设置：`密钥`、配对 `二维码`、中继地址和自动启动开关都在这里（见「客户端配对」和「配置指南」）。在 Linux 上，自动启动提示还会说明显示管理器的自动登录，用于在本地登录之前进入桌面（见「远程桌面与模拟器」的「服务器配置」）；
- `Terminal` —— 终端分析：提示符检测、自动确认与 LLM 分类（见「自动确认」）；
- `UART` —— 基于本地 UART 端口的串口终端 Profile（见「UART 串口」）；
- `插件` —— 已安装的插件：可启用、编辑或上传（LLM 提供商也是插件——见「LLM 大模型」）；
- `LLM` —— 为每个 AI 功能指定 LLM 提供商（见「LLM 大模型」）；
- `语音识别` —— 语音识别提供商、模型与转写设置（见「语音输入」的「服务器配置」）；
- `环境变量` —— 按分组树组织的环境变量集合（见「环境变量」）；
- `MCP` —— 暴露给 Code Agent 的终端 MCP 服务器（见「Terminal MCP」）；
- `DDNS` —— DDNS 提供商与同步设置（见「DDNS 动态域名」）；
- `端口转发` —— 转发端口池与实时的 TLS 转发（见「端口转发」）；
- `静态 HTTP` —— 通过 HTTP 托管的文件夹与当前生效的分享（见「HTTP 文件服务」）；
- `远程桌面` —— 远程桌面的画面采集、输入与串流设置（见「远程桌面与模拟器」的「服务器配置」）；
- `LLM 统计` —— 所有 LLM 功能的 Token 用量、请求数与性能指标。

## 保存与提示

- 大多数分区在编辑后不久会自动保存——保存指示器与任何错误信息显示在分区底部；
- `MCP`、`DDNS` 和 `远程桌面` 会挂起编辑，直到按下 `保存更改`：在有未保存编辑期间，按钮旁会出现 `未保存的更改` 提示，`重置` 会丢弃这些编辑；
- 从移动客户端打开时，Web 界面会跟随应用的语言与主题，并隐藏自身的语言和主题切换控件。
