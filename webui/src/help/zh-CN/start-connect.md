使用 Web 界面中的配对二维码将客户端连接到本服务器，也可以手动输入连接信息。客户端所需的全部信息（地址、端口、密钥）都在服务器分区中显示。

## 准备服务器

- 打开 `服务器` 分区，确认已设置 `密钥`；点击骰子按钮可生成一个。重新生成密钥会使所有已配对客户端失效，需要重新配对。
- 展开 `二维码` 区块，选择其他设备应使用的 `网卡` 和 `IP 版本`（IPv4 / IPv6）。
- 若已配置 DDNS 域名，可把 `连接方式` 切换为 `DDNS 域名`，让二维码嵌入域名而不是 IP 地址。
- `配对预览` 会显示客户端实际拨号的连接 URL（`wss://host:port`）。
- 点击 `二维码` 会把加密的分享串复制到剪贴板——客户端可据此一键自动填充。

## 桌面客户端

- 点击标题栏中的服务器名称按钮，在菜单中选择 `服务器`，打开服务器管理器对话框。

![桌面客户端 — 点击服务器名称按钮打开的服务器菜单](images/start-connect-server-menu.jpg)

- 点击服务器列表旁的 `+` 按钮，进入添加服务器表单。
- 如果剪贴板里有分享串，表单右上角会出现剪贴板图标——点击它即可解密分享串并自动填写 `名称`、`地址` 和 `密钥`。
- 否则手动填写：显示名称、连接 URL（`wss://host:port`，IPv6 地址需加方括号）和密钥。
- 点击 `保存`，然后选择该服务器即可开始会话。

![桌面客户端 — 服务器管理器的添加服务器表单](images/start-connect-add-server.jpg)
