UART 串口把设备的串行控制台（调试口、嵌入式主板、单板机）变成一个终端标签页,在客户端里像普通终端一样查看与交互。

## 配置端口

Web 界面的 `UART` 设置页 → `添加 UART 端口`：

- `名称`：显示在终端里的名字（如"调试控制台"）；
- `串口`：从检测到的串口列表中选择（页面顶部显示检测数量）；
- `波特率` / `数据位` / `校验位` / `停止位` / `流控`：与设备固件一致；
- `终端类型` 与 `编码`：编码默认自动（UTF-8）,可按设备固件选择；
- `显示高级选项` 里有更多串口参数。

保存后端口出现在 `已配置 UART 端口` 列表,可随时编辑或删除。

## 在客户端使用

配置好的端口像普通服务器会话一样打开为终端标签：

- 串口数据只读呈现,键盘输入直接发往串口；
- 右键菜单提供 `清除`（清屏）与 `Encoding` 子菜单（运行中切换编码,当前项带 ✓）；
- 串口会话没有 Shell 相关能力（快速命令、应用、环境变量菜单不出现）。

典型用途：路由器/交换机控制台、嵌入式开发板日志、工装烧录口监视。
