`Host with HTTP server` 把服务器上的任意目录一键发布为 HTTP 文件服务:同一局域网(或经中继)的其他设备——手机、另一台电脑、测试机——用浏览器就能浏览和下载该目录下的文件。适合临时分享构建产物、日志包,或给不装客户端的设备递文件。

## 使用方式

三种入口都在目录上:`文件列表` 右键、`Recent` 条目右键、面包屑右键 → `Host with HTTP server`。

点击后:

1. 服务器在该目录上启动静态 HTTP 服务,端口从 Static HTTP 的端口区间中分配;
2. **本地服务器**:服务的 `http://127.0.0.1:端口/` 地址直接复制到剪贴板,状态栏提示 "HTTP server: …(copied to clipboard)";
3. **远程服务器**(经中继连接):客户端自动请求一条反向代理映射,拿到可从外部访问的分享 URL 再复制——局域网限制不再是障碍。

之后在任何设备的浏览器打开该 URL,即可像普通网页目录一样浏览、下载文件。

## 管理已启动的服务

每个 HTTP 服务会持续运行,直到手动停止:

- 打开 Web 界面的 `静态 HTTP` 设置页,`Services` 列表列出所有正在运行的服务及其根目录;
- 每条记录有停止按钮;端口区间也可在该页配置。

> 该服务是只读的文件浏览,不会暴露写接口;目录内容变化实时可见,适合持续产出日志/产物的场景。
