Vibe Terminal 是一个可远程管理的终端中枢，面向嵌入式与服务器开发。每台你要操作的机器——开发机、构建服务器、嵌入式开发板——上都运行一个**服务器**，**客户端**则从桌面应用或命令行连接到它。本指南同时涵盖两端：配置服务器的 Web 界面，以及与服务器协同工作的客户端。

## 整体架构

- 一切都运行在**服务器**上——终端会话驻留在服务器端，因此关闭客户端、网络中断或调整窗口布局都不会打断正在运行的命令；重新连接后即可从断点继续；
- 客户端通过一条加密的 WebSocket 连接（`wss://host:port`；本地服务器为 `wss://localhost:5153`）拨号，并使用服务器的**密钥**完成认证；配对通过二维码或加密的分享串完成密钥传递（详见客户端配对）；
- **Web 界面**是服务器自身的配置页面——Profile、插件、LLM 供应商、中继、端口转发等。它不是终端：日常工作在桌面客户端或 `vtermc` 中进行。

## 组成部分

- **服务器** —— 运行在目标机器上；承载终端会话，并向已连接的客户端提供文件、Git、远程桌面、语音和 AI 等功能；
- **桌面客户端** —— 原生工作区：支持分屏、标签组与独立窗口的终端，文件浏览器与编辑器，Git 工具，语音输入，Code Agent 会话历史，远程桌面与远程调试；
- **`vtermc` CLI** —— 在任意普通终端、SSH 远程环境或无图形界面的机器上启动并接入会话；与桌面客户端共用同一份服务器列表（详见命令行客户端）；
- **Web 界面** —— 在浏览器中配置服务器本身，左侧边栏按分区组织（详见使用 Web 界面）。

## 托盘图标

在带有桌面会话的机器上，服务器运行期间会显示托盘图标：

![托盘图标菜单 —— Open 将运行中的客户端带到前台或启动一个新实例，Settings 在浏览器中打开 Web 界面，语音项则启动或停止语音识别服务器](images/start-tray-menu.jpg)

- **Open** —— 将运行中的桌面客户端带到前台，未在运行时则启动一个新实例（双击图标效果相同）；
- **Settings** —— 在浏览器中打开服务器的 Web 界面（详见使用 Web 界面）；
- **Start/Stop Vibe Voice** —— 无需打开 Web 界面即可启动或停止语音识别服务器，与 `语音识别` 分区的 Start/Stop 按钮一致；启用语音识别后才会出现，且标签随状态变化（例如模型已加载时显示 `Stop Vibe Voice (model on device)`）；
- **Exit** —— 关闭服务器。

当文件夹通过 HTTP 对外托管时，`HTTP Servers` 项会为每个分享提供一键停止（详见 HTTP 文件服务）。

## 功能地图

本指南其余部分与侧边栏章节一一对应：

- **终端** —— 创建、分屏与组织终端；Profile、WSL 与 UART 串口；快速命令与环境变量；通过 MCP 让外部 Agent 驱动终端；查看 Code Agent 会话；自动确认交互式提示；
- **文件管理** —— 最近项目、服务器端文件浏览器、上传与下载，以及通过 HTTP 对外提供目录（详见文件浏览器、上传与下载和 HTTP 文件服务）；
- **Git** —— 暂存、LLM 辅助提交、Worktree、交互式 Rebase、解决冲突与 Push；
- **远程桌面与模拟器** —— 观看并控制服务器的屏幕、Android 设备与模拟器，以及 iOS 模拟器；
- **语音输入** —— 服务器端语音识别，支持按键说话（push-to-talk）听写与 LLM 润色；
- **中继** —— 通过单一公共入口点触达位于 NAT 或动态 IP 之后的机器；
- **远程访问** —— 为服务器上运行的服务提供 DDNS 动态域名与 TLS 端口转发；
- **AI 功能** —— LLM 供应商作为插件，可按功能分别指定，并支持 MCP 集成（详见 LLM 大模型和 MCP）。

## 从哪里开始

1. 打开 Web 界面的 `服务器` 分区，设置 `密钥`，并配对客户端——客户端配对 将详细介绍二维码和手动配置两种方式；
2. 浏览 Web 界面各分区，配置 Profile、插件与各项功能——详见使用 Web 界面；
3. 在服务器上打开一个终端，按需学习上述各章节。
