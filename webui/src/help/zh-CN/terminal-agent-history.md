在终端里运行代码 Agent(Claude Code、Codex、Kimi、Pi、OpenCode 等)时,它们的对话被局限在那个终端窗口里——滚动历史混在命令输出中,换屏就看不到了。`Code Agent 会话历史`把 Agent 的完整对话提取到一个专用面板:结构化展示每一轮问答、可切换历史会话、支持翻译,还能从面板直接向终端发命令。

## 打开面板

点击标题栏右侧的聊天(`AI`)按钮切换 Copilot 面板;面板顶部的下拉列出当前终端会话中 Agent 的**全部历史会话**,按时间排序,选中即加载。

![Copilot 面板 —— 会话下拉与对话流](images/terminal-agent-history.jpg)

## 工作原理

- 服务器知道当前终端里运行着哪个 Agent 应用,并解析其**原生会话文件**(各 Agent 的 JSONL/历史格式,位于其项目目录);会话文件变化时实时推送增量,对话流随之滚动更新;
- 支持的 Agent:`claude` / `codex` / `kimi` / `pi` / `opencode`;其他应用暂无会话面板;
- 消息区分角色(你 / Agent)与类型(正文 / **Thinking** 推理过程),显示模型名与时间,Markdown 渲染。

## 面板能力

- **切换会话**:顶部 `Conversations` 下拉在多个历史会话间切换,每项显示内容摘要与时间;
- **翻译**:每条 Agent 消息可请求翻译,译文就地替换原文(可切回);
- **直接发命令**:底部输入框输入内容(Shift+Enter 换行)回车,命令直接送入当前终端——像在 Agent 的输入框里打字一样,但不占用终端视图。

## 与其他功能的关系

- 面板与终端是同一会话的两个视图:Agent 在终端里的提问仍然通过终端回答(或配合「自动确认」);面板负责回看历史,不截获交互;
- 结合 `Terminal MCP`(见前一篇),外部 Agent 也能读取终端屏幕与执行命令——面板展示的对话与 MCP 操作共同构成完整的 Agent 工作记录。
