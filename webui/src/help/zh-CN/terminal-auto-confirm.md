服务端终端分析器持续观察终端输出：识别命令提示、检测任务完成，并在配合 LLM 时对输出进行分类。「自动确认」是其中最常用的能力——当终端停在普通的确认提示（如 `Proceed? [Y/n]`）时，自动替你按下 Enter,长时间任务不再卡在询问上。

## 配置

Web 界面的 `终端分析` 设置页：

- `终端观察器`：总开关，启用服务端终端分析；
- `自动确认`：只对被分类为**普通确认**的提示自动发送 Enter,不会盲目应答其他提问；
- `延迟分析时间（秒）`：Agent 进入空闲后等待多久再分析，避免连续任务之间产生多余的 LLM 请求；
- `确认宽限期（秒）`：检测到确认提示后等待用户接管的宽限时间；
- `完成通知`：输出被分类为任务完成时发送事件（可接入通知渠道）。

> 页面提示：Agent 自身的自动模式开启时，建议在客户端关闭「自动确认」，避免两套自动化互相抢答。

## 依赖 LLM

提示的分类由 LLM 完成：在 `LLM 配置` 页选择 `提供商` 并填好凭据（配置用于终端分类、Git 提交信息、聊天助手等全部 LLM 功能）。未配置 LLM 时,分析器仍可工作，但分类精度下降，自动确认建议保持关闭。
