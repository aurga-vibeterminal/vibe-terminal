Git 面板把版本控制做进客户端：不离开终端窗口就能完成暂存、提交、分支管理、worktree、交互式 rebase、冲突解决和推送。所有操作作用于当前终端会话所在 的 Git 仓库——在哪个目录开的终端,面板就显示哪个仓库。

## 打开

点击左侧活动栏的 `Git` 标签（仅当活动会话位于 Git 仓库中时显示仓库数据）。标签页的仓库由其活动会话决定；通过仓库面包屑可以在父/子仓库间跳转,子模块会单独列出。

![Git 面板全貌 —— 更改、历史与分支](images/git-overview-panel.jpg)

## 能做什么

- **暂存与提交**：逐文件或批量 stage/unstage、放弃更改、写信息提交,支持 AI 生成提交信息（见「LLM 辅助」）；
- **历史**：提交历史与单文件历史,任意两个版本的对比、回退；
- **分支**：本地/远程分支与标签的切换（Checkout）、新建、删除；
- **Worktree**：为分支创建独立工作树（自动开新终端标签）,完成后合并回主分支再删除（见「Worktree 工作树」）；
- **交互式 Rebase**：可视化重排/合并/编辑提交队列,冲突可视化解决（见「交互式 Rebase」）；
- **冲突解决**：四种模式的合并编辑器,包括逐块 AI 代理解决（见「解决冲突」）；
- **推送与杂项**：带完整选项的 Push 对话框、Stash、Detached HEAD 处理（见「Push、Checkout 与更多」）。
