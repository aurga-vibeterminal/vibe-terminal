插件（Addon）在不改动核心的前提下为服务器扩展新能力：LLM 提供商、语音识别后端、动态 DNS 更新器、额外的 MCP 工具面，以及 Code Agent 应用识别，都以插件形式存在。Web UI 的 `Addons`（插件）区块负责管理它们。

## 类别

每个插件声明一个类型，区块按类型分组展示卡片：

- **Applications（应用）** —— 教终端观察器识别一个 Code Agent CLI（内置 Claude Code、Codex、Kimi Code、Pi、OpenCode）：进程检测、忙碌/空闲状态、自动化钩子；
- **LLM Providers（LLM 提供商）** —— 供 AI 功能选择的对话补全后端（内置 OpenAI 兼容提供商）；
- **Voice / ASR（语音识别）** —— 语音识别后端（内置 `vibe-voice` 插件指向被守护的本地 ASR 服务器）；
- **Dynamic DNS（动态 DNS）** —— 让域名始终指向当前地址（内置 Cloudflare）；
- **MCP** —— 在 MCP 宿主上额外提供的 MCP 工具面（内置 EasyEDA Pro）；
- 其余类型归入 **Other（其他）** 分组。

## 内置与上传的插件

- **内置（Built-in）** 插件随程序发布，始终可用。其清单与源码保持原始状态 —— 被覆盖的源码随时可以恢复；
- **上传（Uploaded）** 插件是你自己的：一个包含清单和 JavaScript 源码的 zip 包，通过 `Upload Addon`（上传插件）按钮安装；
- `Modified`（已修改）徽标表示该插件的源码被你覆盖过。

每张卡片显示插件类型、徽标和启用开关；展开后显示描述、作者、配置字段和源码。

## 配置

插件的清单声明其配置字段，展开的卡片会把它们渲染成表单。配置按插件存储，仅在插件启用时生效；密码类字段保持掩码显示。关闭插件会保留其配置，重新启用后继续沿用。
