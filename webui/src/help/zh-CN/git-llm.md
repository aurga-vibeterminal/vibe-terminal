Git 面板的智能化能力由 LLM 驱动：一键生成提交信息、AI 辅助理解差异、在 rebase 冲突中逐块代理解决。这些都依赖在 Web 界面配置好的 LLM 提供商。

## 配置提供商

打开 Web 界面的 `LLM 配置` 页：

- `提供商` 选择一个 LLM 后端并填入凭据（密钥等字段由提供商的清单定义）；这里的配置是全局的——终端分类、Git 提交信息、聊天助手等共用同一提供商；
- 提供商本身是 LLM 类型的插件：内置了常用提供商,自定义提供商可以在 `插件` 页面上传 zip 安装（清单声明配置字段,Web 界面据此自动生成表单）。

![Web 界面 LLM 配置页 —— 选择提供商并填写凭据](images/git-llm-provider-config.jpg)

## Git 中的 LLM 能力

- **生成提交信息**：在 Git 面板的提交框旁点击 AI 按钮,LLM 读取本次暂存的差异生成提交信息,以打字动画填入输入框；信息始终可编辑,确认后再提交；
- **差异 AI 分析**：差异视图头部的星光按钮触发对当前 diff 的分析解读；
- **冲突 AI 代理**：rebase 冲突的合并编辑器提供 AI 模式,逐块解释并解决冲突（含置信度）,详见「解决冲突」。

![AI 生成的提交信息填入提交框](images/git-llm-commit-message.jpg)

> LLM 只读取仓库内容用于生成文本；提交与合并动作始终由你确认触发。
