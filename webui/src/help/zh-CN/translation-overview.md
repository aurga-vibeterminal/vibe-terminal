翻译功能把客户端里遇到的文字变成你选择的语言：AI 聊天回复、提交信息、代码注释，或代码编辑器与差异视图中的任意选区。翻译模型配置在服务器端完成——客户端只负责发送文本、渲染结果并缓存，方便在原文与译文之间来回切换。

## 哪里可以使用翻译

- **Copilot 聊天面板**——每条消息的头部（你的消息、模型回复和 `思考中...` 块）都有翻译图标。点击一次将消息正文替换为译文；再点一次恢复原文；
- **提交信息草稿**——Git 面板的提交框在草稿超过一行后会显示翻译按钮。它会把整段草稿就地翻译，再点一次即可找回原稿；
- **提交详情弹窗**——在 Git 历史中悬浮某次提交会打开详情弹窗；哈希旁边的翻译图标把提交信息切换成你的语言；
- **代码编辑器与差异视图**——选中任意内容（块选区也算），右键选择 `翻译`。行号槽中会出现一个地球角标标记被翻译的行，译文卡片在选区旁展开。

## 工作原理

1. 客户端把文本发给服务器——若文本来自编辑器或差异视图的选区，还会附上文件名，让模型知道该文件使用哪种注释语法；
2. 服务器的翻译 LLM 将其翻译为 Web 界面配置的目标语言。Markdown 格式（标题、列表、表格、代码块）会被保留；文件选区中的注释标记（如 `//`、`#`）会被识别为装饰并去除，代码与标识符原样保留；
3. 客户端把结果按 Markdown 渲染在请求来源处——聊天消息就地替换，编辑器与差异选区显示在可滚动的卡片中。

## 前置条件

- 一台启用了翻译功能的服务器——一次性配置见「服务器配置」页（Web 界面的 `LLM 配置`）；
- 一台连接到该服务器的桌面客户端。客户端无需任何配置：所有界面共用同一份服务器设置。

若翻译未配置，客户端会显示服务器返回的错误（例如在译文卡片中），而不是翻译结果。
