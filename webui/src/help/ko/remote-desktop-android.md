데스크톱 화면에 더해, 원격 데스크톱은 Android 기기도 스트리밍할 수 있습니다 — adb 경유 실기기와 AVD 에뮬레이터. 클라이언트는 이들을 휴대폰 틀 창에 표시하고 터치 입력, 회전, 원격 에뮬레이터 수명 주기 제어를 제공합니다.

## 전제 조건

서버가 Android 도구 모음을 찾아야 합니다:

- **Android SDK**(`adb` 제공) — 기기와 에뮬레이터 모두에 필요;
- **Android Studio** — AVD 에뮬레이터 부팅에 필요.

둘 다 기본적으로 자동 감지됩니다. 감지가 실패하거나 도구가 표준 위치 밖에 있으면 `Remote Desktop` → `Screen streaming tools`의 `Android SDK directory` / `Android Studio directory`를 설정하세요. 변경은 즉시 적용됩니다(핫 적용, 서버 재시작 불필요).

## 기기 원천

경로가 갖춰지면 서버는 사용 가능한 Android 원천을 자동 나열합니다:

- **연결된 실기기** — USB 디버깅을 켜고 USB로 연결. `adb devices`에 보이는 것은 무엇이든 스트리밍 가능;
- **AVD 에뮬레이터** — 실행 중인 에뮬레이터는 저절로 나타납니다. 클라이언트에서 고른 AVD를 요청 시 부팅(먼저 손으로 켤 필요 없음)하고 원격으로 종료할 수도 있습니다.

각 원천은 클라이언트의 SCREENS 바에 자기 항목을 받습니다.

## 화면 회전

에뮬레이터 창의 회전 버튼은 `adb`를 통해 시스템 `user_rotation`을 설정합니다. 기기 자체의 표시 방향이 바뀌고 창이 새 해상도에 다시 맞춰지며 세로·가로 모두에 적응합니다.

## 클라이언트 쪽

데스크톱 클라이언트 왼쪽 패널의 `Debug` 탭을 열고 SCREENS 바의 `Android Simulator` 버튼(서버가 Android 원천을 공개할 때만 나타남)을 클릭해 에뮬레이터 창을 엽니다. 기기 선택기가 휴대폰 틀의 모양을 바꾸고 `Rotate`가 방향을 뒤집습니다. 클라이언트 사용법 참조.

> 실기기 터치 주입은 adb의 입력 채널을 사용합니다(Android 4.4+). 일부 제조사 커스텀 ROM은 제한하며, 그 경우 기기는 보기 전용입니다.
