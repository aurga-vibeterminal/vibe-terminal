환경 변수 기능은 프로젝트별(`ANDROID_HOME`, API 키, 프록시 설정)로 그룹화된 변수 집합을 유지하고, 원클릭으로 어떤 터미널 세션에나 적용하거나 해제합니다. 서버 설정에 저장되며 값은 저장 시 암호화됩니다.

## Web UI에서 유지 관리

`Environment Variables` 섹션은 트리로 정리됩니다:

- **그룹** — 순수한 컨테이너, 중첩 가능(마우스 오른쪽 클릭 → `New Group`). 프로젝트나 시나리오별 정리용;
- **컬렉션** — 트리의 잎이자 실제 변수 보유자(`New Leaf`). 터미널에 적용할 수 있는 것은 컬렉션뿐입니다;
- 각 컬렉션의 키/값 쌍은 `Edit Variables`로 편집합니다(`Add Variable`). 값은 기본적으로 숨겨져 있습니다;
- 컬렉션은 복제해 변형을 만들 수 있습니다(한 키만 바꾼 같은 집합).

![환경 변수 페이지 — 그룹/컬렉션 트리](images/terminal-env-tree.jpg)

## 터미널에 적용

터미널 안에서 마우스 오른쪽 클릭 → `Envs`:

- 하위 메뉴는 Web UI의 트리를 반영합니다. 컬렉션을 펼쳐 `Apply`를 고르면 변수가 현재 세션에 주입되고, `Clear`로 다시 제거합니다;
- 새로 시작된 프로세스는 변수를 봅니다(이미 실행 중인 포그라운드 프로그램은 못 봅니다);
- 컬렉션은 그룹 아래 접힌 채 나타납니다. 트리에 컬렉션이 없는 동안에는 `Envs` 항목 전체가 숨겨집니다.
