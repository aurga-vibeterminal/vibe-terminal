머신을 릴레이에 연결하는 데는 두 필드면 됩니다: 릴레이 주소와 그 키. 기능이 무엇이고 조각들이 어떻게 맞는지는 이전 페이지 개요를 참고하세요.

## 릴레이 서버 설정

1. 릴레이 역할을 할 머신에서 `Server` 섹션을 엽니다.
2. `Secret Key`가 설정되어 있는지 확인 — 주사위 버튼으로 생성할 수 있습니다. 같은 키가 클라이언트와 공유 서버 양쪽을 페어링합니다.
3. `QR Code` 블록을 펼치고 클라이언트와 공유 서버가 접근에 사용할 `Network Interface` / `IP Version`을 고릅니다.

## 공유 서버 연결

릴레이의 연결 정보는 클립보드로 이동합니다 — 다시 칠 필요 없이:

1. 릴레이 서버의 Web UI에서 `QR code`를 클릭합니다. 암호화된 공유 문자열(주소, 포트, 시크릿 키)이 클립보드에 복사됩니다.
2. 공유할 머신의 Web UI를 열고, `Server` 섹션에서 `Relay Address` 필드를 클릭합니다.
3. 브라우저가 이 사이트의 클립보드 접근 허용을 묻는 대화상자를 띄웁니다 — `Allow`를 클릭:

![브라우저 — 필드에 초점을 맞추면 나타나는 클립보드 접근 권한 대화상자](images/relay-allow-paste.jpg)

4. 접근이 허용되면 클립보드가 확인되고, 공유 문자열이 들어 있으면 필드 옆에 붙여넣기 버튼이 나타납니다. 클릭하면 복호화해 `Relay Address`와 `Relay Secret Key`를 자동 채웁니다:

![Web UI — 붙여넣은 공유 문자열에서 자동 채워진 릴레이 주소와 시크릿 키](images/relay-paste-share.jpg)

5. 값을 검토하고 `Apply` 클릭 — 저장하면 업스트림 릴레이에 다시 연결됩니다.

![Web UI — 채워진 릴레이 필드와 Apply 버튼](images/relay-apply-share.jpg)

> 클립보드 읽기에는 보안 컨텍스트(HTTPS 또는 localhost)가 필요합니다. 평문 HTTP에서는 붙여넣기 버튼이 숨겨진 채입니다. 릴레이 주소와 키를 손으로 입력하세요.

기본적으로 업스트림 연결은 암호화만 될 뿐 검증되지 않습니다. 릴레이 인증서도 고정하려면 '인증서 및 TLS'의 '릴레이 엄격 검증'을 참고하세요.

## 데스크톱 클라이언트

### 공유 서버 탭

공유 서버에서 실행되는 터미널의 탭에는 두 표식이 붙습니다: 탭 왼쪽 가장자리의 색 스트라이프 — 서버마다 한 색 — 과 상태 점 옆의 원격 OS 아이콘(Windows / Apple / Linux). 릴레이 서버 자신의 로컬 탭에는 표식이 없습니다.

![데스크톱 클라이언트 — 공유 서버 터미널의 탭 표식](images/relay-tab-indicator.jpg)

### 서버별 터미널 프로필

프로필 메뉴(제목 표시줄)는 서버별로 터미널 프로필을 묶습니다: 연결된 릴레이 서버 자신의 프로필이 먼저, 이어 공유 서버마다 머신 이름을 딴 접을 수 있는 그룹. 그룹을 펼쳐 프로필을 고르면 그 서버에 터미널이 열립니다. 메뉴는 제목 표시줄에서 선택된 탭 그룹을 따릅니다.

![데스크톱 클라이언트 — 서버별 그룹이 있는 프로필 메뉴](images/relay-profile-menu.jpg)

### 그룹화와 별도 창

제목 표시줄의 그룹 선택기는 모든 서버의 탭 그룹을 나열하며, 공유 서버의 기본 그룹은 `Ungrouped (Server Name)`으로 표시됩니다. 각 그룹의 하위 메뉴는 빠른 전환을 위해 탭을 나열하고 `Move Group to New Window`를 제공합니다 — 그룹 전체를 자체 창으로 분리해 한 대의 머신에 창이나 모니터를 전용하는 데 유용합니다.

![데스크톱 클라이언트 — 새 창으로 이동 동작이 있는 그룹 선택기 메뉴](images/relay-group-selector.jpg)
