머신과 서버 사이의 파일 전송은 드래그 앤 드롭이며, 방향이 곧 의미입니다: **드래그인 = 서버로 업로드, 드래그아웃 = 이 머신으로 다운로드**. 전송은 암호화된 클라이언트-서버 연결을 탑니다. 원격·공유 서버도 로컬처럼 동작합니다.

## 업로드: 드래그인

OS 파일 관리자에서 파일(또는 폴더 전체)을 파일 목록으로 드래그해 놓습니다:

- 트리 모드에서 **폴더 행에 놓으면** 그 폴더로 업로드됩니다. **루트에 놓으면**(행 사이의 삽입 선) 현재 루트 디렉터리로 업로드됩니다;
- 목록 하단에 전송 행이 나타나 `Uploading`, 파일 이름, 진행률 표시줄을 보여 줍니다;
- 완료되면 `Uploaded n file(s)`가 표시됩니다. 실패에는 이유(예: 권한 거부)가 붙고 목록이 새로 고쳐져 새 파일이 드러납니다.

## 다운로드: 드래그아웃

목록에서 파일을 누르고, 클라이언트 창 밖으로 드래그해 OS 파일 관리자(또는 바탕 화면)에 놓습니다:

- 파일이 서버에서 놓은 곳으로 스트리밍됩니다;
- 전송 행은 같은 방식으로 진행률을 표시합니다. **완료된 다운로드 행은 클릭할 수 있고** 로컬 다운로드 폴더를 엽니다;
- 다중 선택 후 여러 파일을 한 번에 드래그할 수 있습니다.

> 드래그 앤 드롭은 이 머신과 한 서버 사이의 단일 파일 이동입니다. 두 서버 사이의 데이터 이동에는 HTTP 서버로 공유나 터미널 명령(scp/rsync)을 결합하세요.
