애드온은 코어를 건드리지 않고 서버에 새 기능을 추가합니다: LLM 제공자, 음성 인식 백엔드, 동적 DNS 업데이터, 추가 MCP 도구 면, Code Agent 앱 감지가 모두 애드온으로 존재합니다. Web UI의 `Addons` 섹션에서 관리합니다.

## 범주

각 애드온은 타입을 선언하고, 섹션은 그에 따라 카드를 묶습니다:

- **Applications** —— 터미널 옵저버가 Code Agent CLI를 인식하게 합니다(Claude Code, Codex, Kimi Code, Pi, OpenCode 내장): 프로세스 감지, 사용 중/유휴 상태, 자동화 훅；
- **LLM Providers** —— AI 기능이 선택하는 채팅 완성 백엔드(OpenAI 호환 제공자 내장)；
- **Voice / ASR** —— 음성 인식 백엔드(내장 `vibe-voice` 애드온은 관리되는 로컬 ASR 서버를 가리킵니다)；
- **Dynamic DNS** —— 호스트 이름을 현재 주소에 따라가게 합니다(Cloudflare 내장)；
- **MCP** —— MCP 호스트에서 제공되는 추가 도구 면(EasyEDA Pro 내장)；
- 그 외 타입은 **Other** 그룹으로 들어갑니다.

## 내장 및 업로드된 애드온

- **내장** 애드온은 프로그램에 포함되어 항상 사용할 수 있습니다. 매니페스트와 소스는 원본 그대로이며 —— 덮어쓴 소스는 언제든 복원할 수 있습니다；
- **업로드된** 애드온은 직접 만든 것입니다: 매니페스트와 JavaScript 소스를 담은 zip을 `Upload Addon` 버튼으로 설치합니다；
- `Modified` 배지는 소스를 덮어쓴 애드온을 나타냅니다.

각 카드는 타입, 배지, 활성화 토글을 보여주며, 펼치면 설명, 작성자, 설정 필드, 소스 코드가 나타납니다.

## 설정

애드온의 매니페스트가 설정 필드를 선언하면 펼친 카드가 폼으로 만듭니다. 값은 애드온별로 저장되고 활성화된 동안만 효과가 있으며, 비밀번호 필드는 마스킹됩니다. 끄더라도 설정은 유지되어 다시 켜면 이어서 사용할 수 있습니다.
