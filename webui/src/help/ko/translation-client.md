서버 구성이 끝나면 클라이언트의 모든 화면에서 같은 지구 아이콘으로 번역을 제공합니다. 결과는 항목별로 캐시되어 오가더라도 요청이 반복되지 않습니다.

## 채팅 패널 메시지

모든 메시지 헤더에 번역 아이콘이 있습니다 — 내 메시지는 시간 옆에, 모델 응답은 보낸이 이름과 시간 오른쪽에, 추론 블록은 `생각 중...` 라벨 오른쪽에:

- **첫 클릭**은 메시지의 원본 Markdown을 서버로 보내고 본문을 번역으로 교체합니다. 번역이 표시되는 동안 아이콘이 밝게 켜집니다;
- **다시 클릭**하면 원문으로 돌아갑니다;
- 대화가 열려 있는 동안 번역은 메시지를 따라다니며, 펼친 `생각 중...` 블록도 마찬가지입니다.

번역된 메시지는 일반적인 Markdown으로 렌더링되어 목록, 표, 코드 블록의 형태가 유지됩니다.

![헤더의 번역 아이콘과 아래에 표시된 번역 본문](images/translation-chat-message.jpg)

## 커밋 메시지 초안

Git 패널의 커밋 상자에서는 초안이 두 줄을 넘으면 AI 버튼 옆에 번역 버튼이 나타납니다:

- **클릭**하면 초안 전체를 번역합니다 — 번역문이 읽기 전용 미리보기로 상자를 채웁니다;
- **다시 클릭**하면 원래 초안으로 돌아갑니다(초안 자체는 절대 수정되지 않습니다);
- 미리보기가 표시되는 동안에는 입력할 수 없습니다. 먼저 되돌린 뒤 계속 편집하세요.

![커밋 상자의 번역 버튼과 번역 미리보기](images/translation-commit-draft.jpg)

## 커밋 상세 팝업

Git 기록에서 커밋에 마우스를 올려 상세 팝업을 엽니다. 해시 복사 버튼 옆에 번역 아이콘이 있습니다. 클릭하면 팝업 안에서 커밋 메시지를 번역하고, 다시 클릭하면 원문을 봅니다. 번역문은 원문과 동일하게 렌더링됩니다 — 제목 줄, Markdown 본문, 코드 블록 포함입니다.

![커밋 상세 팝업 — 해시 줄의 복사와 번역 버튼](images/translation-git-tip.jpg)

## 코드 에디터 선택 영역

코드 에디터에서 텍스트를 선택하세요 — 일반 선택과 블록(사각형) 선택 모두 됩니다 — 그리고 우클릭 후 `번역`(메뉴 첫 항목)을 고릅니다:

1. 선택 영역 첫 줄의 줄번호 위에 채워진 지구 배지가 나타납니다;
2. 번역 카드가 즉시 열리고 *Translating…* 자리표시자가 서버 응답 도착 시 채워집니다;
3. 카드는 끈끈합니다. 스크롤해도 제자리에 있고 닫기 버튼, `Esc`, 바깥 클릭으로만 닫힙니다. 배지에 마우스를 올리면 다시 열립니다.

번역된 각 선택 영역마다 배지가 생기며, 같은 줄을 다시 번역하면 캐시된 카드를 다시 보여줄 뿐입니다. 다른 파일을 열면 배지는 사라집니다.

![코드 에디터의 선택 영역과 컨텍스트 메뉴의 번역](images/translation-editor-menu.jpg)

## diff 뷰 선택 영역

diff 뷰도 같은 방식입니다. diff 본문에서 줄을 선택하고, 우클릭, `번역`. 배지는 첫 줄의 새 줄번호를 대체하고 결과 카드는 그 아래에 고정됩니다. 편집 모드의 선택도 번역할 수 있습니다. 다른 파일이나 커밋으로 전환하면 배지가 지워집니다.

![diff에서 번역된 선택 영역 — 거터 배지와 번역 카드](images/translation-diff-card.jpg)

## 무엇이 번역되는가

서버는 모델에게 텍스트의 출처를 알려 줍니다:

- **산문**(채팅 메시지, 커밋 메시지) — Markdown 서식은 유지되고 자연어만 번역됩니다;
- **파일 선택 영역**(에디터, diff) — 요청에 파일 이름이 함께 가므로 모델이 그 파일의 주석 표시자(`//`, `#`, `--`, …)를 압니다. 주석 표시자는 제거되고 주석 텍스트는 산문으로 번역됩니다. 주석 안의 Markdown(제목, 목록, 코드 펜스)은 살아남습니다. 선택 영역이 일반 코드라면 주석과 문자열 리터럴만 번역되고 식별자와 구조는 그대로 남습니다.
