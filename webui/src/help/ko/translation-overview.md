번역은 클라이언트에서 마주치는 텍스트 — AI 채팅 응답, 커밋 메시지, 코드 주석, 코드 에디터나 diff의 임의 선택 영역 — 을 선택한 언어로 바꿔 줍니다. 번역 모델은 서버에서 구성하며, 클라이언트는 텍스트를 보내고 결과를 렌더링하고 캐시해서 원문과 번역을 오갈 수 있게 할 뿐입니다.

## 번역을 사용할 수 있는 곳

- **Copilot 패널** — 모든 메시지 헤더(내 메시지, 모델 응답, `생각 중...` 블록)에 번역 아이콘이 있습니다. 한 번 클릭하면 메시지 본문이 번역으로 교체되고, 다시 클릭하면 원문으로 돌아갑니다;
- **커밋 메시지 초안** — Git 패널의 커밋 상자는 초안이 여러 줄이 되면 번역 버튼을 표시합니다. 초안 전체를 그 자리에서 번역하며, 한 번 더 클릭하면 원래 문구로 돌아옵니다;
- **커밋 상세 팝업** — Git 기록에서 커밋에 마우스를 올리면 상세 팝업이 열립니다. 해시 옆의 번역 아이콘이 커밋 메시지를 당신의 언어로 바꿔 줍니다;
- **코드 에디터와 diff 뷰** — 아무거나 선택하고(블록 선택도 가능) 우클릭 후 `번역`를 고르세요. 거터에 작은 지구 배지가 번역된 줄을 표시하고, 선택 영역 옆에 번역 카드가 열립니다.

## 동작 방식

1. 클라이언트가 텍스트를 서버로 보냅니다 — 에디터나 diff에서 선택한 텍스트라면 파일 이름도 함께 전송되어 모델이 그 파일의 주석 문법을 알 수 있습니다;
2. 서버의 번역 LLM이 Web UI에서 구성된 대상 언어로 번역합니다. Markdown 서식(제목, 목록, 표, 코드 펜스)은 유지되고, 파일 선택 영역에서는 `//`나 `#` 같은 주석 표시자를 장식으로 인식해 제거하며 코드와 식별자는 그대로 둡니다;
3. 클라이언트는 결과를 요청이 온 곳에 Markdown으로 렌더링합니다 — 채팅 메시지는 그 자리에서 교체, 에디터와 diff 선택은 스크롤 가능한 카드에 표시됩니다.

## 필요 조건

- 번역 기능이 활성화된 서버. 일회성 구성은 *Server Setup*(Web UI의 `LLM` 섹션)을 참고하세요;
- 해당 서버에 연결된 데스크톱 클라이언트. 클라이언트 쪽 구성은 전혀 없습니다. 모든 화면이 동일한 서버 설정을 자동으로 사용합니다.

번역이 구성되어 있지 않으면 결과 대신 서버의 오류(번역 카드 안 등)가 표시됩니다.
