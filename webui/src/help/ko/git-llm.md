Git 패널의 지능은 LLM으로 구동됩니다. 원클릭 커밋 메시지, AI 지원 diff 읽기, 헝크 단위 에이전트 충돌 해결. 모두 Web UI에서 설정된 LLM 공급자에 의존합니다.

## 공급자 설정

Web UI의 `LLM` 섹션을 엽니다:

- `Provider`를 고르고 자격 증명을 채웁니다(필드는 공급자의 매니페스트가 정의). 설정은 전역입니다 — 터미널 분류, Git 커밋 메시지, 채팅 도우미 등 AI 기능이 같은 공급자를 공유합니다;
- 공급자는 LLM 유형 애드온입니다. 흔한 것은 내장되어 있고, 사용자 지정 공급자는 `Addons` 섹션에서 zip으로 업로드할 수 있습니다(매니페스트가 설정 필드를 선언하면 Web UI가 폼으로 만듭니다).

## Git의 LLM 기능

- **커밋 메시지 생성** — 커밋 상자 옆의 AI 버튼을 클릭하면 LLM이 스테이지된 diff를 읽고 메시지를 써서 애니메이션과 함께 상자에 입력합니다. 메시지는 계속 편집 가능합니다 — 만족할 때만 커밋하세요;
- **diff 분석** — diff 보기 헤더의 반짝임 버튼이 현재 diff를 분석합니다;
- **충돌 AI 에이전트** — 리베이스 병합 편집기의 AI 모드가 설명과 신뢰도와 함께 헝크를 하나씩 해결합니다(충돌 해결 참조).

![커밋 상자에 입력되는 AI 생성 커밋 메시지](images/git-llm-commit-message.jpg)

> LLM은 텍스트를 만들기 위해서만 리포지토리 내용을 읽습니다. 커밋과 병합은 항상 여러분이 확인할 때만 일어납니다.
