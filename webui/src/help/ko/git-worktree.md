워크트리는 한 리포지토리의 여러 브랜치를 별도 디렉터리로 체크아웃합니다. 메인 작업 트리를 건드리지 않고 병렬 개발한 뒤, 브랜치를 다시 병합하고 정리합니다. Vibe Terminal은 이 전체 순환을 클릭으로 바꿉니다.

## 워크트리 만들기

1. Git 패널의 브랜치 목록에서 대상 브랜치(로컬 또는 원격)를 마우스 오른쪽 클릭 → `New Worktree`;
2. 대화상자가 새 워크트리에 브랜치 이름을 붙입니다 — 마음대로 고치세요. 확인하면 서버가 워크트리 디렉터리를 만들고 거기에 브랜치를 체크아웃합니다;
3. **새 터미널 탭이 자동으로 열리고** 작업 디렉터리가 새 워크트리로 설정됩니다 — 메인 작업 트리는 자기 브랜치에 남은 채 즉시 격리된 개발을 시작합니다.

![New Worktree 대화상자 — 이름은 기본적으로 브랜치](images/git-worktree-create.jpg)

![새로 만든 워크트리용으로 열린 새 탭](images/git-worktree-terminal.jpg)

## 병렬 작업

각 워크트리는 완전히 독립된 작업 디렉터리입니다. 메인 브랜치와 기능 브랜치의 빌드와 테스트가 서로 간섭 없이 다른 탭에서 나란히 실행됩니다. 워크트리에서 체크아웃된 브랜치에는 브랜치 목록에서 경로를 보여 주는 워크트리 표식이 붙고, 워크트리 탭에서 어떤 브랜치처럼 바로 커밋과 푸시가 됩니다.

워크트리 브랜치의 마우스 오른쪽 클릭은 워크트리 전용 항목 두 개를 추가합니다: `Reveal in File Explorer`(로컬 세션)는 그 디렉터리를 시스템 파일 관리자에서 열고, `Open in Terminal`은 거기서 다른 탭을 엽니다.

## 다시 병합하고 정리

1. 워크트리 탭 안에서 평소처럼 커밋하고 푸시;
2. 메인 탭을 대상 브랜치(예: `main`)로 전환하고, 기능 브랜치를 마우스 오른쪽 클릭 → `Merge into Current Branch`로 작업을 가져옵니다;

   ![워크트리 브랜치를 메인 브랜치로 다시 병합](images/git-worktree-merge.jpg)

3. 병합되면 브랜치를 마우스 오른쪽 클릭 → `Delete Worktree`: 워크트리 디렉터리와 브랜치를 함께 제거합니다. 먼저 모든 것이 병합 또는 푸시되었는지 확인하세요 — 대화상자가 다시 경고하며 이 동작은 되돌릴 수 없습니다.

   ![Delete Worktree 확인 — 디렉터리와 브랜치가 함께 제거됨](images/git-worktree-delete.jpg)
