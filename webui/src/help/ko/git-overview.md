Git 패널은 버전 관리를 클라이언트에 내장합니다. 스테이징, 커밋, 브랜치 관리, 워크트리, 인터랙티브 리베이스, 충돌 해결, 푸시를 — 터미널 창을 떠나지 않고. 모든 것은 현재 터미널 세션의 Git 리포지토리에서 동작합니다. 세션이 어느 디렉터리에서 실행 중이든, 그 리포지토리가 패널에 표시됩니다.

## 열기

왼쪽 활동 막대의 `Git` 탭을 클릭합니다(활성 세션이 Git 리포지토리 안에 있을 때만 리포지토리 데이터가 나타납니다). 탭의 리포지토리는 활성 세션을 따릅니다. 리포지토리 이동 경로로 부모-자식 리포지토리 사이를 오갈 수 있고, 서브모듈은 별도로 나열됩니다.

![Git 패널 — 변경, 기록, 브랜치](images/git-overview-panel.jpg)

## 할 수 있는 것

- **스테이징과 커밋** — 파일 단위 또는 일괄 스테이지/해제, 변경 버리기, 메시지로 커밋, AI 생성 커밋 메시지(LLM 지원 참조);
- **기록** — 커밋 기록과 파일별 기록, 리비전 간 비교와 되돌리기;
- **브랜치** — 로컬/원격 브랜치와 태그 체크아웃, 생성, 삭제;
- **워크트리** — 브랜치를 격리된 작업 트리로 체크아웃(자동으로 새 터미널 탭이 열림), 끝나면 다시 병합(워크트리 참조);
- **인터랙티브 리베이스** — 커밋 큐를 시각적으로 재정렬/스쿼시/편집, 충돌 해결 포함(인터랙티브 리베이스 참조);
- **충돌 해결** — 네 가지 모드의 병합 편집기, 헝크를 하나씩 해결하는 AI 에이전트 포함(충돌 해결 참조);
- **푸시 등** — 완비된 푸시 대화상자, 스태시, detached-HEAD 처리(푸시, 체크아웃 등 참조).

이어지는 페이지가 이 순서대로 각 영역을 다룹니다.
