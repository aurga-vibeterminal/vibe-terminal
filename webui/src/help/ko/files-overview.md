파일 관리를 사용하면 클라이언트에서 서버의 파일을 직접 다룰 수 있습니다. 왼쪽 활동 막대에는 두 항목 — `Recent`(최근 프로젝트)과 파일 탐색기 — 이 있으며 터미널 탭과 함께 씁니다. 모든 것은 세션의 서버에서 동작합니다: 로컬 머신, 또는 릴레이를 통한 원격/공유 머신.

## Recent: 최근 프로젝트

`Recent`는 코드 에이전트가 현재 서버에서 가장 최근에 연 폴더를 최신순으로 나열합니다:

- 항목을 **클릭**하면 파일 탐색기가 그 디렉터리로 전환됩니다;
- **마우스 오른쪽 클릭**하면 빠른 동작 메뉴가 열립니다:
  - `Open in VS Code` — 이 머신의 VS Code에서 디렉터리 열기;
  - `Reveal in File Explorer` — OS 파일 관리자에서 보기;
  - `Copy Full Path` / `Copy Relative Path` — 전체 경로, 또는 리포지토리 기준 상대 경로;
  - `Search in Folder` — 그 디렉터리 안의 파일 검색;
  - `Open in Terminal` — 거기서 새 터미널 탭 열기. `cd Here` — 현재 터미널을 그곳으로 cd;
  - `Host with HTTP server` — 디렉터리를 HTTP 파일 서비스로 공개(HTTP 서버로 공유 참조);
  - `Open in App` — 서버에서 감지된 에이전트 앱으로 열기.

## 파일 탐색기

`Explorer` 탭은 서버 쪽 파일 시스템을 탐색하고 관리합니다: 디렉터리 탐색, 트리와 평면 보기, 검색, 만들기/이름 바꾸기/삭제 등 파일 작업, 더해 서버와 이 머신 사이의 드래그 앤 드롭 업로드·다운로드. 파일 탐색기와 업로드와 다운로드를 참고하세요.
