Web UI는 서버 자체의 설정 페이지입니다: 모든 서버 기능은 섹션으로 정리되어 왼쪽 사이드바에 나열되니다. 터미널이 아닙니다 — 일상적인 작업은 데스크톱 클라이언트나 `vtermc`에서 이루어집니다(개요 참조). 이 페이지에서는 레이아웃과 공통 동작을 설명하고, 기능 장에서는 각 섹션의 설정을 자세히 다룹니다.

## 레이아웃

- **사이드바** — 섹션 목록(아래), 서버 이름 옆의 도움말 아이콘, 하단의 앱 버전이 있습니다. 좁은 화면에서는 왼쪽에서 미끄러져 나오며 헤더의 햄버거 버튼으로 열고 닫습니다;
- **헤더** — 현재 섹션의 제목과 오른쪽 위의 언어 선택기, 밝기/어두운 테마 전환이 있습니다(좁은 화면에서는 도움말 아이콘도 여기에 있습니다);
- **콘텐츠** — 선택한 섹션의 폼이 가운데에 배치되어 스크롤됩니다.

## 섹션

사이드바 순서대로:

- `서버` — 포트, TLS 인증서 및 인증 설정: `비밀 키`, 페어링 `QR 코드`, 릴레이 주소, `자동 시작` 토글이 모두 여기에 있습니다(클라이언트 연결 및 설정 가이드 참조). Linux에서는 자동 시작 힌트가 로컬 로그인 전에 데스크톱에 도달하기 위한 디스플레이 매니저 자동 로그인도 설명합니다(원격 데스크톱과 시뮬레이터의 서버 설정 참조);
- `Terminal` — 터미널 분석: 프롬프트 감지, 자동 확인, LLM 분류(자동 확인 참조);
- `UART` — 로컬 UART 포트 기반 직렬 터미널 프로필(UART 시리얼 참조);
- `애드온` — 설치된 애드온: 활성화, 편집, 업로드할 수 있습니다(LLM 공급자도 애드온입니다 — LLM 참조);
- `LLM` — 각 AI 기능에 LLM 공급자를 할당합니다(LLM 참조);
- `음성` — 음성 인식 공급자, 모델 및 전사 설정(음성 입력의 서버 설정 참조);
- `환경 변수` — 그룹 트리로 구성된 환경 변수 컬렉션(환경 변수 참조);
- `MCP` — 코드 에이전트에 노출된 터미널 MCP 서버(터미널 MCP 참조);
- `DDNS` — DDNS 공급자 및 동기화 설정(DDNS 참조);
- `포트 포워딩` — 포워딩 포트 풀과 활성 TLS 포워딩(포트 포워딩 참조);
- `Static HTTP` — HTTP로 호스팅하는 폴더와 활성 파일 공유(HTTP 서버로 공유 참조);
- `원격 데스크톱` — 원격 데스크톱의 캡처, 입력 및 스트림 설정(원격 데스크톱과 시뮬레이터의 서버 설정 참조);
- `LLM 통계` — 모든 LLM 기능의 토큰 사용량, 요청 수 및 성능 지표.

## 저장 및 팁

- 대부분의 섹션은 편집 후 곧 자동으로 저장됩니다 — 저장 표시기와 오류는 섹션 하단에 나타납니다;
- `MCP`, `DDNS`, `원격 데스크톱`은 `변경 사항 저장`을 누를 때까지 편집을 보류합니다: 편집이 보류 중인 동안 버튼 옆에 `저장되지 않은 변경 사항` 힌트가 표시되고, `재설정`은 이를 버립니다;
- 모바일 클라이언트에서 열면 Web UI는 앱의 언어와 테마를 따르고 자체 언어 및 테마 컨트롤을 숨깁니다.
