`Host with HTTP server`는 서버의 어떤 디렉터리든 원클릭으로 HTTP 파일 서비스로 공개합니다. 같은 네트워크(또는 릴레이 경유)의 다른 기기 — 휴대폰, 다른 컴퓨터, 테스트 장비 — 가 브라우저로 그 디렉터리를 탐색하고 내려받을 수 있습니다. 빌드 산출물과 로그 묶음 공유, 클라이언트가 없는 기기에 파일을 넘길 때 이상적입니다.

## 사용법

세 가지 진입점이 모두 디렉터리에 있습니다: 파일 목록의 마우스 오른쪽 클릭 메뉴, Recent 항목의 마우스 오른쪽 클릭 메뉴, 이동 경로의 마우스 오른쪽 클릭 메뉴 → `Host with HTTP server`.

클릭하면:

1. 서버가 그 디렉터리를 루트로 하는 정적 HTTP 서비스를 시작하며, 포트는 Static HTTP 포트 범위에서 가져옵니다;
2. **로컬 서버**: `http://127.0.0.1:port/` URL이 클립보드로 바로 복사되며, "HTTP server: … (클립보드에 복사됨)" 상태 메시지가 표시됩니다;
3. **원격 서버**(릴레이 경유 연결): 클라이언트가 자동으로 리버스 프록시 매핑을 요청하고 외부에서 도달 가능한 공유 URL을 복사합니다 — LAN 제한이 장애가 되지 않습니다.

아무 기기의 브라우저에서 그 URL을 열면 디렉터리가 일반 웹 목록처럼 탐색·다운로드됩니다.

## 실행 중 서비스 관리

각 HTTP 서비스는 중지될 때까지 계속 실행됩니다:

- Web UI의 `Static HTTP` 섹션을 열면 `Services` 목록이 실행 중인 모든 서비스와 문서 루트를 보여 줍니다;
- 각 항목에 중지 버튼이 있습니다. 포트 범위는 같은 페이지에서 설정합니다.

> 이 서비스는 읽기 전용 파일 목록입니다 — 쓰기 엔드포인트가 없습니다. 디렉터리 내용은 변경에 따라 실시간으로 보이므로 계속 생성되는 로그와 산출물에 적합합니다.
