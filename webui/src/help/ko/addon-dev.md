사용자 지정에는 두 가지 수준이 있습니다: 기존 애드온의 소스에 패치하거나, 내장 애드온을 본떠 새로 만들어 업로드하는 것입니다.

## 소스 핫패치

애드온 카드의 연필 버튼으로 JavaScript 소스를 열어 편집합니다. 저장하면 원본을 덮어쓰는 스냅샷이 저장되고 —— 내장/업로드 모두 —— 변경 사항은 재시작 없이 즉시 적용됩니다. 프롬프트 조정, URL 수정, 라이브 시스템에서 아이디어 검증에 유용합니다.

`Reset`은 스냅샷을 버리고 원본 소스를 복원합니다(내장 전용 —— 업로드한 애드온은 원래 당신 것입니다).

![애드온 소스 편집 —— 저장한 스냅샷이 원본을 덮어씀](images/addon-edit-source.jpg)

## 직접 애드온 만들기

애드온은 두 개의 파일입니다:

- `<id>.json` —— 매니페스트: `id`, `name`, `description`, `author`, `email`, `date`, `type`, 그리고 Web UI가 폼으로 만드는 `config_fields`(key, label, 필드 타입, 기본값, 설명)；
- `<id>.js` —— 소스: 일반 JavaScript 파일(내장 QuickJS 엔진으로 실행, 설정된 필드에 대한 `addon.get_config()` 브리지 제공). 타입이 호출하는 함수를 내보냅니다 —— 예: LLM 제공자의 `chat_completion()`, MCP 애드온의 도구 목록과 브리지 호출.

가장 빠른 시작법은 기존 애드온 내보내기입니다: 카드의 `Export` 버튼으로 매니페스트와 소스를 하나의 zip으로 받을 수 있습니다. 목표에 가장 가까운 내장 애드온을 골라(`crates/vterm-server/src/addon/builtins/`에도 있습니다) id, name, type, 내보낼 함수를 고치고 `Upload Addon`으로 설치하세요. 업로드한 애드온은 휴지통 버튼으로 삭제할 수 있습니다.

![애드온 내보내기 —— 매니페스트와 JavaScript 소스를 하나의 zip으로](images/addon-export.jpg)

## 저장 위치

업로드된 애드온과 소스 스냅샷은 설정 디렉터리의 `addons/` 폴더에 `<id>.json` + `<id>.js`로 저장되어 재시작 후에도 남습니다. 내장 id는 `.js` 덮어쓰기만 적용되며, 내장 애드온은 자체 매니페스트를 유지합니다.
