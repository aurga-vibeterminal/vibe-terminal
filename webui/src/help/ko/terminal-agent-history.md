터미널에서 코드 에이전트(Claude Code, Codex, Kimi, Pi, OpenCode 등)를 실행하면 그 대화는 터미널 창에 갇힙니다 — 명령 출력 사이로 스크롤되고 화면이 지나가면 사라집니다. `코드 에이전트 대화 기록`은 전체 대화를 전용 패널로 끌어올립니다. 모든 주고받기가 구조화되어 표시되고, 지난 대화를 전환할 수 있으며, 메시지를 번역할 수 있고, 패널에서 바로 터미널로 명령을 보낼 수도 있습니다.

## 패널 열기

제목 표시줄 오른쪽의 채팅(`AI`) 버튼을 클릭해 Copilot 패널을 토글합니다. 상단의 드롭다운은 활성 터미널 세션에서 실행 중인 에이전트의 **모든 지난 대화**를 최신순으로 나열합니다. 하나를 고르면 로드됩니다.

![Copilot 패널 — 대화 드롭다운과 메시지 흐름](images/terminal-agent-history.jpg)

## 동작 방식

- 서버는 터미널에서 어떤 에이전트 앱이 실행 중인지 알고 그 **네이티브 세션 파일**(각 에이전트의 프로젝트 디렉터리 아래 JSONL/기록 형식)을 해석합니다. 파일 변경은 실시간으로 스트리밍되어 대화 보기가 최신으로 유지됩니다;
- 지원 에이전트: `claude` / `codex` / `kimi` / `pi` / `opencode`. 다른 앱에는 아직 대화 패널이 없습니다;
- 메시지는 역할(당신 / 에이전트)과 유형(텍스트 / **Thinking** 추론)을 가지며 모델 이름과 시간과 함께 Markdown으로 렌더링됩니다.

## 패널 기능

- **대화 전환**: 상단의 `Conversations` 드롭다운으로 지난 세션 사이를 이동합니다. 각 항목에는 요약과 시간이 표시됩니다;
- **번역**: 어떤 에이전트 메시지든 요청 시 번역할 수 있습니다. 번역은 텍스트를 그 자리에서 대체하며(토글로 되돌릴 수 있음);
- **직접 명령 보내기**: 하단 상자에 입력하고(Shift+Enter 줄 바꿈) Enter를 누르면 명령이 현재 터미널로 바로 들어갑니다. 터미널 보기를 차지하지 않고 에이전트의 입력 상자에 치는 것 같습니다.

## 다른 기능과의 관계

- 패널과 터미널은 같은 세션의 두 보기입니다. 터미널 안 에이전트의 질문은 계속 거기서(또는 자동 확인으로) 답합니다. 패널은 기록 검토용이지 상호 작용 가로채기용이 아닙니다;
- `터미널 MCP`(이전 페이지)와 결합하면 외부 에이전트가 터미널 화면을 읽고 명령을 실행할 수도 있습니다 — 여기 표시되는 대화와 MCP 행동이 에이전트 작업의 완전한 기록을 이룹니다.
