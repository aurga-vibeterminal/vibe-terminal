리베이스나 병합이 충돌에 부딪히면 패널은 충돌 보기로 전환됩니다: 왼쪽에 충돌 파일 목록, 오른쪽에 병합 편집기. 충돌 파일은 `CHANGES` 목록에도 `!` 배지로 나타나며, 클릭하면 평범한 diff 대신 이 보기로 바로 점프합니다. 편집기는 네 가지 해결 모드를 제공하며 언제든 전환할 수 있습니다.

## 충돌 파일 목록

파일은 상태별로 묶입니다: 자동 병합에 성공한 것(자동 스테이지)과 아직 수동 주의가 필요한 것. 파일을 클릭해 편집기로 엽니다. 해결이 진행될수록 목록은 실시간으로 갱신되어, 빌 때까지 이어집니다.

## 네 가지 해결 모드

- **Merge**(기본) — 충돌이 헝크 단위로 제시됩니다. 헝크마다 `take ours` / `take theirs`를 고르거나 병합 결과를 인라인 편집;
- **Split** — diff를 더 잘게 줄 단위 세그먼트로 쪼개, 한 헝크 안에서 양쪽을 조금씩 채택할 수 있습니다;
- **Raw** — `diff3` 충돌 마커(`<<<<<<<` / `=======` / `>>>>>>>`)가 있는 평범한 편집. 수동 조정용;
- **AI** — 에이전트가 파일을 헝크 단위로 해결합니다. LLM이 각 충돌 헝크를 분석해 설명과 신뢰도가 있는 해결 카드를 만듭니다. 지시를 입력해 전략을 이끌고(예: "상대 쪽 선호, 로그 문 유지"), 일시 중지하고 다른 모드에서 다듬고, 재개할 수 있습니다 — 이미 해결된 헝크는 건너뜁니다.

어느 모드에서든 해결은 세션의 파일에 쓰이고 스테이지됩니다. 수동 편집과 똑같이.
